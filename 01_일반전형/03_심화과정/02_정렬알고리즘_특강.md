# 📊 제2특강: 정렬 및 탐색 알고리즘 손추적 특강

> **"코딩 시험이 아닙니다! 중간 과정을 시험지 여백에 한 줄씩 적어 내려가는 '손추적(Hand-Tracing)'이 실수를 0으로 만듭니다."**

디미고 소질·적성검사의 컴퓨팅 사고력 영역에서 '정렬(Sorting)'과 '탐색(Search)'은 거의 매년 1~2문제씩 고정 출제되는 핵심 주제입니다. 시험에서는 학생들에게 복잡한 프로그래밍 코드를 작성하라고 요구하지 않습니다. 대신 **"알고리즘의 규칙에 따라 단계별로 데이터가 어떻게 변하는지 그 과정을 쫓아갈 수 있는가?"**를 평가합니다.

이 특강에서는 버블 정렬, 선택 정렬, 삽입 정렬의 회전별 상태 변화와 시험 단골 킬러 문제인 '최소 교환 횟수 구하기', '이진 탐색 횟수 계산'을 완벽하게 마스터합니다.

---

## 1. 왜 눈으로 풀면 100% 틀릴까? (손추적의 원칙)

정렬 문제는 머릿속으로만 생각하면 앞뒤 숫자가 꼬여서 반드시 실수가 발생합니다.
* **만점자의 풀이 습관**: 시험지 빈 공간에 대괄호 `[ ]`를 그리고, 한 회전(Pass)이 끝날 때마다 숫자가 바뀐 상태를 **한 줄씩 직접 쓰면서** 풉니다.
* 회전이 끝날 때마다 **자리가 확정된 숫자에는 밑줄이나 동그라미**를 쳐두면 다음 회전에서 비교 대상에서 제외하기가 매우 쉽습니다.

## 2. 버블 정렬 (Bubble Sort) 회전별 손추적

> **"이웃한 두 숫자를 비교해서 큰 놈을 오른쪽으로 밀어낸다!"**

거품이 수면 위로 뽀글뽀글 올라오는 것처럼, 매 회전마다 **남은 숫자들 중 가장 큰 숫자가 맨 오른쪽 끝자리로** 이동하여 확정됩니다.

### 💡 실전 추적 예제
배열: **`[7, 2, 5, 3, 1]`** (5개의 숫자를 오름차순으로 정렬)

* **[1회전 (Pass 1)]**:
  * (7, 2) 비교 ➔ 7이 크므로 교환: `[2, 7, 5, 3, 1]`
  * (7, 5) 비교 ➔ 7이 크므로 교환: `[2, 5, 7, 3, 1]`
  * (7, 3) 비교 ➔ 7이 크므로 교환: `[2, 5, 3, 7, 1]`
  * (7, 1) 비교 ➔ 7이 크므로 교환: `[2, 5, 3, 1, 7]`
  * 👉 **1회전 결과**: `[2, 5, 3, 1, 7]` (가장 큰 **7**이 맨 뒤에 고정 확정!)

* **[2회전 (Pass 2)]**: (확정된 7은 제외하고 앞의 4개만 비교)
  * (2, 5) 비교 ➔ 2가 작으므로 그대로: `[2, 5, 3, 1, 7]`
  * (5, 3) 비교 ➔ 5가 크므로 교환: `[2, 3, 5, 1, 7]`
  * (5, 1) 비교 ➔ 5가 크므로 교환: `[2, 3, 1, 5, 7]`
  * 👉 **2회전 결과**: `[2, 3, 1, 5, 7]` (두 번째로 큰 **5** 고정 확정!)

* **[3회전 (Pass 3)]**: (5와 7을 제외한 앞의 3개만 비교)
  * (2, 3) 비교 ➔ 그대로: `[2, 3, 1, 5, 7]`
  * (3, 1) 비교 ➔ 3이 크므로 교환: `[2, 1, 3, 5, 7]`
  * 👉 **3회전 결과**: `[2, 1, 3, 5, 7]` (**3** 고정 확정!)

* **[4회전 (Pass 4)]**: (앞의 2개만 비교)
  * (2, 1) 비교 ➔ 2가 크므로 교환: `[1, 2, 3, 5, 7]`
  * 👉 **최종 정렬 완료**: `[1, 2, 3, 5, 7]`

> ⚠️ **시험 단골 질문**: "버블 정렬 2회전이 끝난 직후의 배열 상태는?" ➔ 정답: `[2, 3, 1, 5, 7]`

## 3. 선택 정렬 (Selection Sort) 회전별 손추적

> **"남은 숫자들 중에서 제일 작은 놈을 딱 찍어서(선택) 맨 앞자리와 맞바꾼다!"**

매 회전마다 **남은 숫자들 중 가장 작은 숫자(최솟값)를 찾아 맨 왼쪽 자리로** 데려와 확정합니다.

### 💡 실전 추적 예제
배열: **`[7, 2, 5, 3, 1]`** (동일한 배열을 선택 정렬로 정렬)

* **[1회전 (Pass 1)]**:
  * 전체 `[7, 2, 5, 3, 1]` 중 최솟값은 **1**입니다.
  * 최솟값 **1**과 맨 첫 번째 자리의 **7**을 맞바꿉니다(Swap).
  * 👉 **1회전 결과**: `[1, 2, 5, 3, 7]` (가장 작은 **1**이 맨 앞에 고정 확정!)

* **[2회전 (Pass 2)]**: (확정된 1을 제외한 `[2, 5, 3, 7]` 중 탐색)
  * 남은 것 중 최솟값은 **2**입니다.
  * 2는 이미 두 번째 자리에 있으므로 자기 자신과 교환(사실상 이동 없음).
  * 👉 **2회전 결과**: `[1, 2, 5, 3, 7]` (**2** 고정 확정!)

* **[3회전 (Pass 3)]**: (확정된 1, 2를 제외한 `[5, 3, 7]` 중 탐색)
  * 남은 것 중 최솟값은 **3**입니다.
  * 최솟값 **3**과 세 번째 자리의 **5**를 맞바꿉니다.
  * 👉 **3회전 결과**: `[1, 2, 3, 5, 7]` (**3** 고정 확정!)

* **[4회전 (Pass 4)]**: (남은 `[5, 7]` 중 탐색)
  * 최솟값 **5**는 이미 네 번째 자리에 있으므로 유지.
  * 👉 **최종 정렬 완료**: `[1, 2, 3, 5, 7]`

## 4. 삽입 정렬 (Insertion Sort) 직관적 이해

> **"손안에 든 카드를 정리하듯, 새 카드를 이미 정렬된 부분의 알맞은 틈새에 쏙 끼워 넣는다!"**

* **동작 원리**:
  * 1번째 원소는 이미 정렬되어 있다고 봅니다.
  * 2번째 원소부터 시작하여, 앞쪽에 있는 숫자들과 비교하면서 자기보다 큰 숫자들은 뒤로 밀어내고 제자리를 찾아 들어갑니다.
* **장점**: 데이터가 이미 어느 정도 정렬되어 있는 상태라면 비교와 이동을 거의 하지 않아 매우 빠르게 끝납니다.

## 5. 카드 최소 맞바꾸기(Swap) 퀴즈 공략법

디미고 시험에서 가장 매력적인 킬러 퍼즐 중 하나는 **"알고리즘 제한 없이, 사람이 눈으로 보고 두 카드를 맞바꿀 때 최소 몇 번 만에 오름차순으로 만들 수 있는가?"**를 묻는 문제입니다.

### 💡 사이클(Cycle) 분석 기법 (만점 비법)
카드를 제자리로 보내는 관계를 화살표로 연결해 보면 닫힌 원(사이클)이 만들어집니다.
* **공식**: **(최소 교환 횟수) = (제자리가 아닌 카드의 수) - (독립된 사이클의 수)**
* 더 직관적인 방법: **"현재 카드를 자기가 원래 가야 할 자리의 카드와 1:1로 맞바꿔나가는 과정"**을 직접 손으로 시뮬레이션합니다.

## 6. 업다운(Up-Down) 이진 탐색 (Binary Search)과 횟수 공식

데이터가 **크기 순서대로 정렬(Sorted)**되어 있을 때, 정가운데(Middle) 값을 찔러보며 탐색 범위를 매번 절반(1/2)씩 날려버리는 초고속 탐색 방법입니다.

### 💡 왜 100개의 데이터도 단 7번 만에 찾을 수 있을까?
* 1번 질문: 100개 ➔ 50개로 감소
* 2번 질문: 50개 ➔ 25개로 감소
* 3번 질문: 25개 ➔ 12개로 감소
* 4번 질문: 12개 ➔ 6개로 감소
* 5번 질문: 6개 ➔ 3개로 감소
* 6번 질문: 3개 ➔ 1개로 감소
* 7번 질문: 1개 ➔ 정답 확인!
* **공식**: 데이터 수가 $N$개일 때, 최악의 경우 필요한 탐색 횟수 $k$는 **$2^k \ge N$을 만족하는 가장 작은 정수 $k$**입니다.
  * $N = 100$일 때: $2^6 = 64 < 100 \le 2^7 = 128$ 이므로 **최대 7번**!
  * $N = 30$일 때: $2^4 = 16 < 30 \le 2^5 = 32$ 이므로 **최대 5번**!

`[9, 4, 7, 2, 6]`
이 배열을 버블 정렬 알고리즘을 사용하여 오름차순으로 정렬할 때, **2회전(Pass 2)이 완료된 직후의 배열 상태**로 올바른 것은 무엇일까요?

[해설]
직접 손으로 각 회전을 추적합니다.
* **1회전**:
  * (9, 4) 비교 ➔ 바꿈: `[4, 9, 7, 2, 6]`
  * (9, 7) 비교 ➔ 바꿈: `[4, 7, 9, 2, 6]`
  * (9, 2) 비교 ➔ 바꿈: `[4, 7, 2, 9, 6]`
  * (9, 6) 비교 ➔ 바꿈: `[4, 7, 2, 6, 9]`
  * ➔ 1회전 완료 상태: `[4, 7, 2, 6, 9]` (9 고정)
* **2회전**: (확정된 9를 제외한 앞의 4개 비교)

  * (7, 2) 비교 ➔ 바꿈: `[4, 2, 7, 6, 9]`
  * (7, 6) 비교 ➔ 바꿈: `[4, 2, 6, 7, 9]`
  * ➔ 2회전 완료 상태: `[4, 2, 6, 7, 9]` (7 고정)

[정답] **[4, 2, 6, 7, 9]**

### [문제 2] 선택 정렬의 실제 교환 횟수
배열 `[6, 3, 8, 2, 5]`를 선택 정렬 알고리즘을 사용하여 오름차순으로 정렬하려고 합니다. 단, 어떤 회전에서 선택된 최솟값이 이미 그 회전의 첫 번째 자리에 위치하여 **자기 자신과 자리를 바꾸는 경우는 교환 횟수에 포함하지 않는다**고 할 때, 전체 정렬이 완료될 때까지 **서로 다른 두 숫자가 자리를 맞바꾼(Swap) 총 횟수**는 몇 회일까요?

[해설]
선택 정렬의 매 회전을 손으로 추적하며 실제 위치가 바뀌는 교환만 카운트합니다.
1. **1회전**: 전체 `[6, 3, 8, 2, 5]` 중 최솟값은 2입니다.
   * 첫 번째 자리의 6과 2를 맞바꿉니다. ➔ **(교환 1회 발생)**
   * 배열 상태: `[2, 3, 8, 6, 5]` (2 고정)
2. **2회전**: 남은 `[3, 8, 6, 5]` 중 최솟값은 3입니다.
   * 3은 이미 두 번째 자리에 있으므로 교환이 발생하지 않습니다. ➔ (교환 0회)
   * 배열 상태: `[2, 3, 8, 6, 5]` (3 고정)
3. **3회전**: 남은 `[8, 6, 5]` 중 최솟값은 5입니다.
   * 세 번째 자리의 8과 5를 맞바꿉니다. ➔ **(교환 1회 발생)**
   * 배열 상태: `[2, 3, 5, 6, 8]` (5 고정)
4. **4회전**: 남은 `[6, 8]` 중 최솟값은 6입니다.
   * 6은 이미 네 번째 자리에 있으므로 교환이 발생하지 않습니다. ➔ (교환 0회)
   * 최종 정렬 완료: `[2, 3, 5, 6, 8]`

따라서 서로 다른 두 숫자가 실제로 교환된 총 횟수는 1회전(1회) + 3회전(1회) = **2회**입니다.

[정답] **2회**

### [문제 3] 뒤섞인 번호표의 최소 교환 횟수 퍼즐
어느 책상 위에 5장의 번호표가 다음과 같은 순서로 놓여 있습니다.
`[4, 5, 1, 2, 3]`
한 번에 **임의의 서로 다른 두 장의 카드를 선택하여 자리를 맞바꾸는 조작**만 할 수 있습니다. 이 카드들을 오름차순인 `[1, 2, 3, 4, 5]`로 정렬하기 위해 필요한 **최소 맞바꾸기(Swap) 횟수**는 몇 회일까요?

[해설]
알고리즘의 제한이 없으므로, 한 번 바꿀 때마다 최대한 많은 카드가 제자리를 찾도록 맞바꿉니다.
* 현재 상태: `[4, 5, 1, 2, 3]` (목표: 1번째 자리에 1, 2번째에 2, 3번째에 3, 4번째에 4, 5번째에 5)
1. 1번 자리에 있는 '4'를 원래 자기 자리인 4번 자리에 있는 '2'와 맞바꿉니다.
   * 결과: `[2, 5, 1, 4, 3]` (4가 제자리를 찾음! 교환 1회)
2. 1번 자리에 있는 '2'를 2번 자리에 있는 '5'와 맞바꿉니다.
   * 결과: `[5, 2, 1, 4, 3]` (2가 제자리를 찾음! 교환 2회)
3. 1번 자리에 있는 '5'를 5번 자리에 있는 '3'과 맞바꿉니다.
   * 결과: `[3, 2, 1, 4, 5]` (5가 제자리를 찾음! 교환 3회)
4. 마지막으로 1번 자리에 있는 '3'과 3번 자리에 있는 '1'을 맞바꿉니다.
   * 결과: `[1, 2, 3, 4, 5]` (1과 3이 동시에 제자리를 찾으며 정렬 완료! 교환 4회)

모든 카드가 제자리가 아니었으며(5장), 5장이 하나의 순환 고리를 이루고 있었으므로 최소 교환 횟수는 $5 - 1 = 4$회입니다.

[정답] **4회**

### [문제 4] 사전에서 단어 찾기 (이진 탐색 비교 횟수)
알파벳 순서로 완벽하게 정렬되어 있는 60페이지 분량의 영단어 사전이 있습니다. 각 페이지에는 1개의 대표 단어가 적혀 있습니다. 어떤 학생이 이진 탐색(Binary Search) 알고리즘을 사용하여 특정한 단어를 찾으려고 합니다.
원하는 단어가 사전에 반드시 존재한다고 할 때, 이 학생이 그 단어를 찾기 위해 사전을 펼쳐서 확인해야 하는 **최대 페이지 확인 횟수(최악의 경우 비교 횟수)**는 몇 회일까요?

[해설]
이진 탐색은 한 번 확인할 때마다 탐색 범위가 절반으로 줄어듭니다.
* 전체 데이터 수 $N = 60$입니다.
* 최대 확인 횟수 $k$는 $2^k \ge 60$을 만족하는 최소의 정수입니다.
  * $2^1 = 2$
  * $2^2 = 4$
  * $2^3 = 8$
  * $2^4 = 16$
  * $2^5 = 32 < 60$
  * $2^6 = 64 \ge 60$
* $2^5(32)$로는 60개의 페이지를 모두 판별할 수 없지만, $2^6(64)$이면 60개의 페이지 중 어느 위치에 있든 최대 6번 만에 무조건 해당 단어를 찾아낼 수 있습니다.

[정답] **6회**
