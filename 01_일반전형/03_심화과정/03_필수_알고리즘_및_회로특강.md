# 🔌 제3특강: 필수 탐색 알고리즘 및 논리 회로 특강

> **100점을 위해 반드시 넘어야 할 마지막 산! 탐색, 회로, 압축, 그리고 최적화**

이 파일은 시험에 단골로 출제되지만 우리가 앞서 다루지 않았던 4가지 핵심 심화 개념을 다룹니다. (※ 모든 주요 개념에는 영어 용어를 병기했습니다. 컴퓨터 과학에서는 영어 용어 자체가 힌트가 될 때가 많습니다!)

---

## 1. 탐색 알고리즘 (Search Algorithm)

수많은 데이터 중에서 내가 원하는 특정 값을 찾아내는 방법입니다. 정렬(Sorting)과 함께 가장 중요한 주제입니다.

### 💡 선형 탐색 (Linear Search)
*   **개념**: 처음부터 끝까지 순서대로 하나씩 확인하며 찾는 무식하지만 확실한 방법입니다.
*   **비유**: 100장의 카드 더미에서 맨 위부터 한 장씩 뒤집으며 원하는 카드를 찾는 것.
*   **특징**: 운이 좋으면 1번 만에 찾지만, 최악의 경우(Worst Case) 맨 마지막에 있어서 100번을 다 뒤집어야 할 수도 있습니다.

### 💡 이진 탐색 (Binary Search)
*   **개념**: 데이터가 **반드시 크기 순서대로 정렬(Sorted)**되어 있을 때만 쓸 수 있습니다. 가운데 값을 찔러보고, 절반씩 버려가며 찾는 아주 빠른 방법입니다.
*   **비유**: 술래잡기에서 "업(Up) / 다운(Down)" 게임을 하는 것과 똑같습니다. 1~100 사이의 숫자를 맞출 때 무조건 '50'부터 부르는 이유가 바로 이진 탐색입니다!
*   **특징**: 100개의 데이터가 있어도 한 번 물어볼 때마다 절반(50 -> 25 -> 12 -> 6 -> 3 -> 1)이 날아가므로, 최악의 경우라도 단 **7번** 만에 무조건 답을 찾습니다.

## 2. 논리 회로 (Logic Gate)

컴퓨터의 뇌(CPU) 안에서 0과 1을 가지고 계산을 수행하는 문(Gate)입니다. 디미고 시험에서는 논리식을 이 기호로 그려놓고 최종 출력값을 묻습니다.

### 💡 꼭 외워야 할 3+1가지 기호 (그림을 상상하며 외우세요!)
1.  **AND 게이트 (논리곱)**
    *   **모양**: 알파벳 'D' 처럼 생겼습니다. (반듯하고 둥금)
    *   **규칙**: 입력이 모두 1(참)일 때만 출력도 1이 나옵니다. (1 * 1 = 1)
2.  **OR 게이트 (논리합)**
    *   **모양**: 알파벳 'C'나 화살촉처럼 앞뒤가 모두 뾰족하게 휘어 있습니다.
    *   **규칙**: 입력 중 하나라도 1(참)이면 출력은 1이 나옵니다. (1 + 0 = 1)
3.  **NOT 게이트 (논리부정)**
    *   **모양**: 삼각형 끝에 작은 동그라미(O)가 붙어 있습니다.
    *   **규칙**: 입력을 반대로 뒤집습니다. (1을 넣으면 0, 0을 넣으면 1)
4.  **XOR 게이트 (배타적 논리합, Exclusive OR)**
    *   **모양**: OR 게이트 모양인데, 입력 쪽에 줄이 하나 더 그어져 있습니다.
    *   **규칙**: 두 입력이 **서로 다를 때만** 1이 나옵니다. (입력이 1, 0 이면 출력은 1 / 1, 1 이면 출력은 0)

## 3. 데이터 압축 (Data Compression)

컴퓨터가 용량을 아끼기 위해 문자나 그림을 짧게 줄여서 표현하는 방법입니다.

### 💡 런-랭스 인코딩 (Run-Length Encoding, RLE)
*   **개념**: 연속해서 반복되는 문자(Run)를 '문자 + 반복 횟수(Length)'로 묶어서 표현하는 압축 기법(Compression Technique)입니다.
*   **예제**: `AAAAABBBCCDAA` 라는 13글자가 있습니다.
    *   A가 5번 -> `5A` (또는 A5)
    *   B가 3번 -> `3B`
    *   C가 2번 -> `2C`
    *   D가 1번 -> `1D`
    *   A가 2번 -> `2A`
*   **결과**: `5A3B2C1D2A` (10글자로 줄어듦!) 비버 챌린지(Bebras Challenge)에서 흰색 픽셀과 검은색 픽셀로 이루어진 그림을 압축할 때 이 규칙이 100% 출제됩니다.

## 4. 탐욕 알고리즘 (Greedy Algorithm)

미래를 생각하지 않고, **지금 이 순간 당장 가장 좋아 보이는 것**을 선택하는 알고리즘입니다. 최적화(Optimization) 문제에 자주 쓰입니다.

### 💡 거스름돈 문제 (Coin Change Problem)
*   **상황**: 편의점에서 860원을 거슬러 줘야 하는데, 동전 개수를 **가장 적게** 주고 싶습니다. (500원, 100원, 50원, 10원이 무한정 있다고 가정)
*   **그리디(탐욕) 선택**: 지금 당장 집을 수 있는 가장 큰(가장 탐나는) 동전부터 집습니다!
    1. 500원짜리 1개 선택 (남은 돈: 360원)
    2. 100원짜리 3개 선택 (남은 돈: 60원)
    3. 50원짜리 1개 선택 (남은 돈: 10원)
    4. 10원짜리 1개 선택 (남은 돈: 0원)
*   **결과**: 총 6개의 동전. 이렇게 단위가 배수 관계일 때 탐욕 알고리즘은 항상 최고의 정답을 냅니다.
