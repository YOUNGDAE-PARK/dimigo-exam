# 🔌 제3특강: 디지털 논리 회로 및 컴퓨터 가산기 특강

> **"컴퓨터의 뇌(CPU) 속에서는 0과 1이 전깃줄을 타고 흐릅니다. 기본개념에서 배운 논리 게이트들이 복잡하게 연결된 회로를 만났을 때, 전선을 따라 신호를 추적하고 컴퓨터 덧셈기의 원리를 정복해 봅시다!"**

디미고 소질·적성검사의 컴퓨팅 사고력 영역에서는 하드웨어의 근본 동작 원리인 **복합 논리 회로(Composite Logic Circuit)**와 컴퓨터가 2진수 덧셈을 수행하는 핵심 장치인 **가산기(Adder)**에 관한 문제가 출제됩니다.

이 특강에서는 기본개념에서 익힌 논리 게이트들을 바탕으로, 시험지에 그려진 다단 회로를 1초의 망설임 없이 손으로 추적하는 방법과 **반가산기(Half Adder)** 및 **전가산기(Full Adder)**의 연결 구조를 완벽하게 마스터합니다.

---

## 1. 복합 논리 회로 다이어그램과 3단계 신호 추적법

시험지에 여러 개의 게이트가 거미줄처럼 얽혀 있는 복합 회로가 나오더라도 전혀 당황할 필요가 없습니다.

```
[A] ───┬──────── (AND) ─── [노드 X] ───┐
       │                                ├── (OR) ─── [최종 출력 OUT]
[B] ───┴── (NOT) ───────── [노드 Y] ───┘
```

### 💡 시험장에서 절대 틀리지 않는 3단계 행동 강령
1. **1단계: 입력단에 숫자 크게 적기** ➔ 입력단(A, B, C 등)에 주어진 0 또는 1을 연필로 전선 시작점에 크게 적습니다.
2. **2단계: 분기점 신호 복사하기** ➔ 전선이 갈라지는 분기점(검은 점 또는 교차점)에서는 동일한 0 또는 1의 신호가 양쪽 갈래 전선으로 그대로 복사되어 흘러갑니다. 갈라진 전선 위에도 숫자를 각각 적어둡니다.
3. **3단계: 중간 노드 값 기록하기** ➔ 각 게이트를 통과할 때마다 게이트 바로 뒤쪽 전선 위에 중간 결과값(노드 X, Y 등)을 적어놓습니다. 앞 단계의 계산 결과를 바탕으로 마지막 게이트까지 신호를 전달하면 최종 출력이 100% 정확하게 도출됩니다.

## 2. 신호 반전과 만능 게이트: NAND와 NOR 회로 분석

기본 4대 게이트(AND, OR, NOT, XOR) 외에, 게이트 끝에 작은 동그라미(NOT)가 붙어 출력을 반대로 뒤집는 반전 게이트들이 자주 출제됩니다.

### 💡 NAND 게이트 (NOT + AND)
* **기호**: AND 게이트(D 모양) 출력단 끝에 **작은 동그라미(O)**가 붙어 있습니다.
* **동작 규칙**: AND 연산 결과를 그대로 반대로 뒤집습니다.
  * 입력이 둘 다 1일 때만 출력은 **0**이 되고, 그 외에는 항상 **1**을 출력합니다.

### 💡 NOR 게이트 (NOT + OR)
* **기호**: OR 게이트(화살촉 모양) 출력단 끝에 **작은 동그라미(O)**가 붙어 있습니다.
* **동작 규칙**: OR 연산 결과를 그대로 반대로 뒤집습니다.
  * 입력 중 하나라도 1이면 출력은 **0**이 되고, 둘 다 0일 때만 **1**을 출력합니다.

> 📌 **상식 돋보기: 왜 반도체에서는 NAND를 좋아할까?**
> NAND 게이트는 **만능 게이트(Universal Gate)**라고 불립니다. 놀랍게도 NAND 게이트들만 적절히 연결하면 NOT, AND, OR, XOR 등 세상의 모든 논리 회로를 전부 만들어낼 수 있기 때문에, 실제 컴퓨터 메모리(NAND 플래시 메모리) 제조에 가장 핵심적으로 쓰입니다!

## 3. 컴퓨터의 2진수 덧셈기 1단계: 반가산기 (Half Adder)

컴퓨터가 어떻게 0과 1만으로 $1 + 1 = 2$라는 덧셈을 수행하는지 그 비밀을 담고 있는 회로입니다.

### 💡 1비트 2진수 덧셈의 4가지 경우
* $0 + 0 = 0$ ➔ **자리올림(Carry) 0, 합(Sum) 0**
* $0 + 1 = 1$ ➔ **자리올림(Carry) 0, 합(Sum) 1**
* $1 + 0 = 1$ ➔ **자리올림(Carry) 0, 합(Sum) 1**
* $1 + 1 = 10_{(2)}$ ➔ **자리올림(Carry) 1, 합(Sum) 0**

### 🎯 게이트와의 1:1 매칭 발견!
* **합(Sum)의 결과 (0, 1, 1, 0)**:
  * 입력 A와 B가 **서로 다를 때만 1**이 됩니다 ➔ **XOR 게이트**!
* **자리올림(Carry)의 결과 (0, 0, 0, 1)**:
  * 입력 A와 B가 **둘 다 1일 때만 1**이 됩니다 ➔ **AND 게이트**!

```
[입력 A] ──┬─────────────┬─── (XOR) ─── [합: Sum]
           │             │
[입력 B] ──┼──────┬──────┘
           │      │
           └──────┴────────── (AND) ─── [자리올림: Carry]
```

* **반가산기(Half Adder)의 정의**:
  * 1비트짜리 2진수 2개($A, B$)를 더하여 **합(Sum = $A \oplus B$)**과 **자리올림(Carry = $A \cdot B$)**을 만들어내는 회로입니다.
  * 아랫자리에서 올라오는 올림수를 받아들이지 못하고 자기들끼리만 더하기 때문에 '절반짜리 가산기(Half Adder)'라고 부릅니다.

## 4. 컴퓨터의 2진수 덧셈기 2단계: 전가산기 (Full Adder) 구조 맛보기

실제 여러 자릿수의 덧셈을 하려면, 아랫자리에서 올라온 **'받아올림수(Carry In, $C_{in}$)'**까지 포함해서 **총 3개의 1비트**를 한꺼번에 더할 수 있어야 합니다.

### 💡 전가산기의 블록 구조
전가산기는 복잡한 새 부품을 쓰는 것이 아니라, **반가산기 2개와 OR 게이트 1개**를 연결하여 완성합니다!

```
 [A] ──┐
       ├── [반가산기 1] ── (중간 Sum) ──┐
 [B] ──┘        │                       ├── [반가산기 2] ───▶ [최종 Sum]
           (Carry 1) ──┐                │
                       ├── (OR) ──▶ [최종 Carry]
 [Cin] ────────────────┼────────────────┘
                       │
                  (Carry 2)
```

* **전가산기의 계산 규칙 (3개 비트 더하기: $A + B + C_{in}$)**:
  * 1이 0개일 때: $0 + 0 + 0 = 0$ ➔ **Sum = 0, Carry = 0**
  * 1이 1개일 때: $1 + 0 + 0 = 1$ ➔ **Sum = 1, Carry = 0**
  * 1이 2개일 때: $1 + 1 + 0 = 10_{(2)}$ ➔ **Sum = 0, Carry = 1**
  * 1이 3개일 때: $1 + 1 + 1 = 11_{(2)}$ ➔ **Sum = 1, Carry = 1** (최고 빈출!)

## 5. 실전 킬러 연습문제

### [문제 1] 3단 복합 논리 회로의 신호 추적
다음과 같이 연결된 논리 회로가 있습니다.
* 세 개의 입력 신호는 각각 $A = 1, B = 0, C = 1$ 입니다.
* 입력 $A$와 $B$가 **XOR 게이트**로 들어갑니다. (출력 $X$)
* 입력 $B$가 **NOT 게이트**를 통과합니다. (출력 $Y$)
* 신호 $X$와 신호 $Y$가 **AND 게이트**로 들어갑니다. (출력 $Z$)
* 마지막으로 신호 $Z$와 입력 $C$가 **OR 게이트**로 들어가 최종 출력 $OUT$을 만듭니다.

최종 출력값 $OUT$은 0과 1 중 무엇일까요?

[해설]
3단계 신호 추적법에 따라 각 노드의 신호를 순서대로 구합니다.
1. 입력: $A = 1, B = 0, C = 1$
2. 노드 $X = A \text{ XOR } B$:
   * $1 \text{ XOR } 0 = 1$ (두 입력이 서로 다르므로 1)
3. 노드 $Y = \text{NOT } B$:
   * $\text{NOT } 0 = 1$
4. 노드 $Z = X \text{ AND } Y$:
   * $1 \text{ AND } 1 = 1$ (둘 다 1이므로 1)
5. 최종 $OUT = Z \text{ OR } C$:
   * $1 \text{ OR } 1 = 1$

[정답] **1**

### [문제 2] NAND 게이트 결합 회로 분석
어느 회로에 두 입력 $A = 1, B = 1$이 들어옵니다.
* 두 입력 $A$와 $B$가 먼저 **NAND 게이트**로 들어갑니다. (출력 $P$)
* 이 출력 $P$의 전선이 두 갈래로 나뉘어, 하나의 **NAND 게이트**의 두 입력단에 동시에 들어갑니다. (출력 $Q$)

최종 출력 $Q$의 값은 얼마일까요?

[해설]
1. 1단계: $P = A \text{ NAND } B$
   * $A = 1, B = 1$ 일 때, AND 결과는 1입니다.
   * NAND는 AND의 반대이므로 출력 $P = \mathbf{0}$ 입니다.
2. 2단계: 출력 $P(0)$가 두 갈래로 나뉘어 다음 NAND 게이트의 두 입력으로 동시에 들어갑니다.
   * 즉, 입력은 $(0, 0)$입니다.
   * $0 \text{ AND } 0 = 0$ 이므로, 이를 뒤집은 NAND의 최종 출력은 $Q = \mathbf{1}$ 입니다.
3. 💡 **보너스 통찰**: NAND 게이트의 두 입력을 하나로 묶으면 신호가 반전되는 **NOT 게이트**의 역할을 하게 됩니다! ($1 \rightarrow 0 \rightarrow 1$)

[정답] **1**

---

### [문제 3] 반가산기(Half Adder)의 입출력 신호 계산
반가산기 회로에 입력 $A = 1, B = 1$을 넣었을 때 생성되는 합(Sum)과 자리올림(Carry)의 값으로 올바른 묶음은 무엇일까요?

[해설]
반가산기는 2진수 덧셈 $1 + 1 = 10_{(2)}$을 수행합니다.
* 합(Sum) 출력:
  * $\text{Sum} = A \text{ XOR } B = 1 \text{ XOR } 1 = \mathbf{0}$
* 자리올림(Carry) 출력:
  * $\text{Carry} = A \text{ AND } B = 1 \text{ AND } 1 = \mathbf{1}$
* 따라서 합은 0, 올림수는 1입니다.

[정답] **Sum = 0, Carry = 1**

---

### [문제 4] 전가산기(Full Adder)의 3비트 덧셈
어느 전가산기(Full Adder)의 세 입력단에 다음과 같은 신호가 입력되었습니다.
* 첫 번째 비트 $A = 1$
* 두 번째 비트 $B = 1$
* 아랫자리에서 올라온 자리올림수 $C_{in} = 1$

이 전가산기가 덧셈을 완료한 후 내보내는 **최종 합(Sum)**과 **최종 자리올림(Carry)**의 값은 각각 얼마일까요?

[해설]
전가산기는 3개의 1비트 숫자들의 덧셈($A + B + C_{in}$)을 수행합니다.
* 10진수 덧셈: $1 + 1 + 1 = 3$
* 이를 2진수로 변환하면 $3 = 11_{(2)}$ 입니다.
* 따라서:
  * 1의 자리에 해당하는 **최종 합(Sum) = 1**
  * 2의 자리에 해당하는 **최종 자리올림(Carry) = 1**
* 3개의 입력이 모두 1일 때, 합과 자리올림 모두 1이 출력됩니다.

[정답] **Sum = 1, Carry = 1**
