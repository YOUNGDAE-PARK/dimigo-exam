# 🚀 [03_심화과정] 작성 표준 지침서 (README)

## 1. 폴더 목적 및 성격
* 기본개념(`02_기본개념/`)에서 학습한 기본 도구들을 융합하여, **디미고 100점 만점을 가르는 킬러 퍼즐과 실전 손추적(Hand-Tracing) 테크닉**을 집중 훈련하는 최상위 특강 단계입니다.
* 대학 전공 이론은 일절 배제하고, **중학교 3학년 눈높이의 비버챌린지(Bebras Challenge) 유형 퍼즐과 손풀이 알고리즘**에 100% 집중합니다.

## 2. 파일별 전담 영역 및 세부 수록 내용

### 📌 `01_비버챌린지_집중공략.md` (융합형 컴퓨팅 퍼즐 특강)
* **유한 상태 머신 (State Machine)**: 지하철 개찰구 비유, 사탕/음료 자판기 상태 전이 다이어그램 화살표 손추적.
* **그리디(탐욕) 최적화와 스케줄링**: 종료 시간이 가장 빠른 것부터 선택하는 Activity Selection 비법 (축제 부스/동아리 체험 최대 개수 선택).
* **데이터 표현과 흑백 도트 압축 (RLE)**: 런-랭스 인코딩 원리, 격자 도트 압축, 0으로 시작하는 단골 함정.
* **정보 보안과 규칙 암호 해독**: 알파벳 26자 표를 시험지 여백에 적고 푸는 카이사르(시저) 복호화.
* **실전 킬러 연습문제**: 4문항 (자판기 상태 추적, 부스 스케줄링, RLE 복원, 카이사르 암호).

### 📌 `02_정렬알고리즘_특강.md` (정렬 손추적 및 최소 Swap 퀴즈 특강)
* **손추적(Hand-Tracing) 원칙**: 대괄호 `[ ]` 그리기, 매 회전마다 자리가 확정된 원소에 밑줄/동그라미 치기.
* **버블 정렬 (Bubble Sort)**: 5개 원소 기준 Pass 1, 2, 3, 4 상태 변화 전수 추적.
* **선택 정렬 (Selection Sort)**: 최솟값 탐색 및 첫 자리 맞바꾸기(Swap) 단계별 추적, 실제 교환 발생 횟수 카운트.
* **삽입 정렬 (Insertion Sort)**: 손안의 카드 정리 비유, 정렬된 영역 끼워넣기 직관.
* **카드 최소 맞바꾸기(Swap) 퀴즈**: 사이클(Cycle) 분석 기법을 통한 최소 교환 횟수 ($N - \text{사이클 수}$) 도출.
* **업다운(Up-Down) 이진 탐색**: 100개 데이터도 최악 7번 만에 찾는 $2^k \ge N$ 거듭제곱 횟수 공식.
* **실전 킬러 연습문제**: 4문항 (버블 2회전 직후, 선택 실제 교환 횟수, 카드 5장 최소 Swap, 사전 단어 탐색).

### 📌 `03_필수_알고리즘_및_회로특강.md` (디지털 하드웨어 및 덧셈기 특강)
* **다단 복합 회로 신호 추적 3단계**: 입력단 숫자 크게 적기 ➔ 분기점 신호 복사 ➔ 중간 노드(X, Y, Z) 적고 최종 전구 점등 판별.
* **반전 게이트와 만능 게이트 (NAND, NOR)**: NAND/NOR 기호와 진리표, NAND로 NOT/AND 구현 원리 상식.
* **컴퓨터 2진 덧셈기 1단계: 반가산기 (Half Adder)**: $1+1=10_{(2)}$ 덧셈에서 합(Sum)은 XOR, 올림수(Carry)는 AND 매칭 1분 마스터.
* **컴퓨터 2진 덧셈기 2단계: 전가산기 (Full Adder)**: 아랫자리 올림수($C_{in}$)를 포함한 3비트 덧셈, "반가산기 2개 + OR 1개" 블록 구조.
* **실전 킬러 연습문제**: 4문항 (3단 복합 회로 추적, NAND 결합 회로, 반가산기 입출력, 전가산기 3비트 덧셈).

## 3. 절대 작성하지 말아야 할 내용 (금지 사항)
* ❌ **시험 운영 요령(`00_만점전략.md` 부활 금지)**: 1분 30초 룰, 30초 패스 룰은 `00_입시요강/`에만 둡니다.
* ❌ **기본개념 중복 작성 금지**:
  * 게이트 기초 진리표를 처음부터 다시 설명하지 말 것.
  * 참말/거짓말쟁이 퍼즐을 여기에 섞지 말 것 (`01_논리적추론` 전담).
  * 격자 최단경로 1, 1, 2, 3 덧셈을 여기에 넣지 말 것 (`02_이산수학` 전담).
* ❌ **대학 CS 전공 이론 금지**:
  * 퀵/병합 정렬 $O(N \log N)$ 분할 정복 수학적 증명
  * 님 게임(Nim Game)의 2진수 XOR 합 필승 공식
  * 허프만 트리 가변길이 인코딩 알고리즘
  * 카르노 맵 및 전가산기 복잡 게이트 수식 유도
