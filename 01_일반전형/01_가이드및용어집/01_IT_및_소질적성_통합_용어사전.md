## 🖥️ 제1편: 컴퓨터 시스템 및 데이터 인프라

### 1.1 컴퓨터 구조 4대 핵심

* **CPU (중앙처리장치, Central Processing Unit)**
  * **정의**: 컴퓨터의 **두뇌**에 해당하며, 모든 수리 연산(ALU)과 프로그램 명령어 해석 및 제어(Control Unit)를 총괄합니다.
  * **비유**: 식당 주방에서 주문을 받아 실제로 요리를 진두지휘하는 **총괄 셰프**.
  * **★ 100점 만점 출제 포인트**: CPU의 성능 척도로 클럭(GHz, 1초당 클럭 사이클 수)과 코어 수(멀티코어: 두뇌가 여러 개)가 지문에 등장할 수 있습니다.

* **RAM (주기억장치, Random Access Memory)**
  * **정의**: 실행 중인 프로그램과 현재 작업 중인 데이터를 일시적으로 올려두는 고속 메모리입니다. 전원이 차단되면 저장된 데이터가 모두 지워지는 **휘발성(Volatile)** 저장장치입니다.
  * **비유**: 요리사가 음식을 만들 때 재료를 올려놓는 넓은 **도마**. 도마가 넓을수록(RAM이 클수록) 여러 앱을 동시에 부드럽게 띄울 수 있습니다.
  * **★ 100점 만점 출제 포인트**: SSD/HDD와 RAM의 차이(속도 vs 휘발성 유무)를 묻는 지문이 자주 출제됩니다. "전원이 꺼져도 작업 내역이 유지된다"는 설명이 나오면 틀린 보기입니다.

* **SSD / HDD (보조기억장치, Storage)**
  * **정의**: 운영체제(OS), 설치 파일, 문서, 동영상 등을 영구적으로 저장하는 대용량 **비휘발성(Non-Volatile)** 장치입니다.
  * **비유**: 식당 안쪽에 있는 거대한 **식자재 보관 창고**.
  * **차이점**: 구형 HDD는 모터와 자기 디스크를 물리적으로 회전시켜 소음과 발열이 있고 충격에 약합니다. 반면 반도체 플래시 메모리를 사용하는 최신 SSD는 읽기/쓰기 속도가 수십 배 빠르고 충격에 강합니다.

* **ROM (롬, Read-Only Memory) 및 캐시 메모리(Cache)**
  * **ROM**: 기록된 데이터를 오직 읽기만 할 수 있으며, 전원이 꺼져도 지워지지 않습니다. 컴퓨터가 켜질 때 하드웨어를 초기 점검하고 부팅을 시작하는 기본 입출력 시스템(BIOS/UEFI)이 영구 탑재되어 있습니다.
  * **캐시 메모리(Cache)**: CPU 내부에 위치한 초고속 메모리로, CPU와 RAM 사이의 속도 차이 병목을 해소하기 위해 자주 쓰는 데이터를 미리 당겨와 보관합니다.

### 1.2 데이터 단위와 진법 변환

* **비트 (Bit, Binary Digit)**
  * **정의**: 컴퓨터가 데이터를 표현하는 **가장 작은 물리적 기본 단위**로, `0` 또는 `1`의 두 가지 상태만 가집니다.

* **바이트 (Byte)**
  * **정의**: 8개의 비트가 모인 묶음 단위입니다 (`1 Byte = 8 Bits`). 영문자 1자, 숫자 1자를 표현하는 데 보통 1바이트가 소요됩니다.

* **데이터 용량의 계층 단위**
  * **순서**: `Byte < KB(킬로) < MB(메가) < GB(기가) < TB(테라) < PB(페타)`
  * **변환 계산**: 컴퓨터는 2진법 체계이므로 매 단계마다 **1,024배(2¹⁰배)**씩 커집니다.
    * 1 KB = 1,024 Bytes
    * 1 MB = 1,024 KB
    * 1 GB = 1,024 MB
    * 1 TB = 1,024 GB
  * **★ 100점 만점 출제 포인트**: "1GB는 몇 Byte인가?"와 같은 거듭제곱 계산 문제 출제 시 $1,024 \times 1,024 \times 1,024 = 2^{30}$ Bytes임을 1초 만에 떠올릴 수 있어야 합니다.

* **진법 변환 (Base Conversion)**
  * **10진수(Decimal)**: 사람이 일상에서 쓰는 0~9 체계.
  * **2진수(Binary)**: 컴퓨터 회로가 사용하는 0과 1 체계.
  * **16진수(Hexadecimal)**: 2진수 4자리를 묶어 0~9와 A(10), B(11), C(12), D(13), E(14), F(15)로 표기하는 방식.
  * **★ 진법 변환 쾌속 공식**:
    * 2진수 `1101₂` = $1 \times 8 + 1 \times 4 + 0 \times 2 + 1 \times 1 = 13₁₀$
    * 16진수 `2F₁₆` = $2 \times 16 + 15 \times 1 = 47₁₀$
    * 2진수 ➔ 16진수: 뒤에서부터 4자리씩 끊어서 읽기 (`1111 0010₂` ➔ `F2₁₆`)

* **음수 표현과 2의 보수 (Two's Complement)**
  * 컴퓨터는 뺄셈 회로를 따로 두지 않고, 덧셈기 하나로 뺄셈을 처리하기 위해 **음수를 2의 보수**로 표현합니다.
  * **만드는 법**: 1) 모든 비트를 반전(0은 1로, 1은 0으로)시킨 뒤 2) 끝자리에 1을 더합니다.
  * **예시**: `+5 (0101₂)` ➔ 비트 반전 `1010₂` ➔ 1 더하기 ➔ `-5 (1011₂)`

* **비트 연산자 (Bitwise Operators)**
  * **비트 시프트 (`<<`, `>>`)**: 비트를 왼쪽으로 1칸 밀면(`X << 1`) 값이 2배($\times 2$)가 되고, 오른쪽으로 1칸 밀면(`X >> 1`) 값이 절반($\div 2$, 몫만 남음)이 됩니다.

### 1.3 네트워크와 인터넷 인프라

* **클라이언트-서버 모델 (Client-Server Architecture)**
  * **서버(Server)**: 네트워크를 통해 정보, 서비스, 데이터를 **제공(Serve)**하는 중앙 컴퓨터 시스템 (예: 유튜브 동영상 서버, 웹 서버).
  * **클라이언트(Client)**: 서버에 접속하여 데이터나 서비스를 **요청하고 소비(Customer)**하는 사용자의 기기나 프로그램 (예: 크롬 브라우저, 스마트폰 앱).

* **패킷 (Packet)**
  * **정의**: 인터넷에서 대용량 데이터를 한꺼번에 보내면 통신 회선이 마비되므로, 데이터를 작게 쪼개어 번호를 붙여 전송하는 **네트워크 전송의 기본 단위**입니다.
  * **구성**: 목적지 IP 주소와 출발지 정보가 담긴 **헤더(Header)** + 실제 전송 내용인 **데이터(Payload)** + 오류 검출 코드인 **트레일러(Trailer)**.

* **네트워크 핵심 장비 (Router, Switch, Hub, Gateway, Modem)**
  * **★ 라우터 (Router, 최빈출)**:
    * **정의**: 서로 다른 네트워크(예: 우리 집 LAN과 외부 인터넷 WAN)를 연결해 주는 장치입니다.
    * **핵심 역할**: 각 패킷의 목적지 IP 주소를 분석하여 목적지까지 가장 빠르고 효율적인 경로를 찾아 패킷을 건네주는 **'최적 경로 지정(Routing)'**을 수행합니다. (인터넷의 교통경찰)
    * **영문 지문 키워드**: `forwards data packets between computer networks`, `determines the best path`, `routing table`.
  * **스위치 (Switch / Switching Hub)**:
    * **정의**: 같은 네트워크(LAN) 안에서 여러 대의 컴퓨터를 연결해 주는 장치입니다.
    * **특징**: 단말기의 **MAC 주소**를 기억하여, 데이터를 받아야 할 특정 포트로만 똑똑하게 데이터를 전달합니다 (충돌 방지 및 대역폭 보존).
  * **허브 (Hub, 더미 허브)**:
    * **정의**: 스위치보다 단순한 구형 장비로, 한 포트에서 들어온 데이터를 목적지와 상관없이 **연결된 모든 컴퓨터 포트로 무차별 복사(Broadcast)**하여 뿌립니다. 네트워크에 불필요한 트래픽(체증)을 유발합니다.
  * **게이트웨이 (Gateway)**:
    * 서로 다른 통신 프로토콜(규약)이나 완전히 다른 구조를 사용하는 두 네트워크 사이를 이어주는 **'통역사 겸 관문'**입니다. (보통 라우터가 게이트웨이 역할을 겸합니다.)
  * **모뎀 (Modem, Modulator-Demodulator)**:
    * 전화선이나 광케이블로 들어오는 아날로그 통신 신호를 컴퓨터가 이해하는 0과 1의 **디지털 신호로 상호 변환**해 주는 장치입니다.
  * **NIC (Network Interface Card, 랜카드)**:
    * 컴퓨터 메인보드에 장착되어 케이블(유선) 또는 전파(무선)를 통해 실제 네트워크 신호를 주고받는 물리적 하드웨어 부품입니다.

* **IP 주소 vs MAC 주소**
  * **IP 주소 (논리적 주소)**: 통신망에서 위치에 따라 달라지는 소프트웨어적 주소 (IPv4: 32비트 숫자 예: `192.168.0.1`, IPv6: 128비트 차세대 주소). 이사 가면 바뀌는 **'주민등록상 집 주소'**에 해당합니다.
  * **MAC 주소 (물리적 주소)**: 전 세계 모든 랜카드(NIC) 제조 시 하드웨어 칩에 영구적으로 새겨지는 **'절대 중복되지 않는 고유 하드웨어 식별 번호 (지문)'**입니다 (예: `00:1A:2B:3C:4D:5E`).

* **LAN vs WAN**
  * **LAN (근거리 통신망, Local Area Network)**: 집, 학교, 한 건물 등 좁은 구역 내의 컴퓨터들을 연결한 고속 네트워크.
  * **WAN (광역 통신망, Wide Area Network)**: 도시, 국가, 전 세계를 연결하는 거대한 통신망 (인터넷이 대표적이며, LAN과 LAN을 라우터로 연결하여 구성).

* **도메인 네임 (Domain Name) 과 DNS (Domain Name System)**
  * 복잡한 숫자형 IP 주소(예: `142.250.196.110`)를 사람이 기억하기 쉬운 문자 형태(예: `google.com`)로 바꾼 것이 도메인 네임입니다.
  * **DNS 서버**: 사용자가 도메인 이름을 입력했을 때 이를 실제 통신용 IP 주소로 실시간 번역해 주는 **인터넷의 전화번호부**입니다.

* **HTTP 와 HTTPS**
  * **HTTP**: 웹 문서(HTML, 이미지 등)를 클라이언트와 서버가 주고받는 기본 규약(Protocol).
  * **HTTPS (HTTP Secure)**: 데이터 통신 구간을 암호화(SSL/TLS)하여 전송 도중 해커가 아이디나 비밀번호를 도청하지 못하게 방어하는 보안 프로토콜 (자물쇠 마크).

* **클라우드 컴퓨팅 (Cloud Computing)**
  * 기업이나 개인이 직접 서버 장비를 전산실에 구매해 두지 않고, 인터넷을 통해 대형 IT 기업(AWS, Google Cloud, Azure 등)의 서버, 저장소, 연산 능력을 **필요한 만큼 빌려 쓰고 쓴 만큼 요금을 지불**하는 기술 형태.

---

### 1.4 운영체제와 소프트웨어

* **운영체제 (OS, Operating System)**
  * CPU, 메모리, 하드디스크 등 복잡한 하드웨어를 직접 제어하고, 사용자가 프로그램을 편리하게 실행할 수 있도록 중재하는 **가장 핵심적인 시스템 소프트웨어** (Windows, macOS, Linux, Android, iOS).

* **오픈 소스 소프트웨어 (Open Source Software, OSS)**
  * 프로그램의 설계도인 **소스 코드(Source Code)를 모든 대중에게 공개**하여, 누구나 들여다보고 기능을 개선하며 자유롭게 재배포할 수 있게 만든 소프트웨어 생태계 (예: Linux, Python, VS Code).

* **컴파일러 (Compiler) vs 인터프리터 (Interpreter)**
  * **컴파일러**: 작성된 소스 코드 전체를 기계어로 한꺼번에 번역하여 독립된 실행 파일(`.exe`)을 생성함. 초기 번역 시간은 걸리지만 실행 속도가 매우 빠름 (C, C++, Rust).
  * **인터프리터**: 소스 코드를 위에서부터 한 줄씩 실시간으로 해석하면서 즉시 실행함. 실행 속도는 비교적 느리지만 수정과 테스트가 매우 유연함 (Python, JavaScript).
  * **★ 100점 만점 출제 포인트**: C언어와 파이썬의 번역 방식 차이를 묻는 문제가 소질적성 및 IT 지문에서 단골로 등장합니다.

## ⌨️ 제2편: 프로그래밍 및 컴퓨팅 사고력 기초

### 2.1 컴퓨팅 사고력의 4대 기둥 (Computational Thinking)

1. **문제 분해 (Decomposition)**: 크고 복잡한 문제를 혼자서 풀 수 있을 만큼 작고 다루기 쉬운 하위 문제들로 쪼개는 작업.
2. **패턴 인식 (Pattern Recognition)**: 쪼개진 문제들 사이에서 반복되는 규칙, 공통점, 유사성을 찾아내는 통찰력.
3. **추상화 (Abstraction)**: 문제 해결에 꼭 필요하지 않은 자질구레한 세부사항을 과감히 버리고, 핵심 원리와 데이터만 추출하는 작업 (예: 지하철 노선도).
4. **알고리즘 설계 (Algorithm Design)**: 주어진 문제를 단계별로 차례차례 따라 하면 누구나 똑같은 정답을 도출할 수 있도록 명확한 절차를 설계하는 능력.

---

### 2.2 변수, 상수, 데이터 교환 (SWAP)

* **변수 (Variable)**
  * 데이터를 임시로 담아두는 이름표가 붙은 메모리 공간. 프로그램 실행 도중 언제든 값이 바뀔 수 있습니다.
  * **대입 연산자 (`=`)**: 수학의 "같다"가 아니라, **오른쪽 값을 왼쪽 변수 상자에 집어넣어라(덮어쓰기)**는 명령입니다 (`A = A + 1`은 기존 A의 값에 1을 더해 다시 A에 저장).

* **상수 (Constant)**
  * 한 번 값을 지정하면 프로그램이 끝날 때까지 절대로 바꿀 수 없는 고정된 값 (예: 원주율 `PI = 3.141592`).

* **값의 교환 (SWAP 알고리즘)**
  * 두 변수 `A`와 `B`의 값을 맞바꾸려면 반드시 임시 저장소 `TEMP`가 필요합니다.
  ```text
  1단계: TEMP = A   (A의 값을 임시 변수에 피신시킴)
  2단계: A = B      (B의 값을 A에 덮어씀)
  3단계: B = TEMP   (피신시켜 둔 원래 A의 값을 B에 넣음)
  ```
  * **★ 함정 방지**: `TEMP` 없이 곧바로 `A = B; B = A;`를 실행하면 A의 기존 값이 영원히 유실되어 두 변수 모두 원래 B의 값으로 똑같아집니다.

---

### 2.3 제어 구조 (Control Structures)

모든 컴퓨터 프로그램은 다음의 **3대 제어 구조**의 조합으로 이루어집니다.
1. **순차 구조 (Sequence)**: 위에서 아래로 한 줄씩 차례대로 실행.
2. **선택/조건 구조 (Selection: `IF-ELSE`)**: 조건식이 참(True)인가 거짓(False)인가에 따라 실행 경로를 둘 중 하나로 분기.
3. **반복 구조 (Iteration: `FOR`, `WHILE`)**: 조건이 만족되는 동안 특정 코드 블록을 계속 되풀이 실행.
   * **`FOR` 문**: 반복 횟수가 명확할 때 주로 사용 (`1부터 10까지 1씩 증가`).
   * **`WHILE` 문**: 특정 종료 조건이 충족될 때까지 반복할 때 주로 사용 (`배터리가 10% 미만일 때까지 계속 경고`).
   * **`break`**: 반복문 루프를 즉시 강제 종료하고 탈출.
   * **`continue`**: 이번 차례의 남은 코드를 건너뛰고 다음 반복 회차로 즉시 넘어감.

---

### 2.4 함수와 데이터 흐름

* **함수 (Function)**: 반복되는 연산 절차를 묶어 이름을 붙여둔 재사용 가능한 코드 상자.
* **매개변수 (Parameter) 와 전달인자 (Argument)**:
  * **매개변수**: 함수를 정의할 때 외부 입력을 받아들이기 위해 선언한 변수 (투입구).
  * **전달인자**: 함수를 실제로 호출할 때 매개변수로 건네주는 실제 구체적인 값 (투입되는 재료).
* **반환값 (Return Value)**: 함수 내부 처리가 끝난 뒤 호출한 원래 위치로 돌려주는 최종 결과물.
* **지역변수 (Local) vs 전역변수 (Global)**:
  * **지역변수**: 함수 내부에서 선언되어 함수가 끝나면 메모리에서 사라지는 변수.
  * **전역변수**: 프로그램 전체에서 공유되는 변수.

---

### 2.5 오류와 디버깅

* **문법 오류 (Syntax Error)**: 프로그래밍 언어의 맞춤법(따옴표 누락, 철자 오타, 괄호 짝 불일치)을 어겨 컴파일 자체가 되지 않는 오류.
* **런타임 오류 (Runtime Error)**: 문법은 맞아서 실행은 되었으나, 실행 도중 비정상적인 상황(0으로 나누기, 존재하지 않는 파일 읽기, 메모리 초과)으로 인해 프로그램이 강제 다운되는 오류.
* **논리 오류 (Logic Error)**: 문법도 맞고 실행도 끝까지 정상 완료되지만, 프로그래머의 알고리즘 계산 착오로 인해 **엉뚱한 오답 결과가 출력되는 버그**. (가장 찾기 어렵고 소질적성검사 문제의 주된 테마)
* **디버깅 (Debugging)**: 소스 코드 속의 오류(버그)를 추적하여 정상 작동하도록 수정하는 작업.

## 🧩 제3편: 소질·적성검사 킬러 이론

### 3.1 논리적 추론과 부울 대수

* **명제 (Proposition)**
  * 참(True)과 거짓(False)을 객관적으로 명확하게 판별할 수 있는 문장.
  * 예: "15는 3의 배수이다." (참인 명제) / "이 게임은 매우 재미있다." (주관적이므로 명제 아님).

* **논리 게이트 (Logic Gates) 와 진리표 (Truth Table)**
  * **AND (논리곱)**: 입력이 **모두 1(참)**일 때만 출력이 1.
  * **OR (논리합)**: 입력 중 **하나라도 1**이면 출력이 1. (둘 다 0일 때만 0)
  * **NOT (논리부정)**: 입력을 반대로 뒤집음 (1 ➔ 0, 0 ➔ 1).
  * **XOR (배타적 논리합, Exclusive OR)**: 두 입력이 **서로 다를 때만 1**, 서로 같으면 0.
  * **NAND / NOR**: AND 및 OR의 결과를 각각 NOT으로 뒤집은 형태.

* **드모르간의 법칙 (De Morgan's Laws)**
  * $\text{NOT}(A \text{ AND } B) = (\text{NOT } A) \text{ OR } (\text{NOT } B)$
  * $\text{NOT}(A \text{ OR } B) = (\text{NOT } A) \text{ AND } (\text{NOT } B)$
  * **★ 실전 적용**: 조건문에서 `!(X >= 5 && Y < 10)`을 단순화하면 `(X < 5 || Y >= 10)`이 됩니다. 복잡한 조건 분기 문제의 필수 도구입니다.

* **역 (Converse), 이 (Inverse), 대우 (Contrapositive)**
  * 명제 $P \rightarrow Q$ ("$P$이면 $Q$이다") 에 대하여:
    * **역**: $Q \rightarrow P$
    * **이**: $\sim P \rightarrow \sim Q$
    * **대우**: $\sim Q \rightarrow \sim P$
  * **★ 핵심 절대 불변 법칙**: **원래 명제가 참이면 그 대우 명제는 무조건 참이다!** 원래 명제와 역/이는 참 거짓이 일치하지 않을 수 있으나, 대우 명제와는 완벽히 진리값이 일치합니다.

* **삼단논법 (Syllogism) 과 귀류법 (Proof by Contradiction)**
  * **삼단논법**: $A \rightarrow B$ 이고 $B \rightarrow C$ 이면, $A \rightarrow C$ 이다.
  * **귀류법**: 결론을 일부러 부정해 본 뒤, 논리를 전개하다가 **모순(Contradiction)**이 발생하는 것을 보여 최초 명제가 참임을 증명하는 기법. "거짓말쟁이 찾기 퍼즐"을 풀 때 특정 인물이 참말을 한다고 가정한 뒤 모순을 찾아내는 기법의 바탕입니다.

---

### 3.2 이산수학 및 카운팅 테크닉

* **합의 법칙 vs 곱의 법칙**
  * **합의 법칙**: 사건 A와 B가 **동시에 일어날 수 없을 때**, 경우의 수를 더함 ($A + B$).
  * **곱의 법칙**: 사건 A가 일어난 후 연이어 사건 B가 **동시에 또는 연속해서 일어날 때**, 경우의 수를 곱함 ($A \times B$).

* **순열 ($nPr$) 과 조합 ($nCr$)**
  * **순열 (Permutation)**: 서로 다른 $n$개 중 $r$개를 골라 **순서를 고려하여 일렬로 나열**하는 경우의 수.
    * 공식: $nPr = n \times (n-1) \times \cdots \times (n-r+1)$ (예: 5명 중 반장, 부반장 뽑기 = $5 \times 4 = 20$)
  * **조합 (Combination)**: 서로 다른 $n$개 중 **순서와 상관없이** 대표 $r$개를 뽑는 경우의 수.
    * 공식: $nCr = \frac{nPr}{r!}$ (예: 5명 중 대표 2명 뽑기 = $\frac{5 \times 4}{2 \times 1} = 10$)

* **비둘기집 원리 (Pigeonhole Principle)**
  * $n$개의 물건을 $m$개의 상자에 넣을 때, $n > m$ 이면 적어도 한 상자에는 2개 이상의 물건이 들어간다는 원리.
  * **★ 100점 만점 킬러 문제 패턴**: "서로 다른 색의 양말이 빨강 4켤레, 파랑 4켤레, 검정 4켤레 있을 때, 눈을 감고 최소 몇 짝을 꺼내야 반드시 같은 색 한 켤레(2짝)가 완성될까?"
    * 최악의 상황: 빨강 1짝, 파랑 1짝, 검정 1짝을 뽑는 경우 (3짝).
    * 여기에 1짝만 더 뽑으면(총 4짝) 비둘기집 원리에 의해 반드시 어떤 색이든 2짝이 일치하게 됨 ➔ 정답: 4짝.

---

### 3.3 그래프 이론과 트리

* **그래프 (Graph) 의 기본 구성 요소**
  * **정점 (Vertex / Node)**: 데이터를 담는 점.
  * **간선 (Edge)**: 정점들을 잇는 선.
  * **차수 (Degree)**: 한 정점에 연결되어 있는 간선의 개수.
  * **악수 정리(Handshaking Lemma)**: 모든 정점의 차수의 총합은 전체 간선 개수의 정확히 2배($2 \times E$)입니다. (따라서 차수가 홀수인 정점의 개수는 항상 짝수 개여야 합니다.)

* **오일러 경로 (한붓그리기, Eulerian Path)**
  * 연필을 종이에서 떼지 않고 모든 간선을 정확히 한 번씩만 지나서 전체 도형을 그릴 수 있는 경로.
  * **성립 조건**:
    1. **오일러 회로** (출발점으로 되돌아옴): 모든 정점의 차수가 **짝수**일 때.
    2. **오일러 경로** (출발점과 도착점이 다름): 차수가 **홀수인 정점이 정확히 2개**일 때 (그 2개가 각각 출발점과 도착점이 됨).

* **트리 (Tree) 의 핵심 성질**
  * 사이클(순환선)이 없는 연결 그래프입니다.
  * **정점의 수가 $V$개이면, 간선의 수는 반드시 $V - 1$개**입니다.
  * **루트 노드(Root)**: 최상위 시작 노드.
  * **리프 노드(Leaf)**: 자식 노드가 없는 최하위 말단 노드.
  * **이진 트리(Binary Tree)**: 모든 부모 노드가 최대 2개의 자식 노드만 가지는 트리.

---

### 3.4 핵심 자료구조

* **스택 (Stack: LIFO - Last In, First Out)**
  * 가장 나중에 들어간 데이터가 가장 먼저 나오는 구조 (후입선출).
  * 연산: `push` (데이터 넣기), `pop` (가장 위의 데이터 꺼내기).
  * **실제 활용**: 웹 브라우저 뒤로 가기, 편집기 실행 취소(Ctrl+Z), **수식의 괄호 짝 검사 `(()())`**.

* **큐 (Queue: FIFO - First In, First Out)**
  * 가장 먼저 들어간 데이터가 가장 먼저 나오는 구조 (선입선출).
  * 연산: `enqueue` (줄 뒤에 서기), `dequeue` (줄 맨 앞사람 나가기).
  * **실제 활용**: 프린터 인쇄 대기열, 은행 번호표 창구, 너비 우선 탐색(BFS).

* **재귀 함수 (Recursive Function) 와 콜스택**
  * 함수가 종료되지 않고 자기 자신을 다시 호출하여 문제를 해결하는 기법.
  * **필수 조건**: 무한 루프에 빠져 메모리가 터지는(Stack Overflow) 사태를 막기 위해, 호출을 멈추고 값을 반환하는 **기저 조건(Base Case / 탈출 조건)**이 반드시 맨 앞에 있어야 합니다.

### 3.5 알고리즘과 시간 복잡도

* **알고리즘의 5대 충족 조건**
  1. **입력(Input)**: 외부에서 제공되는 데이터가 0개 이상 존재해야 함.
  2. **출력(Output)**: 적어도 1개 이상의 명확한 결과를 내놓아야 함.
  3. **명확성(Definiteness)**: 각 명령어의 의미가 모호하지 않고 명확해야 함.
  4. **유한성(Finiteness)**: 유한한 횟수의 단계를 거친 후 반드시 스스로 종료되어야 함.
  5. **유효성(Effectiveness)**: 모든 명령은 컴퓨터가 실제로 수행 가능한 연산이어야 함.

* **순서도 (Flowchart) 주요 기호**
  * **타원**: 프로그램의 시작(Start)과 종료(End).
  * **직사각형**: 값의 대입 및 일반 계산 처리 (`SUM = SUM + I`).
  * **마름모**: 조건 판단 갈림길 (`I > 10 ?` ➔ 참/거짓 분기).
  * **평행사변형**: 데이터 입력 및 출력 (`READ A`, `PRINT SUM`).

* **시간 복잡도와 Big-O 표기법**
  * 데이터 입력 개수 $N$이 커질 때 연산 횟수가 증가하는 비율을 나타낸 지표입니다.
  * **속도 비교 (왼쪽이 가장 빠름)**:
    $$O(1) < O(\log N) < O(N) < O(N \log N) < O(N^2) < O(2^N)$$
  * $O(1)$: 상수 시간 (배열 인덱스 접근).
  * $O(\log N)$: 로그 시간 (이진 탐색: 100만 개도 약 20번 만에 탐색 완료).
  * $O(N)$: 선형 시간 (단일 반복문, 1부터 N까지 합).
  * $O(N^2)$: 2차 시간 (중첩 2중 반복문, 버블 정렬).

* **핵심 탐색 및 정렬 알고리즘 요약**
  * **선형 탐색(Linear Search)**: 1번부터 차례대로 확인. 정렬 불필요, $O(N)$.
  * **이진 탐색(Binary Search)**: **반드시 사전 정렬된 데이터**에서 중앙값을 비교하며 범위를 매번 절반씩 날림. $O(\log N)$.
  * **버블 정렬(Bubble Sort)**: 인접한 두 원소를 비교하며 큰 값을 뒤로 계속 밀어냄. $O(N^2)$.
  * **깊이 우선 탐색(DFS)**: 막다른 길이 나올 때까지 바닥 끝까지 깊게 파고듦. (스택/재귀 활용).
  * **너비 우선 탐색(BFS)**: 시작점에서 가까운 이웃부터 동심원 형태로 탐색. **최단 거리 탐색의 핵심** (큐 활용).
  * **백트래킹(Backtracking)**: 해를 찾아가다 조건이 맞지 않으면 즉시 직전 단계로 되돌아와 가지치기(Pruning)함 (N-Queen, 미로 탈출).

## 🛡️ 제4편: 정보 보안 및 최신 AI 테크 트렌드

### 4.1 정보 보안과 사이버 위협

* **해킹 (Hacking) 과 화이트해커 (White Hat Hacker)**
  * **블랙해커(크래커)**: 악의를 품고 타인의 전산망에 무단 침입하여 데이터를 탈취하거나 파괴하는 범죄자.
  * **화이트해커**: 보안 취약점을 미리 발견하여 패치하고 방어벽을 구축해 주는 착한 보안 전문가 (디미고 해킹방어과의 핵심 지향점).

* **악성코드 (Malware) 와 랜섬웨어 (Ransomware)**
  * **멀웨어(Malware)**: 시스템에 위해를 가하기 위해 악의적으로 제작된 모든 소프트웨어의 총칭 (바이러스, 웜, 트로이 목마, 스파이웨어 등).
  * **랜섬웨어(Ransomware)**: 시스템 파일들을 무단으로 암호화하여 열지 못하게 '인질'로 잡은 뒤, 암호 해독키를 대가로 금전(비트코인)을 협박 갈취하는 사이버 범죄.

* **피싱 (Phishing) 과 사회공학 (Social Engineering)**
  * 사람의 심리적 약점(공포, 호기심, 욕심)을 속여 가짜 웹사이트로 유도한 뒤 비밀번호나 금융 정보를 빼앗는 사기 기법 (스마트폰 문자를 악용한 것은 스미싱 Smishing).

* **방화벽 (Firewall) 과 DDoS (디도스 공격)**
  * **방화벽**: 허가되지 않은 외부의 불법 침입 패킷을 감시하고 차단하는 디지털 방어 성벽.
  * **DDoS (분산 서비스 거부 공격)**: 수많은 감염된 좀비 PC들을 동원하여 특정 서버에 동시 접속 폭탄을 퍼부음으로써 서버를 마비시키는 공격.

### 4.2 암호화 원리

* **대칭키 암호화 (Symmetric Encryption)**
  * 데이터를 암호화할 때 쓰는 열쇠와 복호화(풀기)할 때 쓰는 **열쇠가 동일한** 방식.
  * 장점: 속도가 매우 빠름.
  * 단점: 상대방에게 키를 안전하게 전달(키 배송 문제)하지 못하면 해커에게 탈취당할 위험이 있음. (예: AES)

* **공개키 / 비대칭키 암호화 (Public Key Encryption)**
  * 누구나 볼 수 있는 **공개키(Public Key)**로 잠그고, 오직 소유자만 가진 **개인키(Private Key)**로만 열 수 있는 한 쌍의 키 구조.
  * 장점: 비밀키를 네트워크로 전송할 필요가 없어 보안성이 극대화됨.
  * 단점: 수학적 계산이 복잡하여 대칭키에 비해 속도가 다소 느림. (예: RSA, HTTPS 통신의 핵심)

* **일방향 해시 함수 (One-way Hash Function)**
  * 어떤 길이의 데이터를 넣어도 고정된 길이의 암호화된 문자열로 뭉개버리며, **절대로 원래 데이터로 역산할 수 없는** 수학적 함수 (예: SHA-256).
  * 실제 활용: 사용자의 비밀번호를 서버 데이터베이스에 원문 그대로 저장하지 않고 해시값으로 저장하여, 서버가 털려도 비밀번호가 노출되지 않게 보호함.

### 4.3 최신 AI 및 신기술

* **인공지능 (AI) > 머신러닝 (ML) > 딥러닝 (DL) 의 포함 관계**
  * **인공지능(AI)**: 인간의 지능적 행동을 흉내 내는 가장 포괄적인 컴퓨터 기술.
  * **머신러닝(기계학습)**: 사람이 규칙을 일일이 짜주지 않고, 데이터에서 컴퓨터가 스스로 패턴을 학습하게 하는 방법.
  * **딥러닝(심층학습)**: 인간의 뇌 신경망 구조를 모방한 '인공신경망(ANN)'을 여러 겹 깊게 쌓아 고차원적인 패턴을 학습하는 최신 기법 (알파고, 자율주행).

* **생성형 AI (Generative AI) 와 LLM (거대 언어 모델)**
  * **생성형 AI**: 단순히 기존 데이터를 판별하는 것에 그치지 않고, 프롬프트 입력에 따라 글, 그림, 음악, 코딩을 새롭게 독창적으로 창작해 내는 AI (ChatGPT, Claude 등).
  * **LLM (Large Language Model)**: 수조 개의 웹 텍스트 데이터를 학습하여 인간의 언어를 유창하게 구사하고 추론하는 초대형 언어 모델.
  * **프롬프트 엔지니어링 (Prompt Engineering)**: 원하는 최적의 답변을 이끌어내기 위해 질문과 지시사항을 정교하고 논리적으로 설계하는 기법.

* **사물인터넷 (IoT, Internet of Things)**
  * 일상의 모든 전자기기(냉장고, 시계, 자동차 등)에 센서와 인터넷 통신 칩을 탑재하여 사람이 조작하지 않아도 사물끼리 데이터를 주고받으며 스마트하게 동작하는 네트워크.

* **빅데이터 (Big Data) 의 3V 특징**
  * **Volume (규모)**: 테라/페타바이트를 넘어서는 방대한 데이터양.
  * **Velocity (속도)**: 실시간으로 매우 빠르게 생성되고 유통됨.
  * **Variety (다양성)**: 정형 엑셀 데이터뿐 아니라 텍스트, 이미지, 음성, 영상 등 비정형 데이터가 혼재함.

## 💼 제5편: e-비즈니스 및 디지털 경영 상식

(※ e-비즈니스과 지망생 및 IT 비즈니스 상식 문항 대비)

### 5.1 전자상거래 모델 (E-Commerce)

* **B2B (Business to Business)**: 기업과 기업 간의 전자상거래 (부품 발주, 원자재 조달).
* **B2C (Business to Consumer)**: 기업이 일반 소비자에게 상품을 판매하는 형태 (쿠팡, 11번가, 네이버쇼핑).
* **C2C (Consumer to Consumer)**: 개인과 개인 간에 중고 물품을 직거래하는 플랫폼 (당근마켓, 중고나라, 번개장터).
* **D2C (Direct to Consumer)**: 중간 유통사나 쇼핑몰을 거치지 않고 제조업체가 자사 공식몰을 통해 소비자에게 직접 다이렉트로 판매하여 마진을 높이는 방식.

---

### 5.2 핀테크 (FinTech)

* **정의**: **금융(Finance)**과 **기술(Technology)**을 결합한 신조어.
* **혁신 사례**: 복잡한 공인인증서와 보안카드 대신 지문 인식이나 간편 비밀번호 하나로 몇 초 만에 송금과 결제를 끝내는 서비스 (토스, 카카오페이, 네이버페이, 애플페이).
* **비즈니스적 의의**: 온라인 쇼핑몰에서 결제 과정의 불편함을 없애 '구매 이탈률'을 획기적으로 낮추고 플랫폼 매출을 극대화하는 핵심 원동력입니다.

---

### 5.3 UI 와 UX 의 차이

* **UI (User Interface, 사용자 인터페이스)**
  * 사용자가 화면을 볼 때 마주하는 **시각적 요소들의 배치와 디자인** (버튼 모양, 색상, 글꼴 크기, 아이콘 디자인).
* **UX (User Experience, 사용자 경험)**
  * 사용자가 앱이나 웹 서비스를 이용하면서 시작부터 끝까지 느끼는 **편리함, 감정, 유용성, 만족감 등 총체적인 경험**.
  * **★ 핵심 요약**: UI는 '겉모습과 도구'이고, UX는 '사용자가 느끼는 총체적 만족감과 편리함'입니다. 화면이 아무리 세련되어도(좋은 UI) 버튼을 찾기 힘들고 결제가 5단계나 걸린다면 나쁜 UX가 됩니다.

---

### 5.4 플랫폼 비즈니스와 네트워크 효과

* **플랫폼 비즈니스 (Platform Business)**
  * 자신이 상품이나 인프라를 직접 소유하지 않고, **공급자(판매자/기사/집주인)와 수요자(소비자/승객/여행객)가 서로 만나 거래할 수 있는 디지털 온라인 장터를 연결해 주고 수수료를 얻는 사업 모델**.
  * 사례: 배달의민족(식당과 손님 연결), 에어비앤비(집주인과 여행자 연결), 우버(차량과 승객 연결).

* **네트워크 효과 (Network Effect) 와 락인(Lock-in) 효과**
  * **네트워크 효과**: 특정 플랫폼을 사용하는 이용자 수가 늘어날수록, 그 플랫폼의 가치가 다른 사람들에게도 덩달아 기하급수적으로 커지는 현상 (예: 모두가 카카오톡을 쓰기 때문에 나도 카카오톡을 쓸 수밖에 없음).
  * **락인(Lock-in, 자물쇠) 효과**: 기존 플랫폼에 저장된 친구 목록, 결제 정보, 적립 포인트 등에 익숙해져 다른 경쟁 서비스로 갈아타기 어렵게 묶어두는 현상.

## 🌐 제6편: [디미고 실전 특강] 영어 독해 지문 대비 IT 핵심 영문 정의 및 기출 유형

디미고 소질·적성검사의 큰 특징 중 하나는 **"영어 설명 지문을 제시하고, 이것이 설명하는 알맞은 IT/네트워크 장비나 개념을 고르는 문항"**이 반드시 출제된다는 점입니다. 이 유형은 단순 번역 능력이 아니라, **영어 기술 문맥 속 핵심 키워드(포워딩, 라우팅, 패킷, 암호화 등)를 포착하는 IT 소양**을 측정합니다.

---

### 6.1 12대 빈출 IT/네트워크 핵심 영문 정의 (Essential English Definitions)

실제 디미고 시험 지문에 그대로 등장하는 표준 기술 영문 정의입니다. 핵심 키워드를 눈에 익혀두세요!

1. **Router (라우터, ★최빈출)**
   * **영문 정의**: *"A networking device that forwards data packets between computer networks. It analyzes the destination IP address of each packet and determines the best and most efficient path (route) across the internet."*
   * **핵심 키워드**: `forwards data packets`, `between computer networks`, `determines the best path (routing)`, `destination IP address`.

2. **Switch (스위치)**
   * **영문 정의**: *"A networking device that connects multiple devices together on a local area network (LAN). It uses MAC addresses to forward data only to the specific intended destination device."*
   * **핵심 키워드**: `connects devices on a LAN`, `uses MAC addresses`, `specific destination device`.

3. **Hub (허브)**
   * **영문 정의**: *"A basic network hardware device for connecting multiple devices. Unlike a switch, it broadcasts all incoming data packets to every port, which can cause network collisions."*
   * **핵심 키워드**: `broadcasts to every port`, `simple/basic device`, `network collision`.

4. **Firewall (방화벽, ★최빈출)**
   * **영문 정의**: *"A network security device that monitors and filters incoming and outgoing network traffic based on predetermined security rules to block unauthorized access."*
   * **핵심 키워드**: `security device`, `monitors and filters traffic`, `predetermined rules`, `block unauthorized access`.

5. **Gateway (게이트웨이)**
   * **영문 정의**: *"A network node that connects two completely different networks using different protocols, acting as a translator between them."*
   * **핵심 키워드**: `connects two different networks`, `different protocols`, `translator / entry point`.

6. **Cache Memory (캐시 메모리)**
   * **영문 정의**: *"A small, high-speed volatile memory located close to the CPU that temporarily stores frequently accessed data and instructions to reduce latency."*
   * **핵심 키워드**: `high-speed memory`, `close to CPU`, `frequently accessed data`, `reduces latency`.

7. **Operating System (운영체제, OS)**
   * **영문 정의**: *"System software that manages computer hardware and software resources, providing common services and an interface for computer programs and users."*
   * **핵심 키워드**: `manages hardware and software`, `system software`, `interface for users`.

8. **Compiler vs Interpreter (컴파일러 vs 인터프리터)**
   * **Compiler**: *"A software program that translates entire source code written in a high-level programming language into machine code at once before execution."*
   * **Interpreter**: *"A program that directly executes instructions written in a programming language line by line without previously compiling them into machine code."*
   * **핵심 키워드**: Compiler(`translates entire code at once`), Interpreter(`executes line by line`).

9. **Ransomware (랜섬웨어, ★보안 빈출)**
   * **영문 정의**: *"A type of malicious software (malware) that encrypts a victim's files and demands a monetary ransom payment in exchange for the decryption key."*
   * **핵심 키워드**: `malicious software (malware)`, `encrypts files`, `demands ransom payment`, `decryption key`.

10. **Phishing (피싱)**
    * **영문 정의**: *"A social engineering attack where attackers disguise themselves as trustworthy entities in emails or messages to steal sensitive information such as passwords and credit card numbers."*
    * **핵심 키워드**: `social engineering`, `disguise as trustworthy entities`, `steal passwords / credit card numbers`.

11. **Cloud Computing (클라우드 컴퓨팅)**
    * **영문 정의**: *"The on-demand delivery of IT resources including computing power, storage, and databases over the internet with pay-as-you-go pricing."*
    * **핵심 키워드**: `on-demand delivery`, `over the internet`, `pay-as-you-go pricing`.

12. **Internet of Things (사물인터넷, IoT)**
    * **영문 정의**: *"A network of physical objects embedded with sensors, software, and connectivity that enables them to collect and exchange data over the internet without human intervention."*
    * **핵심 키워드**: `physical objects embedded with sensors`, `exchange data`, `without human intervention`.

### 6.2 디미고 실전 기출 스타일 맛보기 예제 3선

#### [기출 맛보기 1: 네트워크 장비]
**[문제]** 다음 영어 설명이 가리키는 네트워크 장치로 가장 알맞은 것은?

> *"This is a critical networking device that forwards data packets between different computer networks. When a packet arrives from one network, this device inspects the destination IP address in the packet header and uses its internal routing table to determine the best and fastest path to the next network."*

① Hub (허브)  
② Modem (모뎀)  
③ Router (라우터)  
④ Repeater (리피터)  

* **[정답]**: **③ Router (라우터)**
* **[해설 및 직독직해]**:
  * *"forwards data packets between different computer networks"* (서로 다른 컴퓨터 네트워크 간에 데이터 패킷을 전달함)
  * *"inspects the destination IP address"* (목적지 IP 주소를 검사함)
  * *"uses its routing table to determine the best and fastest path"* (라우팅 테이블을 사용해 가장 빠르고 최적의 경로를 결정함)
  * ➔ IP 주소를 기반으로 최적 경로를 설정(Routing)하여 패킷을 중계하는 장치는 오직 **Router (라우터)**뿐입니다!

#### [기출 맛보기 2: 정보 보안]
**[문제]** 다음 글에서 설명하고 있는 보안 시스템은 무엇입니까?

> *"In computer networking, this security mechanism acts as a barrier between a trusted internal network and an untrusted external network such as the Internet. It continuously monitors incoming and outgoing traffic, deciding whether to allow or block specific data packets based on a defined set of security rules."*

① Web Browser (웹 브라우저)  
② Firewall (방화벽)  
③ DNS Server (DNS 서버)  
④ Compiler (컴파일러)  

* **[정답]**: **② Firewall (방화벽)**
* **[해설 및 직독직해]**:
  * *"barrier between a trusted internal network and untrusted external network"* (신뢰할 수 있는 내부망과 신뢰할 수 없는 외부망 사이의 방어벽 역할을 함)
  * *"deciding whether to allow or block specific data packets based on a defined set of security rules"* (정의된 보안 규칙에 따라 특정 데이터 패킷을 허용할지 차단할지 결정함)
  * ➔ 허가되지 않은 불법 침입 트래픽을 감시·차단하는 장치는 **Firewall (방화벽)**입니다.

#### [기출 맛보기 3: 사이버 위협]
**[문제]** 다음 뉴스 기사 발췌문이 묘사하는 사이버 공격(악성코드) 유형은?

> *"A hospital computer system was paralyzed yesterday by a cyber attack. The attackers deployed malicious software that locked all patient records and diagnostic images using strong encryption algorithms. The cybercriminals left a text message on the screen demanding 50 Bitcoins in exchange for the decryption tool."*

① Phishing (피싱)  
② Ransomware (랜섬웨어)  
③ DDoS (디도스)  
④ Spyware (스파이웨어)  

* **[정답]**: **② Ransomware (랜섬웨어)**
* **[해설 및 직독직해]**:
  * *"locked all records using strong encryption algorithms"* (강력한 암호화 알고리즘을 사용해 모든 환자 기록을 잠가버림)
  * *"demanding 50 Bitcoins in exchange for the decryption tool"* (암호 해독 도구를 제공하는 대가로 50 비트코인을 요구함)
  * ➔ 데이터를 암호화하여 인질로 잡고 금전(몸값: Ransom)을 요구하는 악성코드는 **Ransomware (랜섬웨어)**입니다.
