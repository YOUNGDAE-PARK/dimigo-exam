### [논리적 추론 영역]

**1.** 다음 두 전제가 참일 때, 논리적으로 **반드시 참**인 결론은 무엇일까요?  
*   전제 1: 모든 프로그래머는 수학적 사고를 좋아한다.  
*   전제 2: 게임 개발을 좋아하는 어떤 학생은 프로그래머이다.  

① 모든 학생은 프로그래머이다.  
② 수학적 사고를 좋아하는 어떤 학생은 게임 개발을 좋아한다.  
③ 수학적 사고를 좋아하지 않는 학생도 프로그래머가 될 수 있다.  
④ 게임 개발을 좋아하는 모든 학생은 프로그래머이다.  

**2.** 세 학생 A, B, C 중 한 명은 참말만 하는 기사이고, 두 명은 거짓말만 하는 건달입니다. 세 사람이 다음과 같이 말했을 때, **진짜 기사(참말)**는 누구일까요?  
*   **A**: "B는 거짓말쟁이(건달)입니다."  
*   **B**: "C는 거짓말쟁이(건달)입니다."  
*   **C**: "A와 B는 둘 다 거짓말쟁이(건달)입니다."  

① A  
② B  
③ C  
④ 아무도 없다  

**3.** 철수, 영희, 민수, 수진 4명이 정보 올림피아드 모의시험을 보았습니다. 다음 점수 비교 결과를 보고 **점수가 가장 높은 학생**을 고르세요. (단, 동점자는 없습니다.)  
*   철수는 영희보다 점수가 높다.  
*   민수는 수진이보다 점수가 높지만, 영희보다는 점수가 낮다.  

① 철수  
② 영희  
③ 민수  
④ 수진  

**4.** 기숙사 101호, 102호, 103호, 104호가 일렬로 붙어 있습니다. 갑, 을, 병, 정 4명이 한 방에 한 명씩 들어가려고 합니다. 다음 조건을 만족할 때 **102호에 배정된 학생**은 누구일까요?  
*   갑은 가장 끝 방(101호 또는 104호)에 살지 않는다.  
*   을은 갑의 바로 옆 방에 산다.  
*   을은 병의 바로 옆 방에 산다.  
*   병은 104호에 산다.  
*   정은 101호에 산다.  

① 갑  
② 을  
③ 병  
④ 정  

**5.** "자연수 $X$가 6의 배수이다"라는 조건은 "자연수 $X$가 짝수(2의 배수)이다"라는 조건에 대해 어떤 조건일까요?  
① 충분조건  
② 필요조건  
③ 필요충분조건  
④ 아무 관련 없는 조건

② 17  
③ 19  
④ 21  

**7.** 아래 그림과 같은 바둑판 모양의 도로망이 있습니다. 좌측 하단 $A$ 지점에서 우측 상단 $B$ 지점까지 오른쪽 또는 위쪽으로만 이동하는 **최단 경로의 총 가짓수**는 몇 가지일까요? (가로 3칸, 세로 2칸)

```text
  ├─┼─┼─┤
A └─┴─┴─┘
```

② 8가지  
③ 10가지  
④ 12가지

② 목요일  
③ 금요일  
④ 토요일

② 9개

*   C언어를 다뤄본 학생: 15명  
*   두 언어 모두 다뤄본 적이 없는 학생: 4명  

**두 언어를 모두 다뤄본 학생**은 총 몇 명일까요?

### [컴퓨팅 사고력 영역]

**11.** 큐(Queue)는 먼저 들어간 데이터가 먼저 나오는 FIFO 구조입니다. 빈 큐에 `1, 2, 3`을 순서대로 넣은 뒤, 큐에서 2개의 데이터를 꺼내어 순서대로 스택(Stack)에 넣었습니다. 그 후 스택에서 데이터를 1개 꺼내면(Pop) 어떤 숫자가 나올까요?  
① 1  
② 2  
③ 3  
④ 꺼낼 데이터가 없다  

**12.** 오름차순 **선택 정렬(Selection Sort)**을 사용하여 배열 `[7, 2, 5, 3]` 을 정렬하려고 합니다. 전체 배열에서 최솟값을 찾아 맨 앞과 교환하는 **1회전(Pass 1)을 수행한 직후**의 배열 상태는 무엇일까요?  
① `[2, 7, 5, 3]`  
② `[2, 3, 5, 7]`  
③ `[7, 2, 3, 5]`  
④ `[3, 2, 5, 7]`  

**13.** 다음 재귀 함수(Recursive Function)를 호출했을 때, `F(4)`의 최종 반환(Return)값은 얼마일까요?  
```text
FUNCTION F(N) {
    IF (N <= 1) {
        RETURN 1
    }
    RETURN N + F(N - 1)
}
```
① 7  
② 10  
③ 12  
④ 15  

**14.** 아래와 같이 숫자가 저장된 **이진 탐색 트리(Binary Search Tree)**가 있습니다. 이 트리에서 숫자 **`28`**을 찾기 위해 루트 노드부터 거치게 되는 노드의 방문 순서로 올바른 것은?  
```text
          [35]
         ／    ＼
      [20]      [45]
     ／  ＼     ／  ＼
   [10]  [30] [40]  [50]
         ／
       [28]
```
① 35 → 20 → 30 → 28  
② 35 → 45 → 40 → 28  
③ 35 → 20 → 10 → 28  
④ 10 → 20 → 28 → 30  

**15.** 입력 데이터의 크기 N=1,000 일 때, **O(log N)** 알고리즘(예: 이진 탐색)과 **O(N)** 알고리즘(예: 선형 탐색)의 최악의 경우 연산 횟수 비율로 가장 적절한 것은? (단, 로그의 밑은 2입니다.)  
① 약 10번 vs 약 1,000번  
② 약 100번 vs 약 1,000번  
③ 약 3번 vs 약 1,000번  
④ 약 10번 vs 약 100만 번  

**16.** 논리 게이트 중 하나인 **XOR(배타적 논리합) 게이트**는 두 입력의 값이 서로 다를 때만 참(1)을 출력합니다. 두 입력이 A=1, B=1 일 때 XOR 게이트의 출력값은?  
① 0  
② 1  
③ 2  
④ 알 수 없음

```text
  G ·───·───·───·───·

    │   │   │   │   │

     (0,0)         (4,0)
```
