### [논리적 추론 영역]

**1.** 5명의 학생(A, B, C, D, E)이 달리기 시합을 했습니다. 다음 3개의 조건이 모두 참일 때, **3등을 한 학생**은 누구일까요? (동점자 없음)  
*   A는 B보다 빨랐습니다.  
*   C는 A보다 빨랐지만, E보다는 느렸습니다.  
*   D는 B보다 빨랐지만, A보다는 느렸습니다.  

① A  
② B  
③ C  
④ D  

**2.** 어느 학교에서 칠판에 장난을 친 용의자가 A, B, C 3명으로 좁혀졌습니다. **범인은 딱 1명**이고, **3명 모두 자기가 유리한 방향으로 진술**합니다. 다음 단서를 바탕으로 범인을 찾으세요.  
*   CCTV를 확인한 결과, **3명 중 정확히 1명만 거짓말**을 했습니다.  
*   **A**: "저는 범인이 아닙니다."  
*   **B**: "A가 범인입니다."  
*   **C**: "B가 범인입니다."  

① A  
② B  
③ C  
④ 알 수 없다  

**3.** 명제 **비가 오면 우산을 가져간다**가 참일 때, 다음 중 반드시 참인 것은?  
① 우산을 가져가면 비가 온다.  
② 비가 오지 않으면 우산을 가져가지 않는다.  
③ 우산을 가져가지 않았으면 비가 오지 않았다.  
④ 우산을 가져갔으므로 반드시 비가 왔다.  

**4.** 그림과 같이 4개의 스위치(S1~S4)가 직렬·병렬로 연결되어 있습니다. 전구에 불이 켜지려면 전류가 흐르는 통로가 존재해야 합니다. **전구에 불이 켜지지 않는** 경우는?  
```text
        S1       S3
  (+)──┤├──┬──┤├──(전구)
              │         │
              └──┤├──┘
                 S2
```
> (S1은 직렬, S2와 S3는 병렬로 연결)  
> 전류 경로: (+) → S1 → (S3 또는 S2) → 전구

① S1=ON, S2=ON, S3=OFF  
② S1=ON, S2=OFF, S3=ON  
③ S1=OFF, S2=ON, S3=ON  
④ S1=ON, S2=ON, S3=ON  

**5.** 아래 표에서 4명(A, B, C, D)이 각각 다른 하나의 과목(국어, 수학, 영어, 과학)을 가장 좋아합니다. 다음 힌트를 보고, **C가 가장 좋아하는 과목**을 찾으세요.  
```text
┌────┬────┬────┬────┬────┐
│    │국어│수학│영어│과학│
├────┼────┼────┼────┼────┤
│ A  │    │    │    │    │
├────┼────┼────┼────┼────┤
│ B  │    │    │    │    │
├────┼────┼────┼────┼────┤
│ C  │    │    │    │    │
├────┼────┼────┼────┼────┤
│ D  │    │    │    │    │
└────┴────┴────┴────┴────┘
```
*   A는 수학이나 과학을 좋아하지 않습니다.  
*   B는 영어를 좋아합니다.  
*   D는 국어를 좋아하지 않습니다.  
*   C는 수학을 좋아하지 않습니다.  

① 국어  
② 수학  
③ 영어  
④ 과학

③ 5

**13.** 오름차순 **삽입 정렬(Insertion Sort)**로 배열 `[6, 3, 8, 2]`를 정렬합니다. **2회전(Pass 2)까지 완료한 직후**의 배열 상태는 무엇일까요? (1회전: 두 번째 원소를 정렬된 부분에 삽입, 2회전: 세 번째 원소를 삽입)  
① `[3, 6, 8, 2]`  
② `[2, 3, 6, 8]`  
③ `[3, 8, 6, 2]`  
④ `[2, 3, 8, 6]`  

**14.** 다음은 입력된 수가 **소수(Prime Number)인지 판별**하는 의사코드입니다. **[빈칸]**에 들어갈 올바른 조건식은 무엇일까요?  
```text
INPUT N
IF (N < 2) {
    PRINT("소수 아님")
    STOP
}
I = 2
WHILE ( [빈칸] ) {
    IF (N을 I로 나눈 나머지가 0) {
        PRINT("소수 아님")
        STOP
    }
    I = I + 1
}
PRINT("소수임")
```
① I < N  
② I <= N  
③ I * I <= N  
④ I < N / 2

① 0  
② 1  
③ 알 수 없다  
④ 부정(Error)
