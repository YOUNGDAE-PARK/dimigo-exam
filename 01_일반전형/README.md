# 📘 일반전형(소질·적성평가) 교재 개발 및 작성 표준 지침서 (README)

이 문서는 **한국디지털미디어고등학교(디미고) 소질·적성검사** 대비 교재(`01_일반전형/`)를 집필하거나 수정할 때, **난이도 일관성 유지, 중복 작성 방지, 중3 눈높이 최적화**를 보장하기 위한 공식 개발 가이드라인입니다.

AI 에이전트(Antigravity)와 모든 교재 집필진은 본 가이드라인의 역할을 엄격히 준수하여 불필요한 반복 수정이나 내용 중복이 발생하지 않도록 해야 합니다.

## 🎯 1. 전체 3단계 계단식 학습 구조 및 역할 분담

일반전형 교재는 학생이 학습 피로감 없이 직관적으로 실력을 쌓을 수 있도록 **철저한 3단계 기능 분업(Separation of Concerns)**을 따릅니다.

│  • 컴퓨터 하드웨어, 네트워크(Router/Switch), 보안, 최신 기술 핵심 용어      │

## 🚫 2. 절대 중복 금지 매트릭스 (Zero-Duplication Matrix)

이전 집필 과정에서 자주 발생했던 아래 5대 중복 주제는 **지정된 전담 폴더에서만 작성**하며, 다른 폴더에서는 절대 재설명하거나 중복 문제를 수록하지 않습니다.

| 핵심 주제 | 전담 폴더 및 파일 | 타 폴더에서의 작성 금지 지침 |
| :--- | :--- | :--- |
| **시험장 시간 배분 및 스킵 요령**<br>(1분 30초 룰, 30초 패스 등) | `00_입시요강/일반전형/`<br>`01_소질적성검사_안내.md` | `01_일반전형` 내부의 어떤 파일에서도 메타 시험 전략을 중복 작성하지 않는다. (심화과정에 `00_만점전략` 부활 절대 금지) |
| **논리 게이트 기본 정의 및 진리표**<br>(AND, OR, NOT, XOR) | `02_기본개념/`<br>`01_논리적추론.md` | `03_심화과정`에서는 게이트 기본 정의를 다시 설명하지 않고, 곧바로 '복합 회로 신호 추적'과 '가산기'로 들어간다. |
| **참말쟁이 / 거짓말쟁이 논리 퍼즐**<br>(가정 검증법, 모순 도출) | `02_기본개념/`<br>`01_논리적추론.md` | `03_심화과정` 회로 특강에 참말/거짓말 퍼즐을 섞어 넣지 않는다. |
| **격자 도로망 최단 경로 덧셈**<br>(1, 1, 2, 3 합의 법칙) | `02_기본개념/`<br>`02_이산수학.md` | `03_심화과정/01_비버챌린지`에 격자 최단경로를 넣지 않는다. 비버챌린지는 '그리디 스케줄링'과 '오토마타'에 집중한다. |
| **정렬 알고리즘 회전별 상태 추적**<br>(버블, 선택, 삽입, Swap 횟수) | `03_심화과정/`<br>`02_정렬알고리즘_특강.md` | `02_기본개념/03_컴퓨팅사고력`에 정렬 알고리즘을 어설프게 섞지 않는다. 정렬의 모든 이론과 추적은 심화 특강으로 일원화한다. |

## ⚠️ 3. 대상 난이도 및 과도한 대학 전공 이론 배제 기준 (오버스펙 방지)

디미고 소질·적성검사는 **중학교 3학년** 학생을 대상으로 50분에 30문항(1문제당 1분 30초)을 풀게 하는 **순발력·직관력 타임어택 검사**입니다. 아래와 같은 **대학 컴퓨터공학(CS) 전공 이론이나 수능 고교 수학은 절대 수록하지 않습니다.**

### ❌ 절대 수록 금지 목록 (대학 전공 / 오버스펙):
1. **알고리즘 증명 및 고급 구조**:
   - 퀵 정렬/병합 정렬의 $O(N \log N)$ 수학적 분할 정복 증명 및 마스터 정리
   - 님 게임(Nim Game)의 그런디(Grundy) 수열 및 2진수 XOR 합 필승 공식
   - 허프만 트리 가변길이 인코딩 트리 구축 알고리즘
   - 다익스트라(Dijkstra) 우선순위 큐 구현
2. **복잡한 디지털 논리 설계**:
   - 카르노 맵(Karnaugh Map)을 이용한 부울식 최적화
   - 전가산기 게이트 레벨 수식 유도 및 캐리 룩어헤드(Carry Lookahead) 회로
   - 플립플롭(Flip-Flop)과 순차 논리 회로
3. **고교/수능 수학**:
   - 미적분, 행렬, 삼각함수, 벡터, 중복조합(nHr) 기호
4. **프로그래밍 실무**:
   - C언어 포인터 메모리 주소 연산, Linux 셸 명령어, Git 명령어, SQL 데이터베이스 쿼리

### ⭕ 적극 권장하는 실전 수록 내용:
* **손추적(Hand-Tracing)**: 머리로 풀지 않고 시험지 여백에 대괄호 `[ ]`, 화살표, 변수 추적표(Trace Table)를 직접 그려서 실수 없이 1분 30초 안에 풀어내는 훈련.
* **직관적 중학 비유**: 실생활 비유(지하철 개찰구, 카드 짝맞추기, 축제 부스 시간표, 편의점 동전 거스름돈 등)를 통한 개념 설명.

## 📝 4. 공통 작성 규칙 및 기호 표기 (AGENTS.md 준수)

1. **톤앤매너**: 경어체('~합니다', '~입니다'), 전문 강사가 중학생에게 1:1로 친절하게 설명하는 강의 어조.
2. **기호 표기**: 불필요한 LaTeX 원시 코드를 남발하지 않고 직관적인 유니코드(`O(1)`, `O(log N)`, `O(N²)`, `P → Q`, `≤`, `≥`, `×`, `÷`)를 적극 사용.
3. **내부 파일명 노출 금지**: 본문이나 해설에 `.md`, `01_문제지.md` 같은 내부 작업용 파일명을 절대 노출하지 말 것.
4. **문제 포맷**: 반드시 `### [문제 N]`, `[해설]`, `[정답]`을 명확히 구분하여 작성.
