# 💻 제3편: 컴퓨팅 사고력 (Computational Thinking)

> **"코딩 문법을 암기하는 시험이 아닙니다. 복잡하게 얽힌 순서도와 의사코드를 표를 그리며 끝까지 추적해 내는 끈기와 논리력이 핵심입니다!"**

디미고 일반전형 소질·적성검사의 컴퓨팅 사고력 영역은 중학교 정보 교과의 '문제 해결과 프로그래밍' 단원을 심화한 형태입니다. 가장 중요한 능력은 **컴퓨터의 입장이 되어, 코드가 한 줄 한 줄 실행될 때마다 변수(메모리) 안의 값이 어떻게 변하는지 빠르고 정확하게 추적(Tracing)하는 것**입니다.

---

## 1. 순서도 (Flowchart) 읽기와 분석

순서도는 알고리즘의 뼈대를 시각적으로 보여주는 지도입니다. 

### 💡 주요 표준 기호
*   **타원 (시작/종료)**: 프로그램의 출발점과 끝점입니다.
*   **직사각형 (처리/연산)**: 변수에 값을 넣거나 계산을 수행합니다. (예: `SUM = SUM + X`)
*   **마름모 (조건 판단)**: 예(Yes)/아니오(No)에 따라 갈림길이 나뉘는 분기점입니다. (예: `X > 10?`)
*   **평행사변형 (입출력)**: 데이터를 입력받거나 화면에 출력(PRINT)합니다.

---

## 2. 변수와 제어 구조 추적 (Tracing Algorithm)

가장 많이 출제되며 가장 배점이 높은 핵심 영역입니다. 눈으로만 풀면 무조건 실수합니다. 반드시 시험지 여백에 표(Trace Table)를 그리고 값을 지워가며 풀어야 합니다.

### 💡 1. 변수(Variable)와 대입 연산 (`=`)
*   컴퓨팅 사고력에서 `=`는 "같다"가 아닙니다. **"오른쪽의 계산 결과를 왼쪽 변수 상자에 집어넣어라(덮어쓰기)"**라는 뜻입니다.
*   예: `X = X + 1` ➔ "현재 X 값에 1을 더한 다음, 그 결과를 다시 X 상자에 넣어라."

### 💡 2. 의사코드(슈도코드) 다중 반복문 추적 훈련
실전에서는 반복문 안에 조건문이 있거나, 반복문 안에 또 반복문이 있는 형태가 자주 나옵니다.

**[실전 추적 예제]**
```text
X = 1
SUM = 0
WHILE (X <= 5) {
    IF (X가 짝수인가?) {
        SUM = SUM + X
    }
    X = X + 1
}
PRINT(SUM)
```
*   **추적 표 (Trace Table) 작성법**:
    | 반복 회차 | 현재 `X` | `X <= 5` (루프 유지?) | `IF (짝수?)` 조건 | 연산 수행 (`SUM`) | 다음 `X` (`X=X+1`) |
    | :---: | :---: | :---: | :---: | :---: | :---: |
    | 시작 전 | 1 | - | - | SUM = 0 | - |
    | 1회차 | 1 | 참 (1<=5) | 거짓 (홀수) | 변동 없음 (SUM=0) | X = 2 |
    | 2회차 | 2 | 참 (2<=5) | **참 (짝수)** | SUM = 0 + 2 = **2** | X = 3 |
    | 3회차 | 3 | 참 (3<=5) | 거짓 (홀수) | 변동 없음 (SUM=2) | X = 4 |
    | 4회차 | 4 | 참 (4<=5) | **참 (짝수)** | SUM = 2 + 4 = **6** | X = 5 |
    | 5회차 | 5 | 참 (5<=5) | 거짓 (홀수) | 변동 없음 (SUM=6) | X = 6 |
    | 6회차 | 6 | **거짓 (6<=5) ➔ 종료** | - | - | - |
*   **결과**: 루프 탈출 후 `PRINT(SUM)` 실행 시 **`6`**이 출력됩니다. (즉, 이 코드는 5 이하의 짝수만 골라서 더하는 알고리즘입니다.)

## 3. 블랙박스 규칙 추론 (함수와 패턴)

입력값과 출력값의 관계표를 보고, 숨겨진 함수 기계(블랙박스)의 규칙을 수식으로 찾아내는 퍼즐입니다.

### 💡 1. 규칙 찾기 비법
| 입력 ($x$) | 출력 ($y$) | 규칙 분석 (힌트 찾기) |
| :---: | :---: | :--- |
| **2** | **5** | 2배 하면 4 ➔ 1이 부족함 (+1) |
| **4** | **9** | 4배 하면 8 ➔ 1이 부족함 (+1) |
| **6** | **13** | 6배 하면 12 ➔ 1이 부족함 (+1) |
| **9** | **?** | $y = 2x + 1$ 규칙 성립! 정답은 19. |

*   **변화율 관찰**: 입력 $x$가 2 커질 때 출력 $y$가 4 커졌습니다. 즉 기울기가 2배이므로 곱하기 2($2x$)를 먼저 의심합니다.
*   **보정값 더하기/빼기**: 곱하기만으로 맞지 않는 차이를 더하거나 빼서 최종 수식을 완성합니다.

## 4. 격자 시뮬레이션 (2D Grid & 로봇 제어)

바둑판 모양의 격자에서 로봇청소기나 캐릭터를 명령(명령어 문자열이나 반복문)에 따라 이동시킨 후 최종 위치를 찾는 문제입니다.

### 💡 1. 2차원 좌표와 방향의 이해
*   로봇이 (X, Y)에 있고 **동쪽**을 바라본다고 가정합시다.
    *   **전진(F)**: X 좌표가 1 증가 ➔ (X+1, Y)
    *   **좌회전(L)**: 바라보는 방향이 동쪽 ➔ 북쪽으로 바뀜 (이동은 안 함)
    *   **우회전(R)**: 바라보는 방향이 동쪽 ➔ 남쪽으로 바뀜 (이동은 안 함)
*   좌회전/우회전 규칙:
    *   오른쪽 회전(R): 북 ➔ 동 ➔ 남 ➔ 서 ➔ 북
    *   왼쪽 회전(L): 북 ➔ 서 ➔ 남 ➔ 동 ➔ 북

### 💡 2. 실전 적용 팁
*   이 문제 역시 머릿속으로 상상하면 헷갈립니다. 문제지 옆 빈 공간에 **십자가 좌표계(동서남북)**를 그리고, 로봇의 현재 머리 방향을 화살표로 그려가며 한 단계씩 지워나가야 절대 틀리지 않습니다.

## ✍️ 단원 마무리 실전 퀴즈

**[문제 1]**
다음 의사코드의 실행 결과로 화면에 출력되는 `A`의 값은 얼마입니까?
```text
A = 10
B = 20
TEMP = A
A = B
B = TEMP
PRINT(A)
```
① 10
② 20
③ 30
④ 알 수 없다.

**[문제 2]**
로봇이 (0, 0) 위치에서 동쪽을 바라보고 있습니다. 다음 명령어를 순서대로 실행한 후 로봇의 최종 좌표는?
(단, `F`는 1칸 전진, `L`은 왼쪽으로 90도 회전, `R`은 오른쪽으로 90도 회전입니다.)
> 명령어: `F - F - L - F - R - F`

① (3, 1)
② (2, 2)
③ (1, 3)
④ (3, -1)

---

### 🎯 퀴즈 정답 및 해설

**[문제 1 정답] ②**
- 전형적인 변수 값 교환(SWAP) 알고리즘입니다. `TEMP`라는 빈 상자를 이용하여 A와 B의 값을 안전하게 맞바꿉니다. 실행이 끝나면 A에는 20, B에는 10이 저장되므로 `PRINT(A)`는 20입니다.

**[문제 2 정답] ①**
- 시작: (0,0), 방향: 동
- `F` ➔ (1,0), 방향: 동
- `F` ➔ (2,0), 방향: 동
- `L` ➔ (2,0), 방향: 북 (회전만 함)
- `F` ➔ (2,1), 방향: 북
- `R` ➔ (2,1), 방향: 동 (회전만 함)
- `F` ➔ (3,1), 방향: 동
- 최종 좌표는 **(3, 1)**입니다.
