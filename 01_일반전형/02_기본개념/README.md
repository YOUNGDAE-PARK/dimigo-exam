# 🔢 [02_기본개념] 작성 표준 지침서 (README)

## 1. 폴더 목적 및 성격
* 디미고 소질·적성검사의 3대 평가 영역(**논리적 추론, 이산수학, 컴퓨팅 사고력**)에 필요한 **교과 기초 이론, 수학적 공식, 기본 알고리즘/자료구조 도구**를 완벽히 습득하는 단계입니다.
* 중학교 교육과정 수준을 기반으로 하되, 실제 시험에 즉시 적용 가능한 계산 공식과 도해 기법을 전수합니다.

## 2. 파일별 전담 영역 및 세부 수록 내용

### 📌 `01_논리적추론.md` (논리적 추론 영역)
* **부울 대수 기초**: AND, OR, NOT, XOR 기본 기호 및 2개 입력 진리표, 드모르간 법칙($\sim(P \land Q) \equiv \sim P \lor \sim Q$).
* **조건 명제와 추론**: 조건명제($P \rightarrow Q$)와 역·이·대우, 대우 명제의 절대적 참, 징검다리 삼단논법.
* **참말/거짓말쟁이 퍼즐**: 가정 검증법(귀류법), 1명만 거짓말할 때의 상호 모순 포착 알고리즘.
* **2차원 그리드 소거법**: 이름-방-동아리 다차원 매칭 표 채우기.
* **★ 빈출 킬러: Wason 선택 과제**: "모음 뒤는 짝수" 규칙에서 대우 논리를 이용한 카드 뒤집기 검증.
* **실전 연습문제**: 4문항 (단계별 상세 해설 및 오답 함정 분석).

### 📌 `02_이산수학.md` (수리 추론 영역)
* **진법 변환과 표현**: 2진수 ➔ 10진수 ➔ 16진수 상호 변환(4비트 묶음법), 컴퓨터 음수 표현 **2의 보수(Two's Complement)**, 비트 시프트(`<<`, `>>`).
* **경우의 수와 조합론**: 합의 법칙과 곱의 법칙, 순열($nPr$), 조합($nCr$), 악수 횟수 공식($\frac{N(N-1)}{2}$).
* **비둘기집 원리**: 색깔 양말/공 뽑기에서 "반드시 한 쌍을 완성하는 최악의 경우(Worst-case)" 계산법.
* **그래프와 한붓그리기**: 악수 정리(차수의 합은 간선 수의 2배), 오일러 경로(홀수점 0개 또는 2개).
* **격자 도로망 최단 경로**: 합의 법칙(1, 1, 2, 3 덧셈)을 이용한 꼭짓점 숫자 누적 계산법 (장애물 우회 포함).
* **트리의 성질**: 간선 개수 공식($E = V - 1$), 포화 이진 트리 노드 수 공식($2^k - 1$).
* **실전 연습문제**: 4문항 (단계별 수식 풀이 해설).

### 📌 `03_컴퓨팅사고력.md` (컴퓨팅 사고력 영역)
* **순서도 (Flowchart)**: 표준 기호 판독, 대입 연산자(`=`), 값 교환(SWAP with TEMP).
* **변수와 다중 제어 구조**: 2중 중첩 루프(Nested Loop) 변수 추적표(Trace Table) 작성법.
* **블랙박스 함수 추론**: 입출력 표에서 기울기와 상수를 찾는 패턴 분석.
* **핵심 자료구조**: 스택(LIFO, 괄호 쌍 검사, 뒤로 가기) vs 큐(FIFO, 대기열, 프린터 버퍼).
* **재귀 함수와 콜스택**: 기저 조건(Base Case), 팩토리얼($N!$) 역추적.
* **시간 복잡도와 Big-O**: $O(1) < O(\log N) < O(N) < O(N^2)$ 비교, 이진 탐색 거듭제곱 비교 횟수 공식.
* **2D 바둑판 격자 로봇**: 방향 벡터(동서남북) 및 우회전/좌회전 시뮬레이션.
* **실전 연습문제**: 4문항 (Trace Table 전수 수록 해설).
