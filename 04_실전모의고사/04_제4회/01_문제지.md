### [논리적 추론 영역]

**1.** A, B, C, D 네 명의 학생이 프로그래밍 대회에 참가했습니다. 순위에 대해 각자 다음과 같이 진술했으며, **딱 1명만 거짓말**을 하고 있습니다. 1등은 누구일까요? (동점자 없음)  
*   **A**: "B는 1등이 아닙니다."  
*   **B**: "C가 1등입니다."  
*   **C**: "저는 2등입니다."  
*   **D**: "A가 1등입니다."  

① A  
② B  
③ C  
④ D  

**2.** 5명의 학생(가, 나, 다, 라, 마)이 일렬로 의자에 앉으려고 합니다. 다음 **3가지 조건**을 모두 만족할 때, **가능한 배치에서 3번째 자리에 앉을 수 있는 학생**은 누구일까요?  
*   '가'는 반드시 맨 앞(1번째)에 앉습니다.  
*   '다'는 '나' 바로 뒤(오른쪽)에 앉습니다.  
*   '마'는 5번째(맨 끝)에 앉습니다.  
*   '라'는 2번째에 앉지 않습니다.  

① 나  
② 다  
③ 라  
④ 마  

**3.** 다음 세 개의 명제가 모두 참일 때, 반드시 참인 결론은 무엇일까요?  
*   전제 1: 코딩을 잘하는 학생은 수학 성적이 좋다.  
*   전제 2: 수학 성적이 좋은 학생은 디미고에 지원한다.  
*   전제 3: 민수는 코딩을 잘하는 학생이다.  

① 디미고에 지원하는 모든 학생은 코딩을 잘한다.  
② 민수는 디미고에 지원한다.  
③ 수학 성적이 좋으면 반드시 코딩을 잘한다.  
④ 코딩을 못하는 학생은 디미고에 지원하지 않는다.  

**4.** 논리곱(AND), 논리합(OR)에 관한 드모르간의 법칙에 따르면, 명제 **"A이고 B이다"의 부정**으로 올바른 것은?  
① A가 아니고 B가 아니다  
② A가 아니거나 B가 아니다  
③ A이고 B가 아니다  
④ A이거나 B가 아니다  

**5.** 동물원에 호랑이, 사자, 곰, 독수리 4마리를 배치하려고 합니다. 네 칸짜리 우리의 구조는 아래와 같습니다.  
```text
┌───┬───┐
│ ① │ ② │
├───┼───┤
│ ③ │ ④ │
└───┴───┘
```
다음 조건을 모두 만족할 때, **②번 우리에 들어가는 동물**은?  
*   호랑이는 사자와 상하좌우로 인접하지 않습니다.  
*   곰은 ③번 우리에 있습니다.  
*   독수리는 사자보다 위쪽 줄에 있습니다.  

① 호랑이  
② 사자  
③ 곰  
④ 독수리

### [컴퓨팅 사고력 영역]

**11.** 아래 순서도(Flowchart)를 따라 실행했을 때, 최종 출력되는 `결과`의 값은 무엇일까요?

```text
          [시작]
            │
        ┌───▼───┐
        │ A = 3  │
        │ B = 1  │
        │결과 = 0│
        └───┬───┘
            │
    ┌───→┌───▼───┐    아니오
    │   │ A > 0 ?├──────────┐
    │   └───┬───┘          │
    │       │ 예            │
    │   ┌───▼──────┐       │
    │   │결과 = 결과│       │
    │   │   + B    │       │
    │   │ B = B + 2│       │
    │   │ A = A - 1│       │
    │   └───┬──────┘       │
    │       │              │
    └───────┘              │
                    ┌──────▼──────┐
                    │ 결과를 출력  │
                    └─────────────┘
```

① 6  
② 9  
③ 12  
④ 15  

**12.** 다음은 세 수 X, Y, Z 중 **가장 큰 값**을 찾아 출력하는 의사코드입니다. **[빈칸]** 에 들어갈 올바른 조건식은 무엇일까요?  
```text
X = 10, Y = 25, Z = 17

MAX = X
IF (Y > MAX) {
    MAX = Y
}
IF ( [빈칸] ) {
    MAX = Z
}
PRINT(MAX)
```
① Z > X  
② Z > Y  
③ Z > MAX  
④ Z > X + Y  

**13.** 빈 큐(Queue, FIFO)에 아래 연산을 순서대로 수행했을 때, **큐에 남아 있는 데이터를 앞(Front)에서부터 순서대로** 나열한 것은?  
> `ENQ(A)` → `ENQ(B)` → `DEQ()` → `ENQ(C)` → `ENQ(D)` → `DEQ()` → `ENQ(E)`

① B, D, E  
② C, D, E  
③ A, C, E  
④ D, E  

**14.** 컴퓨터에서 아래와 같은 논리 회로에 입력값 $A=1$, $B=1$, $C=0$을 넣을 때, 최종 출력 $Y$의 값은 무엇일까요?

```text
  A ──┐
      ├─ [AND] ─── X ──┐
  B ──┘                 ├─ [OR] ─── Y
  C ────────────────────┘
```
> (A와 B를 AND 게이트에 넣어 X를 만든 뒤, X와 C를 OR 게이트에 넣어 Y를 출력)

① 0  
② 1  
③ 2  
④ 알 수 없다  

**15.** 다음 의사코드에는 **논리적 오류**가 1개 있습니다. 1부터 10까지의 **홀수만** 모두 더하는 것이 목적인데, 실행하면 의도와 다른 결과가 나옵니다. **오류가 있는 줄(Line)**은 몇 번째일까요?

④ Line 5
