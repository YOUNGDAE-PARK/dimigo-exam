🎤 [교사 인터뷰 실전 가이드] 스쿨배틀 시연 및 교사 피드백 확보 계획

목적: 디미고 특별전형 제출 서류(실적설명서, 교사추천서)와 심층면접의 신뢰도를 결정짓는 '실제 교사 피드백 경험'을 확보하는 실전 가이드
시기: 2학기 중간고사 기간 전 이번 주 중(월~금)에 즉시 실행
핵심 원칙: 윤하가 직접 말하고, 직접 시연하고, 직접 메모한다. 아빠는 사전 코칭과 기기 세팅만 지원.

🧭 1. 왜 교사 인터뷰가 반드시 필요한가

① 교사추천서의 진정성 확보

  • 특별전형 필수 제출 서류에 교사추천서 1부가 포함됩니다.
  • 담임 또는 교과 선생님이 스쿨배틀을 직접 보신 적이 있어야 추천서에 구체적이고 진정성 있는 내용을 작성해 주실 수 있습니다.
  • 한 번도 안 보신 프로젝트를 추천서에 적어달라고 하면 선생님도 난감해하시며, 형식적인 추천서가 될 수밖에 없습니다.

② 윤하의 '진짜 경험' 축적

  • 선생님이 실제로 해주신 코멘트 한 문장이, 면접장에서 "실제로 선생님께 보여드렸더니..."이라고 정직하게 답할 수 있는 황금 같은 근거가 됩니다.
  • "세특 자동 생성이 되면 좋겠다"든, "교과서 저작권을 고려해야 한다"든, 선생님의 날것 그대로의 반응이 윤하의 기획자로서의 깊이를 만들어 줍니다.

③ 실적설명서 및 면접 답변에 '검증된 사실'을 추가 가능

  • 인터뷰 후, 실적설명서의 '자체 기획 검증' 섹션에 "교과 선생님께 시연 후 받은 실제 조언"을 사실 기반으로 추가할 수 있습니다.
  • 허구가 아닌 팩트이므로 심층면접에서 어떤 꼬리 질문이 와도 당당합니다.

🎯 2. 인터뷰 대상 선생님 우선순위

순위 대상 이유 기대 효과
1순위 정보 교과 선생님 (2학년 세특 작성 교사) 파이썬/데이터 분석 세특을 직접 작성해 주신 분 → 윤하의 기술적 성장을 가장 잘 아심 추천서에 "수업에서 배운 역량을 실제 서비스 기획으로 확장한 학생"이라고 적어주실 가능성 높음
2순위 담임 선생님 교사추천서 작성 권한이 있는 가장 현실적인 대상 추천서 작성을 공식 요청하는 자리를 겸할 수 있음
3순위 수학 교과 선생님 수학 93→98점 우상향의 근거를 아시는 분 "수학적 사고력을 기획에 접목한 학생"이라는 추천 포인트 확보

현실적 권장: 1순위 + 2순위 두 분에게 각각 시연하는 것이 최선. 시간이 부족하면 담임 선생님 1분만이라도 반드시 실행.

📋 3. 인터뷰 사전 준비 체크리스트

아빠의 사전 세팅 (인터뷰 전날까지)

  • battle-study 로컬 실행 환경을 노트북에 세팅 (WiFi 없이도 시연 가능한 상태)
  • 학생용 배틀 화면 → 오답 던전 → 교사용 대시보드 순서로 시연 동선 확인
  • AI 출제 기능이 동작하는 화면 캡처 또는 목업 준비 (API 키 만료 시 대비)

윤하의 사전 연습 (인터뷰 전날)

  • 아빠 앞에서 3분간 소리 내어 시연 해설 리허설 1회 완료
  • 선생님께 드릴 말씀(아래 대본) 3회 읽기 연습
  • 메모 수첩 또는 스마트폰 메모장 준비 (선생님 말씀 즉시 기록용)

🎙️ 4. 인터뷰 실전 진행 시나리오 (약 10~15분)

Step 1. 인사 및 요청 (1~2분)

윤하가 직접 선생님께 말합니다. 자연스러운 대화체로 연습시켜 주세요.

윤하: "선생님, 안녕하세요. 저 디미고 e-비즈니스과 특별전형을 준비하고 있는데요, 학생들이 게임처럼 퀴즈를 풀면서 공부하는 교육 플랫폼을 기획하고 프로토타입까지 만들어봤거든요. 선생님 입장에서 이런 기능이 실제 수업에 도움이 될지, 또 어떤 점을 더 보완하면 좋을지 솔직한 의견을 들어보고 싶어서요. 혹시 5~10분만 화면 보여드려도 될까요?"

Step 2. 화면 시연 (3~5분)

노트북을 선생님 앞에 펴놓고, 윤하가 직접 마우스를 움직이며 설명합니다.

시연 순서:

  1. 학생용 화면 (2분): 매칭 진입 → 1:1 퀴즈 배틀 (타임어택 데미지 연출) → 오답 던전
  2. 교사용 대시보드 (2분): 단원 선택 후 AI 문항 생성 → 수행평가 모드 (탭 전환 감지 경고) → 학습 데이터 리포트

시연 중 윤하의 해설 키포인트:

  • "학생들이 게임 입장권을 더 얻으려면 자기가 틀렸던 문제를 다시 풀어야 하는 구조라서, 자연스럽게 복습하게 만들었어요."
  • "선생님이 교과서 지문을 넣으시면 AI가 오답 선지까지 포함한 문항 초안을 만들어 드려요."
  • "수행평가 볼 때 학생이 다른 창을 열면 바로 경고가 뜨도록 설계했어요."

Step 3. 핵심 질문 (3~5분)

시연 직후 아래 질문을 순서대로 드립니다. 선생님의 답변을 윤하가 실시간으로 메모합니다.

질문 1: 교사 업무 경감 관점

"선생님, 학생별 오답 데이터가 자동으로 정리되어 학기 말 세특 초안으로 제시된다면, 실제로 업무에 도움이 되실까요? 아니면 현실적으로 어떤 부분이 더 필요할까요?"

질문 2: AI 출제 기능의 현장 적합성

"AI가 문항을 자동으로 만들어 주는 기능이 있는데, 실제 수업이나 수행평가에 바로 쓰시려면 어떤 조건이 갖춰져야 할까요? 예를 들어 교육과정 성취기준이나 교과서 출판사별 차이 같은 것이요."

질문 3: 학교 도입의 현실적 장벽

"이런 교육 플랫폼이 학교에 정식으로 도입되려면, 선생님 입장에서 가장 큰 장벽이나 우려사항은 뭘까요?"

질문 4 (선택): 교사추천서 연계

"선생님, 그리고 디미고 특별전형 지원 시 교사추천서가 필요한데요, 혹시 작성을 부탁드려도 괜찮을까요? 제가 학생부 요약 자료를 미리 정리해서 드리겠습니다."

Step 4. 감사 인사 및 마무리 (1분)

윤하: "선생님, 바쁘신 중에 소중한 의견 주셔서 정말 감사합니다. 선생님 말씀을 참고해서 서비스를 더 보완해 보겠습니다!"

🔄 6. 인터뷰 결과 활용 계획

인터뷰에서 확보된 실제 피드백은 다음 문서에 사실 기반 근거로 반영합니다.

활용 대상 반영 방법

03_자기소개서 (문항 1, 4) 기획자로서 현장 교사의 의견을 경청하고 반영한 구체적 에피소드 추가
05_내재화 플랜 (4단계) 윤하의 '진짜 경험'으로 기록하여 면접 답변의 진정성 확보
