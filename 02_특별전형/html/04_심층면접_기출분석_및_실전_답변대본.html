    중학교 생활 속에서 종이 신문의 낮은 열독률을 발견하고 모바일 카드뉴스로 소통 방식을 혁신했던 경험처럼, 친구들이 게임에는 몰입하면서 공부는 지루해하는 문제를 해결하기 위해 <스쿨배틀>을 기획하고 Next.js로 실제 작동하는 프로토타입까지 완성했습니다.

    문제를 정의하고, 시제품을 만들어 검증하고, 현장의 피드백을 받아 개선하는 이 전체 사이클을 3년간 학교와 프로젝트에서 직접 겪어본 경험이야말로 디미고 e-비즈니스과가 찾는 실전형 인재의 자격이라고 확신합니다."

Part 2. 실적설명서(스쿨배틀) 심화 검증 질문 (심사위원 집중 공격 영역)

Q3. [기획 검증] "스쿨배틀 초기 기획(1.0)에서 가장 큰 한계점이나 시행착오는 무엇이었고, 2.0으로 어떻게 보완·발전시켰나요?"

  • 모범 답변:

    "네, 처음 1.0 버전을 구상했을 때는 '학생들의 이용 트래픽에 따른 광고 수익'만을 단순하게 생각했습니다.
    하지만 프로토타입을 직접 플레이하며 자체 검토하는 과정에서, 학생 대상 광고만으로는 학교와 학부모의 신뢰를 얻기 어렵고 서비스 지속성이 떨어진다는 치명적인 한계를 깨달았습니다.
    제 기획의 부족함을 인정하고, 교육 현장의 진짜 의사결정권자인 선생님들이 겪는 '문제 출제 시간 부족'과 '학생 참여 유도의 어려움'에 주목했습니다.
    그래서 학교·학원 대상 '교사용 AI 문제 출제 및 학습 데이터 관리 대시보드'로 비즈니스 모델을 완전히 피벗했습니다.
    이 과정을 통해 내 고집이 아닌, 현장 고객의 실제 결핍과 비즈니스 지속 가능성의 관점에서 기획을 다듬는 진짜 기획자의 눈을 배웠습니다."

Q4. [기술 구현 범위] "실시간 전국 1:1 대전이라고 적혀 있는데, 백엔드 서버나 소켓(WebSocket)은 어떻게 구현되어 있나요?"

  • 답변 포인트: 솔직한 구현 범위 인정 (프론트엔드 MVP) + 향후 협업 계획
  • 모범 답변:

    "솔직히 말씀드리면, 현재 단계의 스쿨배틀은 핵심 게임 규칙(타임어택, 데미지 계산, 오답 복습 유인)과 교사용 화면 구조의 사용성을 검증하기 위한 '인터랙티브 프론트엔드 프로토타입(MVP)'입니다.
    Next.js 환경에서 상태 관리와 타이머 로직을 통해 실제 1:1 대결 화면의 인터랙션을 충실히 시뮬레이션했습니다.
    대규모 동시 접속자를 감당하는 실시간 WebSocket 통신 백엔드 서버는 중학생 혼자서 구축하기에 한계가 있었습니다.
    이 부족한 부분은 디미고 입학 후 웹프로그래밍과 동료들과 팀을 결성하여, 분산 처리 서버와 보안 아키텍처를 함께 구현하는 융합 프로젝트로 완성하고 싶습니다."

Q5. [기술 진위 검증] "AI 코딩 도구(Claude)를 활용해 개발했다고 적었는데, 본인이 직접 한 것과 AI의 도움을 받은 범위는 어디까지인가요?"

  • 답변 포인트: 기획과 정책(100% 본인) + 구체적 에러 해결 사례
  • 모범 답변:

    "서비스 기획, 화면 흐름도(Wireframe), 세부 게임 룰(타임어택 크리티컬 데미지, 오답 던전 입장권 시스템)은 100% 제가 직접 설계했습니다.
    AI 코딩 도구는 제가 구상한 인터랙션을 Next.js 코드로 옮길 때 문법 오류를 디버깅해 주는 페어 프로그래머로 활용했습니다.
    구체적인 예로, 시험 모드에서 탭 전환을 감지하는 visibilitychange 이벤트 리스너를 작성할 때 이벤트가 중복 호출되어 화면이 무한 재렌더링되는 버그가 발생했습니다. AI와 질문을 주고받으며 React useEffect의 클린업(Cleanup) 함수가 리스너를 정리해 주어야 한다는 원리를 이해하고 코드를 직접 수정했습니다. 단순 복사·붙여넣기가 아니라 로직의 동작 원리를 파악하며 개발했습니다."

Q6. [비즈니스 현실성] "공교육 학교 현장에서 교사 개인이 월 구독료를 결제하기 어려울 텐데, 어떻게 해결할 생각인가요?"

    따라서 초기부터 공교육 학교 전체를 뚫으려는 비현실적인 접근 대신, 도입 결정이 유연하고 학업 성취도 관리가 시급한 방과후학교 프로그램이나 사설 보습학원 시장에 먼저 공급하여 1차 실증 레퍼런스를 쌓는 전략을 세웠습니다.
    이후 실증 데이터를 기반으로 디미고 진학 후 조달청 벤처나라 및 학교장터(S2B)에 정식 패키지로 등록하여, 학교 단위 연간 라이선스 공급 계약을 체결하는 단계적 진입 경로를 밟겠습니다."

Q7. [차별점 질문] "카훗(Kahoot)이나 퀴즈렛 같은 유명한 교육 앱이 많은데, 스쿨배틀만의 결정적인 차별점은 무엇인가요?"

Q8. [기획 검증] "프로토타입을 직접 사용해 보면서 발견한 가장 큰 기획적 과제는 무엇이었나요?"

Q10. [자율활동] "학생자치회 소통홍보부에서 종이 신문 대신 카드뉴스를 도입할 때 반대나 우려는 없었나요? 어떻게 설득했습니까?"

  • 학생부 근거: 1~2학년 자율활동(학생자치회 언론·소통홍보부)
  • 모범 답변:

    "인쇄물에 익숙하셨던 선생님들과 선배들의 반대가 있었습니다. 종이 신문이 가진 전통과 기록성을 잃을 수 있다는 우려였습니다.
