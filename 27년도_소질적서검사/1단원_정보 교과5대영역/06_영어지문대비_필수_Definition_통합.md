# ★ [영어 지문 대비] 정보 교과 5대 영역 필수 영문 Definition 통합본

> **디미고 영어 융합 문항 5초 컷 공략법**:  
> 디미고 소질·적성검사의 영어 지문은 전체 문장을 번역하는 시험이 아닙니다. 지문 속에 숨어 있는 **'정답 직결 스캔 키워드'** 2~3개만 눈으로 빠르게 찾아내어 아래 핵심 용어와 1:1로 매칭하면 5초 만에 정답을 고를 수 있습니다. (유사 혼동 어휘는 한 칸에서 바로 비교할 수 있도록 묶어 정리했습니다.)

## Ⅰ. 컴퓨팅 시스템 (하드웨어 · 소프트웨어 · 네트워크 · 피지컬 컴퓨팅)

| 구분 | 핵심 용어 | 시험 출제 영문 Definition | 정답 직결 스캔 키워드 |
| :---: | :--- | :--- | :--- |
| **HW** | **CPU**<br>(중앙처리장치) | The primary component of a computer that acts as its **"brain,"** performing **arithmetic, logical, and control operations** specified by instructions. | `brain`, `executes instructions`, `arithmetic and logical` |
| **HW** | **RAM**<br>(주기억장치) | A high-speed **volatile memory** that **temporarily stores** programs and data **currently in use**; its contents are **lost when power is turned off**. | `volatile`(휘발성), `temporarily stores`, `currently in use`, `lost when power is off` |
| **HW** | **ROM**<br>(읽기전용 메모리) | A **non-volatile memory** from which data can **only be read**; it stores startup instructions (**BIOS/firmware**) that **remain even without power**. | `non-volatile`(비휘발성), `read-only`, `startup / BIOS` |
| **HW** | **Cache Memory**<br>(캐시 메모리) | A small, ultra-fast memory that stores **frequently accessed data** to **reduce the speed gap (bottleneck)** between the fast CPU and slower RAM. | `frequently accessed data`, `speed gap`, `between CPU and RAM` |
| **HW** | **SSD**<br>(보조기억장치) | A **non-volatile storage** device using **flash memory** instead of spinning disks(HDD), offering fast read/write speeds and shock resistance. | `non-volatile storage`, `flash memory`, `no moving parts` |
| **SW** | **Operating System**<br>(운영체제, OS) | System software that **manages computer hardware and software resources** and provides a **user interface** and common services for applications. | `manages hardware and software resources`, `system software` |
| **SW** | **Compiler vs Interpreter**<br>(언어 번역기) | • **Compiler**: Translates the **entire source code** into machine code **all at once** before execution.<br>• **Interpreter**: Translates and executes source code **line by line** immediately. | • Compiler: `entire code`, `all at once`<br>• Interpreter: `line by line`, `immediately` |
| **NW** | **Router**<br>(라우터) | A networking device that **forwards data packets between networks** and determines the **optimal (best) path** using **IP addresses**. | `forwards data packets`, `between networks`, `optimal / best path` |
| **NW** | **DNS**<br>(도메인 네임 시스템) | A system that **translates human-readable domain names** (e.g., `dimigo.hs.kr`) into **numerical IP addresses** used by computers. | `translates domain names into IP addresses`, `phonebook` |
| **NW** | **Protocol**<br>(프로토콜) | A standard **set of rules** that govern how data is formatted, transmitted, and received so devices can **communicate over a network**. | `set of rules`, `govern communication over a network` |
| **NW** | **Firewall**<br>(방화벽) | A security system that **monitors and filters incoming and outgoing network traffic** to **block unauthorized access**. | `monitors traffic`, `blocks unauthorized access` |
| **피지컬** | **Sensor vs Actuator**<br>(센서와 액추에이터) | • **Sensor (Input)**: **Detects physical changes** in the environment (light, temperature, distance) and converts them into electrical signals.<br>• **Actuator (Output)**: Converts control signals into **physical motion or action** (motor, LED). | • Sensor: `input`, `detects physical changes`<br>• Actuator: `output`, `physical motion / action` |

## Ⅱ. 데이터 (단위 · 진법 · 멀티미디어 · 데이터 구조화)

| 구분 | 핵심 용어 | 시험 출제 영문 Definition | 정답 직결 스캔 키워드 |
| :---: | :--- | :--- | :--- |
| **단위** | **Bit vs Byte**<br>(비트와 바이트) | • **Bit (Binary Digit)**: The **smallest unit of data** in a computer, representing a single value of **0 or 1**.<br>• **Byte**: A group of **8 bits** used to represent a single character. | • Bit: `smallest unit`, `0 or 1`<br>• Byte: `group of 8 bits` |
| **수치** | **Binary System**<br>(이진법 / 2진수) | A number system used by computers that represents all data using **only two digits: 0 and 1** (base-2). | `only two digits: 0 and 1`, `base-2` |
| **문자** | **Encoding & Unicode**<br>(인코딩 / 유니코드) | **Encoding** converts data into digital code(0s and 1s); **Unicode** is an international standard that assigns a unique code to characters of **all languages in the world**. | `converts into digital code`, `all languages in the world` |
| **이미지** | **Pixel & Bitmap vs Vector**<br>(픽셀 / 비트맵 vs 벡터) | • **Pixel**: The **smallest controllable dot (element)** of a digital image.<br>• **Bitmap**: Made of a **grid of pixels** (loses quality when enlarged).<br>• **Vector**: Made of **mathematical formulas** (scales without losing quality). | • Pixel: `smallest dot of an image`<br>• Bitmap: `grid of pixels`<br>• Vector: `mathematical formulas` |
| **압축** | **Data Compression**<br>(데이터 압축) | The process of **encoding information using fewer bits** than the original representation to **reduce file size** for storage or transmission. | `fewer bits`, `reduce file size` |
| **분류** | **Structured vs Unstructured Data**<br>(정형 vs 비정형 데이터) | • **Structured**: Data organized in **fixed rows and columns** (tables, databases).<br>• **Unstructured**: Data with **no predefined format** (videos, audio, images, free text). | • Structured: `fixed rows and columns`<br>• Unstructured: `no predefined format` |
| **관리** | **Database (DB)**<br>(데이터베이스) | An organized **collection of structured data** stored electronically so that it can be **easily accessed, managed, and updated**. | `organized collection of data`, `easily accessed and managed` |
| **활용** | **Big Data**<br>(빅데이터) | Extremely **large and complex datasets** (high **Volume, Velocity, and Variety**) that cannot be easily processed by traditional data-processing software. | `extremely large and complex datasets`, `Volume, Velocity, Variety` |

## Ⅲ. 알고리즘과 프로그래밍 (추상화 · 순서도 · 제어 구조 · 디버깅)

| 구분 | 핵심 용어 | 시험 출제 영문 Definition | 정답 직결 스캔 키워드 |
| :---: | :--- | :--- | :--- |
| **설계** | **Abstraction**<br>(추상화) | The process of **removing unnecessary details** and focusing only on the **essential features** needed to solve a problem. | `removing unnecessary details`, `essential features` |
| **설계** | **Algorithm & Flowchart**<br>(알고리즘 / 순서도) | • **Algorithm**: A finite, **step-by-step procedure** or set of rules for solving a problem.<br>• **Flowchart**: A **visual diagram** representing an algorithm using **geometric shapes and arrows**. | • Algorithm: `step-by-step procedure`<br>• Flowchart: `visual diagram`, `shapes and arrows` |
| **설계** | **Pseudocode**<br>(의사코드) | An informal, **human-readable description of an algorithm** that uses structural conventions of programming languages without strict syntax rules. | `informal`, `human-readable description of an algorithm` |
| **저장** | **Variable**<br>(변수) | A **named storage location** (container) in memory whose **value can change** during program execution. | `named storage location`, `value can change` |
| **저장** | **Array / List**<br>(배열 / 리스트) | A data structure that stores a **collection of elements sequentially**, where each item is accessed by its position called an **index**. | `collection of elements sequentially`, `accessed by index` |
| **제어** | **Conditional vs Loop (Iteration)**<br>(조건문 vs 반복문) | • **Conditional (`if-else`)**: Executes different branches depending on whether a condition is **true or false**.<br>• **Loop (`for`/`while`)**: **Repeats a block of instructions** while a condition is met. | • Conditional: `true or false branch`<br>• Loop: `repeats a block of instructions` |
| **모듈** | **Function**<br>(함수) | A **reusable block of code** that performs a specific task; it accepts inputs (**parameters**) and produces an output (**return value**). | `reusable block of code`, `parameters`, `return value` |
| **오류** | **Bug & Debugging**<br>(버그와 디버깅) | • **Bug**: An **error or flaw** in a program that produces incorrect results.<br>• **Debugging**: The process of **finding and fixing errors(bugs)** in software code. | • Bug: `error or flaw`<br>• Debugging: `finding and fixing errors` |
| **오류** | **Syntax vs Logical Error**<br>(문법 오류 vs 논리 오류) | • **Syntax Error**: An error in the **grammar/rules** of the language that **prevents the program from running**.<br>• **Logical Error**: A flaw in **algorithm design** where the program **runs without crashing but produces wrong results**. | • Syntax: `grammar rules`, `prevents running`<br>• Logical: `runs without crashing`, `wrong results` |

## Ⅳ. 인공지능 (기계학습 · 딥러닝 · 학습 데이터 · AI 윤리)

| 구분 | 핵심 용어 | 시험 출제 영문 Definition | 정답 직결 스캔 키워드 |
| :---: | :--- | :--- | :--- |
| **개념** | **Artificial Intelligence (AI)**<br>(인공지능) | Technology that enables computers to **simulate human intelligence** such as **perceiving, learning, reasoning, and problem-solving**. | `simulate human intelligence`, `learning and reasoning` |
| **개념** | **Machine Learning (ML)**<br>(기계학습 / 머신러닝) | A subset of AI that enables computers to **learn patterns from data automatically** and improve **without being explicitly programmed**. | `learn from data`, `without being explicitly programmed` |
| **개념** | **Deep Learning**<br>(딥러닝) | An advanced machine learning technique that uses multi-layered **artificial neural networks** modeled after the **human brain**. | `artificial neural networks`, `human brain` |
| **유형** | **Supervised Learning**<br>(지도학습) | A machine learning method that trains a model using **labeled data** (inputs paired with the **known correct answers**). | `labeled data`, `known correct answers` |
| **유형** | **Unsupervised Learning**<br>(비지도학습) | A machine learning method that discovers hidden patterns or **groups (clusters)** in **unlabeled data** without predefined answers. | `unlabeled data`, `hidden patterns / clusters` |
| **유형** | **Reinforcement Learning**<br>(강화학습) | A learning method where an agent learns optimal actions through **trial and error** to maximize cumulative **rewards**. | `trial and error`, `maximize rewards` |
| **데이터** | **Training vs Test Data**<br>(훈련 vs 테스트 데이터) | • **Training Data**: Data used to **train (teach)** an AI model.<br>• **Test Data**: Separate, **unseen data** used to **evaluate the accuracy** of the trained model. | • Training: `train / teach`<br>• Test: `unseen data`, `evaluate accuracy` |
| **최신** | **Generative AI & Hallucination**<br>(생성형 AI와 환각) | • **Generative AI**: AI capable of **generating new content** (text, images, audio).<br>• **Hallucination**: When an AI generates **false or fabricated information** presented as fact. | • Generative: `generating new content`<br>• Hallucination: `false / fabricated information` |
| **윤리** | **Algorithmic Bias**<br>(알고리즘/데이터 편향) | Systematic and **unfair discrimination** in AI outputs caused by **prejudiced or unbalanced training data**. | `unfair discrimination`, `unbalanced training data` |

## Ⅴ. 디지털 문화 (디지털 사회 기술 · 사이버 범죄 · 암호화 · 저작권)

| 구분 | 핵심 용어 | 시험 출제 영문 Definition | 정답 직결 스캔 키워드 |
| :---: | :--- | :--- | :--- |
| **기술** | **IoT (Internet of Things)**<br>(사물인터넷) | A network of **physical objects ("things") embedded with sensors and software** that connect and **exchange data over the Internet**. | `physical objects`, `sensors`, `exchange data over the Internet` |
| **기술** | **Cloud Computing**<br>(클라우드 컴퓨팅) | The delivery of computing services (storage, servers, software) **over the Internet ("the cloud") on demand**, rather than storing files on a local hard drive. | `computing services over the Internet`, `on demand` |
| **위협** | **Malware**<br>(악성코드) | **Malicious software** specifically designed to **disrupt, damage, or gain unauthorized access** to a computer system (viruses, worms, spyware). | `malicious software`, `disrupt or damage` |
| **위협** | **Ransomware**<br>(랜섬웨어) | A type of malware that **encrypts a victim's files** and **demands payment (ransom)** in exchange for restoring access to the data. | `encrypts files`, `demands payment (ransom)` |
| **위협** | **Phishing**<br>(피싱) | A cyberattack that uses **disguised emails or messages** pretending to be a trusted institution to **trick users into revealing sensitive information** (passwords, credit cards). | `disguised emails`, `trick into revealing sensitive info` |
| **위협** | **DDoS Attack**<br>(분산 서비스 거부) | A cyberattack that **floods a target server with overwhelming traffic** from multiple compromised computers, making the service **unavailable**. | `floods a server`, `overwhelming traffic`, `unavailable` |
| **보안** | **CIA Triad**<br>(기밀성·무결성·가용성) | • **Confidentiality(기밀성)**: Only **authorized users** can access data.<br>• **Integrity(무결성)**: Data is accurate and **not improperly modified**.<br>• **Availability(가용성)**: Systems and data are **accessible when needed**. | • Confidentiality: `only authorized access`<br>• Integrity: `not modified`<br>• Availability: `accessible when needed` |
| **보안** | **Encryption vs Decryption**<br>(암호화와 복호화) | • **Encryption**: Converting readable **plaintext into unreadable ciphertext** to protect confidentiality.<br>• **Decryption**: Converting **ciphertext back into readable plaintext**. | • Encryption: `plaintext into ciphertext`<br>• Decryption: `ciphertext back into plaintext` |
| **보안** | **Public-Key (Asymmetric) Encryption**<br>(공개키/비대칭키 암호화) | An encryption system that uses **two different keys**: a **public key** shared with everyone to encrypt data, and a **private key** kept secret to decrypt it. | `two different keys`, `public key and private key` |
| **권리** | **Open Source Software**<br>(오픈소스 소프트웨어) | Software released with its **source code made publicly available** so that anyone can **inspect, modify, and redistribute** it. | `source code publicly available`, `modify and redistribute` |
