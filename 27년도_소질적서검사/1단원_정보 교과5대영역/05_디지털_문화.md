# Ⅴ. 디지털 문화 (디미고 소질·적성검사 핵심 요약)

> **디미고 실전 출제 유형 4가지**:  
> ① **보안 사고 사례를 보고 침해된 정보 보안 3요소(기밀성·무결성·가용성) 찾기**  
> ② **사이버 범죄 수법(랜섬웨어·피싱·파밍·스미싱·DDoS) 구분하기**  
> ③ **대칭키 vs 공개키 암호화 특징 비교 및 개인정보 해당 여부 판별**  
> ④ **저작권 CCL 기호 조합 해석 및 동시 사용 불가(`ND`+`SA`) 함정 찾기**

---

## 1. 디지털 사회의 핵심 기술 (e-비즈니스·융합 빈출)

| 핵심 디지털 기술 | 작동 원리 및 디미고 시험 출제 포인트 |
| :---: | :--- |
| **사물인터넷 (IoT)** | 일상 속 사물에 **센서와 통신 기능**을 내장하여, 사람의 개입 없이 **사물끼리 인터넷으로 데이터를 주고받으며 자동 제어**하는 기술 (예: 스마트홈, 웨어러블 기기) |
| **클라우드 컴퓨팅**<br>(Cloud Computing) | 내 컴퓨터(하드디스크)에 직접 설치·저장하지 않고, **인터넷을 통해 중앙 서버의 저장공간·SW·연산 자원을 언제 어디서나 빌려 쓰는** 기술 (예: 구글 드라이브, 웹 오피스) |
| **핀테크 (FinTech)** | **금융(Finance) + 기술(Technology)**의 합성어로, 모바일 간편결제·송금·인터넷 전문은행 등 IT 기술을 결합한 디지털 금융 서비스 |

## 2. 개인정보 보호와 정보 보안 3대 요소

### 2.1 개인정보 판별 기준 (★선지 함정 주의)
* **개인정보**: 살아 있는 개인에 관한 정보로서 성명, 주민등록번호, 영상 등을 통해 개인을 알아볼 수 있는 정보
* **★ 결합 식별 원칙**: 그 정보 **하나만으로는 특정 개인을 알아볼 수 없더라도, 다른 정보와 쉽게 결합하여 개인을 알아볼 수 있는 정보**(예: 학교명 + 학년·반 + 생일 조합)도 **개인정보에 해당**합니다.

### 2.2 정보 보안의 3대 핵심 목표 (CIA Triad, ★출제 1순위)

시험에서는 구체적인 피해 사례를 주고 **기밀성 · 무결성 · 가용성 중 무엇이 깨졌는지** 묻습니다.

```
┌──────────────────────────────┐  ┌──────────────────────────────┐  ┌──────────────────────────────┐
│   1. 기밀성 (Confidentiality)│  │     2. 무결성 (Integrity)    │  │    3. 가용성 (Availability)  │
├──────────────────────────────┤  ├──────────────────────────────┤  ├──────────────────────────────┤
│ • 허가된 사람만 열람 가능    │  │ • 허가 없이 데이터가 함부로  │  │ • 권한 있는 사용자가 원할 때 │
│ • 핵심 키워드: '유출·도청 방지'│ │   위조·변조되지 않고 정확함  │  │   언제든 중단 없이 이용 가능 │
│ • 침해 사례: 고객 명단 유출, │  │ • 핵심 키워드: '조작·변조 방지'│ │ • 핵심 키워드: '서비스 정상작동'│
│   비밀번호 탈취, 메시지 도청 │  │ • 침해 사례: 성적·송금액 조작│  │ • 침해 사례: DDoS 서버 마비, │
│ • 대책: 암호화, 비밀번호 설정│  │ • 대책: 접근 통제, 해시 검증 │  │   랜섬웨어로 파일 열람 불가  │
└──────────────────────────────┘  └──────────────────────────────┘  └──────────────────────────────┘
```

### 2.3 암호화(Encryption)의 두 가지 방식 비교

```
[ ① 대칭키(비밀키) 암호화 ] : 암호화 열쇠(A) ══(동일)══ 복호화 열쇠(A)
  • 장점: 암호화·복호화 속도가 빠름
  • 단점: 상대방에게 열쇠(A)를 전달하는 과정에서 해커에게 열쇠가 탈취될 위험이 있음

[ ② 공개키(비대칭키) 암호화 ] : 암호화 열쇠(공개키: 모두에게 공개) ≠ 복호화 열쇠(개인키: 나만 보관)
  • 장점: 잠그는 열쇠(공개키)와 여는 열쇠(개인키)가 달라 열쇠 배송 위험이 없고 보안성이 높음
  • 단점: 대칭키 방식보다 연산이 복잡하여 속도가 느림
```

## 3. 주요 사이버 범죄 및 보안 위협 1초 구분표

| 위협 명칭 | 핵심 수단 | 1초 구분 핵심 키워드 |
| :---: | :---: | :--- |
| **랜섬웨어**<br>(Ransomware) | 파일 암호화 | 컴퓨터의 문서·파일을 **강제로 암호화(인질)**한 뒤, 풀어주는 대가로 **금전(몸값, Ransom)을 요구** |
| **피싱 (Phishing)** | 이메일·메신저 | 금융기관·지인을 사칭한 **이메일·메신저**로 속여 계좌번호·비밀번호 등 **민감한 개인정보 탈취** |
| **파밍 (Pharming)** | 가짜 웹사이트 | 정상 홈페이지 주소를 입력해도 악성코드/DNS 조작으로 **가짜 사이트로 몰래 이동시켜** 정보 탈취 |
| **스미싱 (Smishing)** | 문자(SMS) 링크 | **문자 메시지(SMS)** 속 인터넷 주소(URL) 클릭을 유도해 악성 앱 설치 및 소액결제·정보 탈취 |
| **DDoS 공격**<br>(분산 서비스 거부) | 좀비 PC 트래픽 | 감염된 수많은 좀비 PC에서 특정 서버로 **동시에 과도한 접속 요청(트래픽)을 보내 서버 마비** |

## 4. 저작권(CCL) 조합 규칙과 소프트웨어 라이선스

### 4.1 저작물 이용 허락 표시 (CCL) 4대 조건

```
┌──────────────────┬──────────────────┬──────────────────┬──────────────────┐
│  저작자 표시(BY) │    비영리 (NC)   │   변경 금지 (ND) │ 동일조건변경(SA) │
├──────────────────┼──────────────────┼──────────────────┼──────────────────┤
│ 출처(창작자 이름)│ 돈을 버는 상업적 │ 원본을 수정·편집 │ 수정하여 만든 2차│
│ 를 반드시 밝혀야 │ 목적으로 사용할  │ 하지 않고 그대로 │ 창작물도 원본과  │
│ 함 (기본 필수)   │ 수 없음          │ 만 사용해야 함   │ 같은 CCL로 공유  │
└──────────────────┴──────────────────┴──────────────────┴──────────────────┘
```
* **★ 시험 1순위 함정 (동시 사용 불가 조합)**:
  * 원본 수정을 금지하는 **`ND(변경 금지)`**와 수정 후 동일 조건 공유를 뜻하는 **`SA(동일조건변경허락)`**는 서로 모순되므로 **절대 함께 쓰일 수 없습니다!** (보기에 `CC BY-ND-SA`가 나오면 무조건 틀린 선지!)
  * *실전 해석*: 사진에 **`[CC BY-NC]`**가 붙어 있다면? → "출처를 밝히고(`BY`), 돈을 벌지 않는 비영리 목적(`NC`)이라면, **사진을 자르거나 수정해서(ND가 없으므로 변경 가능!)** 사용할 수 있다."

### 4.2 소프트웨어 라이선스 비교
* **상용 소프트웨어**: 비용을 지불하고 정품을 구매해야 사용할 수 있는 소프트웨어
* **프리웨어 (Freeware)**: 무료로 사용 가능하지만, **소스 코드(설계도)는 비공개**여서 수정할 수 없는 소프트웨어
* **오픈소스 소프트웨어 (Open Source SW)**: **소스 코드까지 전면 공개**하여 누구나 자유롭게 **열람·수정·재배포**할 수 있는 소프트웨어 (예: Linux, Android, Python)
