# Ⅳ. 인공지능 (디미고 소질·적성검사 핵심 요약)

> **디미고 실전 출제 유형 4가지**:  
> ① **전통적 프로그래밍(규칙 기반) vs 기계학습(데이터 기반) 입출력 빈칸 추론**  
> ② **기계학습 3대 유형(지도[분류/회귀] · 비지도[군집] · 강화학습) 사례 매칭**  
> ③ **의사결정나무(Decision Tree) 조건 분기 추적 및 훈련/테스트 데이터 분리 원칙**  
> ④ **AI 윤리 쟁점(데이터 편향성, 생성형 AI 환각 현상) 판별**

## 1. 인공지능(AI)의 개념과 학습 원리

### 1.1 인공지능 · 기계학습 · 딥러닝 포함 관계와 지능 에이전트

```
┌───────────────────────────────────────────────────────────────────────┐
│  인공지능 (AI: 인간의 인식·학습·추론 능력을 컴퓨터로 구현한 기술)     │
│   ┌───────────────────────────────────────────────────────────────┐   │
│   │  기계학습 (Machine Learning: 컴퓨터가 데이터로부터 스스로     │   │
│   │            패턴과 규칙을 찾아 학습하는 기술)                  │   │
│   │   ┌───────────────────────────────────────────────────────┐   │   │
│   │   │  딥러닝 (Deep Learning: 인간 뇌 신경망을 모방한       │   │   │
│   │   │          '인공신경망'으로 대규모 데이터를 심층 학습)  │   │   │
│   │   └───────────────────────────────────────────────────────┘   │   │
│   └───────────────────────────────────────────────────────────────┘   │
└───────────────────────────────────────────────────────────────────────┘
```
* **지능 에이전트 (Intelligent Agent)**: 목표 달성을 위해 주변 환경을 **인식(센서)** → **학습·추론(판단)** → 자율적으로 **행동(액추에이터)**하는 시스템 (예: 자율주행차, 로봇 청소기)
* **일반 자동화 SW vs 인공지능 SW 구별**: 사람이 정해준 고정 조건(`온도 ≥ 28도면 에어컨 켜기`)만 그대로 수행하면 일반 프로그램이고, **축적된 데이터를 통해 스스로 규칙을 개선·학습하면** 인공지능입니다.

### 1.2 전통적 프로그래밍 vs 기계학습 구조 비교 (★출제 1순위)

시험에서는 아래 두 상자의 **입력과 출력에 들어갈 말**을 맞바꾸어 오답 함정을 만듭니다.

```
[ ① 전통적 프로그래밍 (규칙 기반) ] ──▶ 사람이 직접 '규칙'을 넣어주면 컴퓨터가 '결과'를 출력
  입력: [ 데이터 ] + [ 사람이 만든 규칙(Algorithm) ]  ───▶  [ 컴퓨터 ]  ───▶  출력: [ 결과(정답) ]

[ ② 기계학습 (데이터 기반 학습) ]   ──▶ 컴퓨터가 '데이터(와 결과)'를 분석해 스스로 '규칙(모델)'을 생성
  입력: [ 대량의 데이터 (및 결과값) ]                 ───▶  [ 컴퓨터 ]  ───▶  출력: [ 학습된 규칙(AI 모델) ]
```

## 2. 기계학습(Machine Learning) 3대 유형과 의사결정나무

### 2.1 기계학습 3대 유형 1초 판별 트리

| 학습 유형 | 판별 기준 (정답·보상 유무) | 세부 방법 및 시험 빈출 사례 (보기로 출제) |
| :---: | :--- | :--- |
| **지도학습**<br>(Supervised) | **정답(Label) 제공 O**<br>(문제 + 정답 함께 학습) | • **분류 (Classification)**: 딱 떨어지는 종류 구분 (스팸 메일 판별, 개/고양이 구분, 손글씨 숫자 인식, 불량품 판별)<br>• **회귀 (Regression)**: 연속적인 숫자 예측 (내일 기온(℃) 예측, 전력 소비량·아파트 가격 예측) |
| **비지도학습**<br>(Unsupervised) | **정답(Label) 제공 X**<br>(보상 없이 특징별 분류) | • **군집 (Clustering)**: 데이터의 유사한 특징끼리 스스로 그룹 묶기 (고객 구매 성향별 그룹화, 유사 뉴스 기사 묶기) |
| **강화학습**<br>(Reinforcement) | **정답 X / 보상(Reward) O**<br>(시행착오를 통해 학습) | • 행동 결과에 따른 **보상(점수)**을 최대화하는 최적 행동 학습 (바둑 AI 알파고, 자율주행 제어, 이족보행 로봇, 게임 AI) |

### 2.2 ★ 실전 추론 유형: 의사결정나무 (Decision Tree) 분류 추적

인공지능이 데이터를 분류할 때 스무고개처럼 **질문(조건)을 따라가며 정답을 결정하는 트리 도식** 문제가 자주 출제됩니다. 표로 주어진 대상의 속성값을 보고 화살표를 정확히 따라가면 쉽게 풀립니다.

```
                [ 질문 1: 날개가 있는가? ]
                  / (예)            \ (아니오)
    [ 질문 2: 하늘을 나는가? ]        [ 결과: 포유류 (강아지) ]
       / (예)          \ (아니오)
 [ 결과: 참새 ]     [ 결과: 펭귄 ]
```

## 3. 인공지능 문제 해결 4단계와 AI 윤리

### 3.1 인공지능 문제 해결 순서와 데이터 분리 원칙

```
┌───────────────┐    ┌──────────────────────┐    ┌──────────────────────┐    ┌──────────────────────┐
│ 1. 문제 정의  │ ─▶ │ 2. 데이터 수집·전처리│ ─▶ │ 3. 모델 학습 (훈련)  │ ─▶ │ 4. 모델 평가 및 적용 │
├───────────────┼    ├──────────────────────┤    ├──────────────────────┤    ├──────────────────────┤
│ 해결할 문제와 │    │ 결측치·이상치 제거,  │    │ [훈련 데이터]를 넣어 │    │ 학습에 쓰지 않은     │
│ 목표 설정     │    │ 편향 없는 데이터 확보│    │ 패턴과 규칙을 학습   │    │ [테스트 데이터]로 평가│
└───────────────┘    └──────────────────────┘    └──────────────────────┘    └──────────────────────┘
```
* **★ 시험 필수 함정 (훈련 데이터 vs 테스트 데이터)**:
  * "모델의 정확도를 높이기 위해 학습에 사용했던 **훈련 데이터**로 모델의 성능을 평가한다." → **❌ 거짓!** 반드시 학습에 사용하지 않은 **새로운 데이터(테스트 데이터)**로 평가해야 합니다.

### 3.2 인공지능의 한계와 윤리적 쟁점
1. **데이터 편향성 (Algorithmic Bias)**: 특정 성별·인종·연령에 치우친 데이터를 학습하면 AI도 차별적·불공정한 결과를 내놓습니다.
2. **환각 현상 (Hallucination)**: 생성형 AI가 사실이 아닌 **거짓 정보를 마치 사실인 것처럼 그럴듯하게 지어내어 답변**하는 현상입니다. (반드시 교차 검증 필요)
3. **개인정보·저작권 침해 및 책임 소재**: 학습 데이터 무단 수집, 딥페이크(Deepfake) 악용, 자율주행 사고 시 책임 주체 문제가 발생합니다.
