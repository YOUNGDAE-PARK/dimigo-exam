# Ⅰ. 컴퓨팅 시스템 (디미고 소질·적성검사 핵심 요약)

> **디미고 실전 출제 유형 3가지**:  
> ① **기억장치·SW 선지 정오 판별** (휘발성 유무, 속도 순서, 컴파일러 vs 인터프리터)  
> ② **네트워크 장비 역할 매칭** (DNS, 라우터, 방화벽의 작동 순서와 역할)  
> ③ **피지컬 컴퓨팅 센서 조건표 추론** (센서 측정값 표를 보고 액추에이터가 작동하는 횟수·시점 찾기)

---

## 1. 하드웨어(HW)와 기억장치 구조

### 1.1 하드웨어 5대 장치 데이터 흐름도

```
                     ┌────────────────────────────────────┐
                     │       중앙처리장치 (CPU: 두뇌)     │
                     │  • 제어장치: 명령어 해독 및 지시   │
                     │  • 연산장치(ALU): 산술·논리 연산   │
                     └─────────┬────────────────▲─────────┘
                          제어 │                │ 명령어·데이터
                               ▼                ▼
┌──────────────┐     ┌────────────────────────────────────┐     ┌──────────────┐
│   입력장치   │ ──▶ │      주기억장치 (RAM / ROM)        │ ──▶ │   출력장치   │
│ 키보드,마우스│     │  실행 중인 프로그램과 데이터 보관  │     │ 모니터,프린터│
│ 마이크,스캐너│     └─────────────────▲──────────────────┘     │ 스피커       │
└──────────────┘                       │ 불러오기 / 저장        └──────────────┘
                                       ▼
                     ┌────────────────────────────────────┐
                     │     보조기억장치 (SSD / HDD)       │
                     │   전원이 꺼져도 데이터 영구 보관   │
                     └────────────────────────────────────┘
```
* **★ 시험 단골 선지**: "보조기억장치(SSD)에 저장된 프로그램은 반드시 **주기억장치(RAM)로 불러와야만** CPU가 읽고 실행할 수 있다." (O)

### 1.2 기억장치 속도 계층 및 휘발성 비교 (★출제 1순위)

```
[속도 빠름 / 용량 작음 / 비쌈]
   ▲   1위: 레지스터 (CPU 내부 연산용 임시 저장)  ─┐
   │   2위: 캐시 메모리 (CPU-RAM 속도 병목 해소)  ├─ ▶ 휘발성 (전원 꺼지면 데이터 소멸)
   │   3위: 주기억장치 RAM (현재 실행 중인 작업)  ─┘
   ▼   4위: 보조기억장치 SSD > HDD (영구 보관)    ── ▶ 비휘발성 (전원 꺼져도 데이터 유지)
[속도 느림 / 용량 큼 / 저렴함]                         ※ 함정 주의: 주기억장치 중 ROM은 비휘발성!
```

* **시험 직결 오답 함정 3가지**:
  1. "RAM 용량을 늘리면 영구 저장할 수 있는 파일 공간이 늘어난다." → **❌ 거짓** (영구 저장은 SSD/HDD 역할, RAM은 동시 실행 작업 공간)
  2. "캐시 메모리는 보조기억장치와 주기억장치 사이의 속도 차이를 줄여준다." → **❌ 거짓** (**CPU와 주기억장치(RAM) 사이**의 속도 차이를 줄여줌)
  3. "ROM은 전원이 꺼지면 저장된 BIOS 정보가 사라진다." → **❌ 거짓** (ROM은 **비휘발성 읽기 전용** 메모리)

## 2. 소프트웨어(SW)와 운영체제(OS)

```
┌───────────────────────────────────────────────────────────┐
│  응용 소프트웨어 (Application SW)                         │
│  • 사용자가 특정 목적을 위해 쓰는 프로그램 (웹브라우저, 앱)│
├───────────────────────────────────────────────────────────┤
│  시스템 소프트웨어 (System SW) — 하드웨어 제어 및 기반 제공│
│  • 운영체제 (OS: Windows, macOS, Linux, Android, iOS)     │
│  • 언어 번역기 (컴파일러, 인터프리터)                     │
├───────────────────────────────────────────────────────────┤
│  하드웨어 (Hardware: CPU, RAM, 입출력장치)                │
└───────────────────────────────────────────────────────────┘
```

* **운영체제(OS)의 핵심 역할**: 하드웨어 자원(CPU, RAM) 효율적 배분·관리, 멀티태스킹 프로세스 제어, 사용자 인터페이스(UI) 제공
* **언어 번역기 1초 구분 (인간이 작성한 소스 코드 → 기계어 0, 1 번역)**:
  * **컴파일러 (Compiler)**: 코드 **전체를 한 번에** 번역하여 실행 파일 생성 (번역 후 실행 속도 빠름)
  * **인터프리터 (Interpreter)**: 코드를 **한 줄씩(Line by Line)** 읽으며 즉시 번역·실행 (별도 실행 파일 없음, 수정·오류 확인 용이)

## 3. 네트워크와 인터넷 통신 흐름

```
[클라이언트 (내 PC/스마트폰)]
       │
       ▼  ① 도메인 입력 시 ▶ [DNS 서버]가 '도메인 이름(dimigo.hs.kr) → 숫자 IP 주소'로 변환
[스위치 / 공유기]   ──▶ ② 같은 공간(LAN) 내부 기기들을 연결
       │
       ▼
[라우터 (Router)]   ──▶ ③ 서로 다른 네트워크(WAN) 사이에서 목적지 IP를 보고 '최적 경로' 탐색
       │
       ▼  ④ 데이터를 작은 조각인 '패킷(Packet)' 단위로 쪼개어 전송 (규칙: 프로토콜 HTTP/HTTPS)
[방화벽 (Firewall)] ──▶ ⑤ 보안 규칙에 따라 외부의 '비인가 접근(Unauthorized Access)' 감시·차단
       │
       ▼
[서버 (Server)]     ──▶ ⑥ 요청받은 웹페이지·데이터를 클라이언트에게 응답
```
* **IP 주소**: 인터넷상에서 컴퓨터를 식별하는 고유한 숫자 주소 (예: `192.168.0.1`)

## 4. 피지컬 컴퓨팅 시스템 (입출력 조건 추론)

```
┌─────────────────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│  1. 입력: 센서 (Sensor) │      │ 2. 처리: 제어장치(보드) │      │ 3. 출력: 액추에이터     │
│  (외부 환경 변화 감지)  │ ───▶ │   (조건문 판단·명령)    │ ───▶ │   (물리적 동작/신호)    │
├─────────────────────────┤      ├─────────────────────────┤      ├─────────────────────────┤
│ • 조도 센서 (밝기)      │      │ • IF (조건) ~ ELSE 문   │      │ • 모터 (회전·열림/닫힘) │
│ • 초음파/적외선 (거리)  │      │   센서값을 기준값과     │      │ • LED / 화면 (점등·표시)│
│ • 온도 / 습도 / 소리    │      │   비교하여 동작 결정    │      │ • 부저/스피커 (경고음)  │
└─────────────────────────┘      └─────────────────────────┘      └─────────────────────────┘
```

### ★ 실전 출제 유형: 센서 조건표 판독법
* **출제 방식**: `"조도 센서 값 ≤ 30 이고(AND) 초음파 거리 ≤ 50cm 일 때만 LED를 켠다"` 같은 제어 규칙과 시간대별 센서 측정표를 주고 **LED가 켜지는 시각**을 고르게 합니다.
* **풀이 공식**:
  1. 조건을 만드는 측정 부품(**조도·초음파·온도**)은 무조건 **센서(입력)**, 결과로 움직이는 부품(**LED·모터·부저**)은 무조건 **액추에이터(출력)**로 분류합니다.
  2. 표 옆에 각 조건의 만족 여부(`O`, `X`)를 적은 뒤, `AND`(둘 다 `O`)인지 `OR`(하나라도 `O`)인지 확인하여 개수를 셉니다.
