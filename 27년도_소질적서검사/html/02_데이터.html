Ⅱ. 데이터 (디미고 소질·적성검사 핵심 요약)

디미고 실전 출제 유형 4가지:
① 최소 비트 수(2^n) 계산 및 2진수 ↔ 10진수 크기 비교
② 격자 픽셀(0·1) 도형 추론 및 런-랭스(RLE) 압축 결과 계산
③ 데이터 정제(결측치·이상치)와 표·트리·그래프 구조화 자료 해석
④ 비트맵 vs 벡터, 아스키 vs 유니코드, 소리 디지털화 3단계 선지 판별

1. 디지털 데이터 표현과 2진수 실전 계산

1.1 비트(Bit)와 정보 표현 가짓수 (2^n 공식)

• 1 Bit (최소 단위) = 0 또는 1 ──▶ 2¹ = 2가지 표현  |  • n Bit (0과 1이 n자리) ──▶ 2ⁿ가지 표현  |  • 1 Byte = 8 Bit ──▶ 2⁸ = 256가지 표현
[시험장 1초 암기표]   2³ = 8  |  2⁴ = 16  |  2⁵ = 32  |  2⁶ = 64  |  2⁷ = 128  |  2⁸ = 256  |  2¹⁰ = 1,024
  • ★ 실전 문제 공식 ("최소 몇 비트가 필요한가?"): 구별할 대상이 N가지일 때, 2ⁿ ≥ N을 만족하는 가장 작은 n을 찾습니다.
    • 예: "50종류의 상품을 2진수 코드로 구별하려면?" → 2⁵(32) < 50 ≤ 2⁶(64) 이므로 최소 6비트 필요!

1.2 10진수 ↔ 2진수 양방향 초고속 변환 및 연산

시험지에서 나눗셈을 길게 하지 말고, 64 - 32 - 16 - 8 - 4 - 2 - 1 자리값을 적어 즉시 변환합니다.

변환 방향 32 16 8 4 2 1 계산 과정 및 결과
① 2진수 101101(2)
→ 10진수 변환		 1 0 1 1 0 1 1이 있는 자리값만 합산:
32 + 8 + 4 + 1 = 45
② 10진수 53
→ 2진수 변환		 1 1 0 1 0 1 큰 자리값부터 쪼개기 (53 = 32+16+4+1):
쓰인 자리에 1 표기 = 110101(2)
  • 크기 비교 팁: 보기에 2진수와 10진수가 섞여 나오면 모두 10진수로 통일해서 비교하는 것이 가장 빠릅니다.
  • 2진수 덧셈 자리올림: 1 + 1 = 10(2) (현재 자리 0, 윗자리로 1 올림), 1 + 1 + 1 = 11(2) (현재 자리 1, 윗자리로 1 올림)

2. 문자 · 이미지 · 소리의 디지털화 원리

2.1 미디어별 디지털 표현 핵심 비교

구분 핵심 원리 및 비교 디미고 시험 단골 함정 & 출제 포인트
문자 아스키(ASCII) vs 유니코드(Unicode) • ASCII: 영문·숫자·기본 기호만 표현 (한글 표현 불가)
• 유니코드: 한글·이모지 등 전 세계 모든 문자를 표현하는 국제 표준
이미지 비트맵(Bitmap) vs 벡터(Vector) • 비트맵: 작은 점(픽셀, Pixel)의 모임 → 확대 시 계단 현상(깨짐) 발생 (사진)
• 벡터: 점·선·면을 수학 공식으로 저장 → 확대해도 절대 깨지지 않음 (로고, 글꼴)
소리 표본화 → 양자화 → 부호화 아날로그 파형을 일정 시간 간격으로 측정(표본화) → 정수 눈금값으로 맞춤(양자화) → 0과 1의 2진수로 변환(부호화)
  • ★ 용량과 품질의 비례 법칙: 이미지의 해상도(픽셀 수)·색상 비트 수(용량 = 가로 픽셀 × 세로 픽셀 × 픽셀당 비트 수)를 높이거나, 소리의 표본화 주기를 짧게(자주 추출)·양자화 단계를 세밀하게 할수록 원본에 가까워지지만 파일 용량은 비례해서 커집니다.

2.2 흑백 비트맵 픽셀(0·1) 매핑과 런-랭스(RLE) 압축 (★빈출 퍼즐)

격자 픽셀 (알파벳 'A' 모양 5×4) 2진수 표현 (흰색 0, 검은색 1) 런-랭스(RLE) 압축: 연속된 개수 표기
□ ■ ■ ■ □ 0 1 1 1 0 (0, 1), (1, 3), (0, 1)  또는  1, 3, 1
■ □ □ □ ■ 1 0 0 0 1 (1, 1), (0, 3), (1, 1)  또는  0, 1, 3, 1 (※ 첫 칸이 검은색일 때!)
■ ■ ■ ■ ■ 1 1 1 1 1 (1, 5)  또는  0, 5
■ □ □ □ ■ 1 0 0 0 1 (1, 1), (0, 3), (1, 1)  또는  0, 1, 3, 1
  • ★ RLE 퍼즐 함정: "항상 흰색(0)의 개수부터 먼저 적는다"는 조건일 때, 줄의 맨 첫 칸이 검은색(1)으로 시작하면 맨 앞에 흰색이 0개라는 뜻인 0을 반드시 먼저 적어야 합니다!

3. 데이터 수집·정제 및 구조화·해석 (2022 개정 핵심)

3.1 데이터 처리 3단계와 정형/비정형 구분

1. 데이터 수집
• 정형 데이터: 표, 엑셀, DB (고정된 행·열 규칙 있음)
• 비정형 데이터: 영상, 음성, 이미지, 댓글 (정해진 틀 없음)
──▶
2. 데이터 정제 (전처리)

──▶
3. 구조화 및 관계 해석
• 표 / 트리 / 그래프 구조화
• 데이터 간 상관관계 분석 및 객관적 의사결정 수행

3.2 데이터 구조화 3대 모델과 실전 문제 유형

① 표 (Table): 행·열 비교
이름 | 국어 | 수학
김디 | 95 | 90
가로(행)·세로(열) 속성 비교
② 트리 (Tree): 상하 계층
[루트: 전체 폴더]
├── [음악] ── (발라드), (팝)
└── [문서] ── (보고서)
• 단말 노드(끝 노드): 발라드, 팝, 보고서 (3개)
③ 그래프 (Graph): 연결망
(A역) ──4분── (B역)
│2분 │3분
(C역) ──6분── (D역)
• A→D 최단 시간: A→B→D(7분) < A→C→D(8분)
  • 상관관계 해석 주의점:
    • 양(+)의 상관관계: X가 증가할 때 Y도 증가  /  음(-)의 상관관계: X가 증가할 때 Y는 감소
    • 인과관계 혼동 금지: 두 변수가 함께 움직인다고 해서(상관관계) 반드시 한쪽이 다른 쪽의 원인(인과관계)인 것은 아닙니다.
