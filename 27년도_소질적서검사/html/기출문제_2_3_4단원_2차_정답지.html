2. 문항별 상세 해설

[Part 1. 정보·IT 기초 이해력 및 데이터·진법 융합 해설]

1. [정답] ③ (하드웨어 4개 / ㄹ)

  • [해설]: 하드웨어는 ㄱ(CPU), ㄴ(캐시 메모리), ㄹ(SSD), ㅂ(RAM)의 4개입니다. ㄷ(펌웨어)와 ㅁ(컴파일러)는 소프트웨어입니다. 전원이 꺼져도 데이터가 남는 비휘발성 기억장치는 보조기억장치인 ㄹ(SSD)뿐이며, 캐시와 RAM은 휘발성입니다.

2. [정답] ④ (환풍기 3회 / 12시, 15시)

  • [해설]: 환풍기는 온도 ≥ 28 또는 습도 ≥ 75일 때 켜집니다.
    • 12시: 26·70 ➔ OFF / 13시: 온도 28 ➔ ON / 14시: 습도 80 ➔ ON / 15시: 25·60 ➔ OFF / 16시: 습도 75 ➔ ON → 환풍기 3회
    • 보조 조명은 조도 < 300이면서 환풍기 OFF여야 하므로, 12시(250, OFF) ✔, 15시(280, OFF) ✔입니다. 13시·16시는 조도가 낮아도 환풍기가 ON이라 꺼집니다.

3. [정답] ② (10초)

  • [해설]: 이미지 1장 = 1,000 × 500 × 24비트 = 12,000,000비트 = 12 Mbit(= 1.5 MB). 10장은 120 Mbit이므로 120 ÷ 12 = 10초입니다.

4. [정답] ③ (Data)

  • [해설]: 16진수를 10진수로 바꿉니다. 44₁₆ = 4×16 + 4 = 68, 61₁₆ = 6×16 + 1 = 97, 74₁₆ = 7×16 + 4 = 116. 대문자 A = 65이므로 68 = D, 소문자 a = 97, t = 97 + 19 = 116 ➔ Data입니다.

5. [정답] ④ ((가) 2, 3, 1, 1 / (나) 0, 3, 2, 2)

  • [해설]: (가) □□ ■■■ □ ■ ➔ 흰 2, 검 3, 흰 1, 검 1. (나)는 검은 칸으로 시작하므로 맨 앞에 흰색 0개를 적어 0, 3, 2, 2가 됩니다.

6. [정답] ①

  • [해설]: (가)는 정답(Label)이 있는 지도학습의 분류, (나)는 정답 없이 묶는 비지도학습의 군집, (다)는 보상을 통한 강화학습입니다. 오답: ②는 스팸 판별이 분류이므로 틀림, ③은 비지도학습인데 강화학습이라 틀림, ④는 평가에는 훈련에 쓰지 않은 테스트 데이터를 써야 함, ⑤는 규칙 기반 프로그래밍이지 딥러닝이 아님.

7. [정답] ⑤

  • [해설]: (가) DDoS는 서비스 접속을 막으므로 가용성 침해입니다. (나) BY(출처 표시), NC(비영리), SA(동일 조건 변경 허락): 비영리 목적의 수정은 가능하고, 2차 창작물도 같은 조건으로 공유해야 합니다. ND(변경 금지)는 없습니다.

8. [정답] ② ((A) DNS - (B) Cache Memory)

  • [해설]: (A)는 도메인 이름을 IP 주소로 바꿔 주는 인터넷의 전화번호부, 즉 DNS입니다. (B)는 CPU와 RAM 사이에서 속도 차이를 줄여 주는 초고속 소형 휘발성 메모리, 즉 캐시 메모리입니다.

[Part 2. 수리추론 영역 해설]

9. [정답] ③ (10)

  • [해설]: k번째 묶음에는 수가 k개 있습니다. 1~9번째 묶음까지 항의 개수는 1+2+…+9 = 45개입니다. 50번째 항은 10번째 묶음의 50 - 45 = 5번째 수이므로 2 × 5 = 10입니다.

10. [정답] ② (1번, 3번, 4번)

  • [해설]: 시계 방향 90도 회전 시 칸 n의 이동은 1→3, 2→6, 3→9, 4→2, 5→5, 6→8, 7→1, 8→4, 9→7입니다. 따라서 {1, 2, 7} ➔ {3, 6, 1}. 이어서 좌우 대칭(1↔3, 4↔6, 7↔9)을 하면 {3, 6, 1} ➔ {1, 4, 3}, 즉 1번, 3번, 4번입니다.

11. [정답] ④ (22일)

  • [해설]: 1일째가 토요일입니다. 수아는 1, 5, 9, 13, 17, 21, 25, …일, 지호는 토·수이므로 1, 5, 8, 12, 15, 19, 22, 26, …일입니다. 겹치는 날은 1일, 5일이고, 4와 7의 최소공배수인 28일마다 같은 패턴이 반복됩니다(28일마다 2일 겹침).
    • 300 = 28 × 10 + 20이므로 28일 주기가 10번 ➔ 10 × 2 = 20일
    • 남은 20일(281300일째)은 주기의 120일째와 같고, 여기에 1일째, 5일째가 모두 포함되어 +2일 ➔ 총 22일

12. [정답] ⑤ (19명)

  • [해설]: 둘 다 취득한 학생을 2x명, 어느 것도 취득하지 못한 학생을 x명이라 하면 40 - x = 23 + 19 - 2x, 즉 x = 2입니다. 둘 다 취득은 4명이므로, 컴퓨터활용능력 단독은 23 - 4 = 19명입니다.

13. [정답] ② (열차 길이 200m, 초속 25m)

  • [해설]: 다리와 터널의 길이 차 1,050 - 550 = 500m를 50 - 30 = 20초 더 달린 것이므로 속력은 500 ÷ 20 = 25m/초입니다. 다리 통과 시 25 × 30 = 750 = 550 + L이므로 열차 길이 L = 200m입니다.

14. [정답] ⑤

  • [해설]: 모든 그래프에서 차수의 총합은 간선 수의 2배(짝수)입니다. ⑤는 3+3+3+2+2+2 = 15(홀수)이므로 그런 그래프는 존재할 수 없습니다. 나머지는 옳은 설명입니다. ①트리의 간선 수는 정점 − 1 = 11, ②2⁴ − 1 = 15, ③차수 합 14 ➔ 간선 7개, ④X자 사각형은 홀수점 4개이므로 한붓그리기 불가능입니다.

15. [정답] ④ (84가지)

  • [해설]: A를 4가지, B는 A와 달라야 하므로 3가지입니다. C도 A와 달라야 합니다. D는 B, C와 달라야 하므로 B와 C의 색이 같은지에 따라 나눕니다.
    • B = C인 경우: A 4 × B 3 × (C = B) 1 × D 3 = 36가지
    • B ≠ C인 경우: A 4 × B 3 × C 2 × D 2 = 48가지
    • 합계 36 + 48 = 84가지

16. [정답] ③ (17가지)

  • [해설]: 각 교차점까지의 경로 수를 (행, 열)로 구합니다. 0행은 모두 1입니다. 1행은 1, 2, 3, 4, 5입니다(예: (1,1) = (0,1) + (1,0) = 2).
    • 2행: (2,0)=1, (2,1)=1+2=3, (2,2)=(1,2)+(2,1)+대각선 (1,1) = 3+3+2 = 8, (2,3)=0(✕), (2,4)=(1,4)+(2,3) = 5+0 = 5
    • 3행: (3,0)=1, (3,1)=1+3=4, (3,2)=4+8=12, (3,3)=12+0=12, (3,4)=12+5=17
    • 따라서 17가지입니다.

[Part 3. 논리·추리 퍼즐 및 국어 조건 독해 해설]

17. [정답] ④

  • [해설]: 보고 모든 부원이 (실험복 AND 보안경)이 거짓이므로, 부정은 어떤 부원은 (실험복 NOT OR 보안경 NOT)입니다. 즉 "실험복을 넣지 않았거나 보안경을 넣지 않은 부원이 적어도 1명 있다"가 항상 참입니다. ①은 '모든 부원이 둘 다 안 넣음'으로 과도하고, ②는 둘 다 안 넣은 부원이 반드시 있다고 단정하므로 틀립니다.

18. [정답] ① (물을 준 학생: 을 / 참말: 갑, 정)

  • [해설]: 병("정이 줬다")과 정("병의 말은 거짓")은 서로 모순이므로 둘 중 정확히 1명이 참말입니다. 따라서 갑, 을 중에서도 정확히 1명이 참말입니다.
    • 을이 참말이면 병이 물을 준 것이므로 갑("을이나 병")도 참말이 되어 모순입니다. 그러므로 을은 거짓, 갑은 참입니다.
    • 을이 거짓이므로 병은 범인이 아니고, 갑이 참이므로 범인은 을입니다. 그러면 병은 거짓, 정은 참입니다. ➔ 범인 을, 참말 갑, 정

19. [정답] ⑤ (F, B)

  • [해설]: A=1번, C=4번(A와 마주 봄). E=2번, B=5번(E와 마주 봄). D는 C(4번) 옆인 3번, 5번에 앉을 수 없으므로 남은 3번, 6번 중 6번이고, F는 3번입니다. D(6번)와 마주 보는 3번은 F, 5번은 B입니다.

20. [정답] ⑤ (9 4 8)

  • [해설]:
    1. 시도 4에서 5, 6, 7은 제외합니다.
    2. 시도 1 2 6 8은 스트라이크 1, 볼 0이고 6은 없으므로 2, 8 중 정확히 1개만 비밀번호에 있고 위치도 맞습니다. 만약 2가 맞는 숫자라면 2는 첫째 자리인데, 시도 2 2 1 4에서 2가 첫째 자리이면 스트라이크가 되어 '볼만 1개'라는 조건에 어긋납니다. 따라서 2는 제외되고 8이 셋째 자리로 확정됩니다.
    3. 시도 3 8 9 2는 볼 2개이고 2는 없으므로 8, 9가 모두 비밀번호에 있고 위치가 모두 틀립니다. 8은 셋째 자리이므로 9는 둘째 자리가 아닌 첫째 자리입니다.
    4. 시도 2 2 1 4는 볼 1개이고 2는 없으므로 1, 4 중 하나가 있고 위치가 틀려야 합니다. 남은 자리는 둘째 자리이며, 4가 둘째 자리에 있으면 시도 2의 4(셋째)와 위치가 달라 볼 1개로 조건을 만족합니다(1이 둘째 자리면 시도 2에서 스트라이크가 되어 불가). ➔ 비밀번호 9 4 8

21. [정답] ② (34)

  • [해설]: (가) 25개 동전은 3³ = 27 ≥ 25이므로 세 묶음으로 나누어 저울질하면 최소 3번입니다. (나) 원반 5개 하노이 탑은 2⁵ − 1 = 31번입니다. 합은 3 + 31 = 34입니다.

22. [정답] ① (15분)

  • [해설]: 최적 순서는 다음과 같습니다.
    1. A, B 건넘(2분) ➔ 2. A 복귀(1분) ➔ 3. C, D 건넘(8분) ➔ 4. B 복귀(2분) ➔ 5. A, B 건넘(2분)
    • 합계 2 + 1 + 8 + 2 + 2 = 15분

23. [정답] ② (45점)

  • [해설]: Dimi!1234는 9글자이므로 길이 점수는 +20점입니다. 대문자·소문자·특수기호·숫자 4종류를 모두 포함하므로 +40점입니다. 다만 추가 보너스 +15점은 10자 이상일 때만 주어지므로 9자인 이 비밀번호는 받지 못합니다. 1234는 연속 오름차순 숫자라 -15점입니다. ➔ 20 + 40 − 15 = 45점

[Part 4. 알고리즘적 문제해결력 영역 해설]

24. [정답] ④ (3, 6, 8, 4)

  • [해설]: (가)는 위에서부터 9, 4, 3, 8, 6입니다. 하나씩 꺼내 홀수는 (나), 짝수는 (다)에 넣습니다.
    • 9 ➔ (나), 4 ➔ (다), 3 ➔ (나), 8 ➔ (다), 6 ➔ (다)
    • (나) 위에서부터 3, 9, (다) 위에서부터 6, 8, 4
    • 단계 5~7: (나)의 맨 위 3을 꺼내 3의 배수이므로 (다)에 넣고 즉시 종료합니다. 9는 꺼내지 않습니다.
    • (다) 위에서부터 3, 6, 8, 4

25. [정답] ② (S = 15, CNT = 3)

  • [해설]: 2508의 일의 자리부터 처리합니다. R = 8(S 8, CNT 1), R = 0(변화 없음), R = 5(S 13, CNT 2), R = 2(S 15, CNT 3). ➔ S = 15, CNT = 3

26. [정답] ① ([1, 2, 5, 4, 3], 총 2회 교환)

  • [해설]: 처음 [4, 2, 5, 1, 3].
    • 1회전: 최솟값 1과 첫째 자리 4 교환 ➔ [1, 2, 5, 4, 3] (교환 1회)
    • 2회전: 최솟값 2가 이미 제자리 ➔ 교환 없음
    • 3회전: 3~5번째 중 최솟값 3과 5 교환 ➔ [1, 2, 3, 4, 5] (교환 2회째)
    • 4회전: 4가 이미 제자리 ➔ 교환 없음. 총 2회

27. [정답] ③ (2개, 5번)

  • [해설]:
    • [문제 A] (가) (()())(), (다) ((())())는 올바릅니다. (나) ())(()는 두 번째 )에서 열린 괄호 수가 음수가 되어 틀립니다. (라) (()()(()는 닫는 괄호가 모자랍니다. ➔ 2개
    • [문제 B] 16 MOD 7 = 2 ➔ 2번, 25 MOD 7 = 4 ➔ 4번, 9 MOD 7 = 2(충돌) ➔ 3번, 30 MOD 7 = 2(충돌) ➔ 3번(충돌), 4번(충돌), 5번에 배정됩니다.

28. [정답] ④ (경로 50 → 30 → 40 → 35 / 단말 노드 20, 35, 70)

  • [해설]: 루트 50, 30 < 50이므로 왼쪽, 70 > 50이므로 오른쪽, 20은 30의 왼쪽, 40은 30의 오른쪽, 35는 50 → 30 → 40을 지나 40의 왼쪽에 놓입니다. 방문 경로는 50 → 30 → 40 → 35이고, 자식이 없는 단말 노드는 20, 35, 70입니다(40은 자식 35가 있으므로 단말이 아님).

29. [정답] ⑤ (3회, S3)

  • [해설]: 시작 S0에서 버튼 A → A → A → B → A → A → B를 누릅니다.
    1. A: S0 → S1
    2. A: S1 → S2 (S2, 1회)
    3. A: S2 → S2 (S2, 2회)
    4. B: S2 → S3
    5. A: S3 → S1
    6. A: S1 → S2 (S2, 3회)
    7. B: S2 → S3
    • S2가 된 횟수 3회, 최종 상태 S3

30. [정답] ① (12 ms, A → C → B → E → D → F)

  • [해설]: A → C 2ms, C → B 1ms로 B까지 3ms(A → B 직통 4ms보다 빠름). B → E 4ms로 E까지 7ms, E → D 2ms로 D까지 9ms, D → F 3ms로 F까지 12ms입니다. E → F 직통은 7 + 6 = 13ms, B → D 직통은 3 + 7 + 3 = 13ms로 더 느립니다.
