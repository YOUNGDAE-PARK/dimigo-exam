Ⅰ. 컴퓨팅 시스템 (하드웨어 · 소프트웨어 · 네트워크 · 피지컬 컴퓨팅)

구분 핵심 용어 시험 출제 영문 Definition 정답 직결 스캔 키워드
HW CPU
(중앙처리장치)		 The primary component of a computer that acts as its "brain," performing arithmetic, logical, and control operations specified by instructions. brain, executes instructions, arithmetic and logical
HW RAM
(주기억장치)		 A high-speed volatile memory that temporarily stores programs and data currently in use; its contents are lost when power is turned off. volatile, temporarily stores, lost when power is off
HW ROM
(읽기전용 메모리)		 A non-volatile memory from which data can only be read; it stores startup instructions (BIOS/firmware) that remain even without power. non-volatile, read-only, startup / BIOS
HW Cache Memory
(캐시 메모리)		 A small, ultra-fast memory that stores frequently accessed data to reduce the speed gap (bottleneck) between the fast CPU and slower RAM. frequently accessed data, speed gap, between CPU and RAM
HW SSD
(보조기억장치)		 A non-volatile storage device using flash memory instead of spinning disks(HDD), offering fast read/write speeds and shock resistance. non-volatile storage, flash memory, no moving parts
SW Operating System
(운영체제, OS)		 System software that manages computer hardware and software resources and provides a user interface and common services for applications. manages hardware and software resources, system software
SW Compiler vs Interpreter
(언어 번역기)		 • Compiler: Translates the entire source code into machine code all at once.
• Interpreter: Translates and executes code line by line immediately.		 • Compiler: entire code, all at once
• Interpreter: line by line
NW Router
(라우터)		 A networking device that forwards data packets between networks and determines the optimal (best) path using IP addresses. forwards data packets, between networks, optimal / best path
NW DNS
(도메인 네임 시스템)		 A system that translates human-readable domain names (e.g., dimigo.hs.kr) into numerical IP addresses used by computers. translates domain names into IP addresses, phonebook
NW Protocol
(프로토콜)		 A standard set of rules that govern how data is formatted, transmitted, and received so devices can communicate over a network. set of rules, govern communication over a network
NW Firewall
(방화벽)		 A security system that monitors and filters incoming and outgoing network traffic to block unauthorized access. monitors traffic, blocks unauthorized access
피지컬 Sensor vs Actuator
(센서와 액추에이터)		 • Sensor (Input): Detects physical changes in the environment and converts them into signals.
• Actuator (Output): Converts control signals into physical motion or action.		 • Sensor: input, detects physical changes
• Actuator: output, physical motion

Ⅱ. 데이터 (단위 · 진법 · 멀티미디어 · 데이터 구조화)

구분 핵심 용어 시험 출제 영문 Definition 정답 직결 스캔 키워드
단위 Bit vs Byte
(비트와 바이트)		 • Bit: The smallest unit of data in a computer, representing 0 or 1.
• Byte: A group of 8 bits used to represent a single character.		 • Bit: smallest unit, 0 or 1
• Byte: group of 8 bits
수치 Binary System
(이진법 / 2진수)		 A number system used by computers that represents all data using only two digits: 0 and 1 (base-2). only two digits: 0 and 1, base-2
문자 Encoding & Unicode
(인코딩 / 유니코드)		 Encoding converts data into digital code(0s and 1s); Unicode is an international standard representing characters of all languages in the world. converts into digital code, all languages in the world
이미지 Pixel & Bitmap vs Vector
(픽셀 / 비트맵 vs 벡터)		 • Pixel: The smallest dot of a digital image.
• Bitmap: Made of a grid of pixels (loses quality when enlarged).
• Vector: Made of mathematical formulas (scales without losing quality).		 • Pixel: smallest dot
• Bitmap: grid of pixels
• Vector: mathematical formulas
압축 Data Compression
(데이터 압축)		 The process of encoding information using fewer bits than the original representation to reduce file size. fewer bits, reduce file size
분류 Structured vs Unstructured Data
(정형 vs 비정형)		 • Structured: Data organized in fixed rows and columns (tables, DB).
• Unstructured: Data with no predefined format (videos, audio, images).		 • Structured: fixed rows and columns
• Unstructured: no predefined format
관리 Database (DB)
(데이터베이스)		 An organized collection of structured data stored electronically so that it can be easily accessed, managed, and updated. organized collection of data, easily accessed and managed
활용 Big Data
(빅데이터)		 Extremely large and complex datasets (high Volume, Velocity, and Variety) that cannot be processed by traditional software. large and complex datasets, Volume, Velocity, Variety

Ⅲ. 알고리즘과 프로그래밍 (추상화 · 순서도 · 제어 구조 · 디버깅)

구분 핵심 용어 시험 출제 영문 Definition 정답 직결 스캔 키워드
설계 Abstraction
(추상화)		 The process of removing unnecessary details and focusing only on the essential features needed to solve a problem. removing unnecessary details, essential features
설계 Algorithm & Flowchart
(알고리즘 / 순서도)		 • Algorithm: A finite, step-by-step procedure for solving a problem.
• Flowchart: A visual diagram representing an algorithm using shapes and arrows.		 • Algorithm: step-by-step procedure
• Flowchart: visual diagram, shapes and arrows
설계 Pseudocode
(의사코드)		 An informal, human-readable description of an algorithm that uses programming structure without strict syntax rules. informal, human-readable description of an algorithm
저장 Variable
(변수)		 A named storage location (container) in memory whose value can change during program execution. named storage location, value can change
저장 Array / List
(배열 / 리스트)		 A data structure that stores a collection of elements sequentially, where each item is accessed by its position called an index. collection of elements sequentially, accessed by index
제어 Conditional vs Loop
(조건문 vs 반복문)		 • Conditional (if-else): Executes branches depending on whether a condition is true or false.
• Loop (for/while): Repeats a block of instructions while a condition is met.		 • Conditional: true or false branch
• Loop: repeats a block of instructions
모듈 Function
(함수)		 A reusable block of code that performs a specific task; it accepts inputs (parameters) and produces an output (return value). reusable block of code, parameters, return value
오류 Bug & Debugging
(버그와 디버깅)		 • Bug: An error or flaw in a program that produces incorrect results.
• Debugging: The process of finding and fixing errors(bugs) in code.		 • Bug: error or flaw
• Debugging: finding and fixing errors
오류 Syntax vs Logical Error
(문법 오류 vs 논리 오류)		 • Syntax Error: An error in the grammar/rules of the language that prevents the program from running.
• Logical Error: A flaw in algorithm design where the program runs without crashing but produces wrong results.		 • Syntax: grammar rules, prevents running
• Logical: runs without crashing, wrong results

Ⅳ. 인공지능 (기계학습 · 딥러닝 · 학습 데이터 · AI 윤리)

구분 핵심 용어 시험 출제 영문 Definition 정답 직결 스캔 키워드
개념 Artificial Intelligence
(인공지능, AI)		 Technology that enables computers to simulate human intelligence such as perceiving, learning, reasoning, and problem-solving. simulate human intelligence, learning and reasoning
개념 Machine Learning
(기계학습, ML)		 A subset of AI that enables computers to learn patterns from data automatically and improve without being explicitly programmed. learn from data, without being explicitly programmed
개념 Deep Learning
(딥러닝)		 An advanced machine learning technique that uses multi-layered artificial neural networks modeled after the human brain. artificial neural networks, human brain
유형 Supervised Learning
(지도학습)		 A machine learning method that trains a model using labeled data (inputs paired with the known correct answers). labeled data, known correct answers
유형 Unsupervised Learning
(비지도학습)		 A machine learning method that discovers hidden patterns or groups (clusters) in unlabeled data without predefined answers. unlabeled data, hidden patterns / clusters
유형 Reinforcement Learning
(강화학습)		 A learning method where an agent learns optimal actions through trial and error to maximize cumulative rewards. trial and error, maximize rewards
데이터 Training vs Test Data
(훈련 vs 테스트 데이터)		 • Training Data: Data used to train (teach) an AI model.
• Test Data: Separate, unseen data used to evaluate the accuracy of the model.		 • Training: train / teach
• Test: unseen data, evaluate accuracy
최신 Generative AI & Hallucination
(생성형 AI와 환각)		 • Generative AI: AI capable of generating new content (text, images).
• Hallucination: When an AI generates false or fabricated information as fact.		 • Generative: generating new content
• Hallucination: false / fabricated information
윤리 Algorithmic Bias
(알고리즘/데이터 편향)		 Systematic and unfair discrimination in AI outputs caused by prejudiced or unbalanced training data. unfair discrimination, unbalanced training data

Ⅴ. 디지털 문화 (디지털 사회 기술 · 사이버 범죄 · 암호화 · 저작권)

구분 핵심 용어 시험 출제 영문 Definition 정답 직결 스캔 키워드
기술 IoT (Internet of Things)
(사물인터넷)		 A network of physical objects ("things") embedded with sensors and software that connect and exchange data over the Internet. physical objects, sensors, exchange data over the Internet
기술 Cloud Computing
(클라우드 컴퓨팅)		 The delivery of computing services (storage, servers, software) over the Internet ("the cloud") on demand, rather than on a local hard drive. computing services over the Internet, on demand
위협 Malware
(악성코드)		 Malicious software specifically designed to disrupt, damage, or gain unauthorized access to a computer system. malicious software, disrupt or damage
위협 Ransomware
(랜섬웨어)		 A type of malware that encrypts a victim's files and demands payment (ransom) in exchange for restoring access to the data. encrypts files, demands payment (ransom)
위협 Phishing
(피싱)		 A cyberattack that uses disguised emails or messages pretending to be a trusted institution to trick users into revealing sensitive information. disguised emails, trick into revealing sensitive info
위협 DDoS Attack
(분산 서비스 거부)		 A cyberattack that floods a target server with overwhelming traffic from multiple compromised computers, making the service unavailable. floods a server, overwhelming traffic, unavailable
보안 CIA Triad
(기밀성·무결성·가용성)		 • Confidentiality(기밀성): Only authorized users can access data.
• Integrity(무결성): Data is accurate and not improperly modified.
• Availability(가용성): Systems and data are accessible when needed.		 • Conf: only authorized access
• Integ: not modified
• Avail: accessible when needed
보안 Encryption vs Decryption
(암호화와 복호화)		 • Encryption: Converting readable plaintext into unreadable ciphertext.
• Decryption: Converting ciphertext back into readable plaintext.		 • Encryption: plaintext into ciphertext
• Decryption: ciphertext back into plaintext
보안 Public-Key Encryption
(공개키/비대칭키 암호화)		 An encryption system that uses two different keys: a public key shared with everyone to encrypt data, and a private key kept secret to decrypt it. two different keys, public key and private key
권리 Open Source Software
(오픈소스 소프트웨어)		 Software released with its source code made publicly available so that anyone can inspect, modify, and redistribute it. source code publicly available, modify and redistribute
