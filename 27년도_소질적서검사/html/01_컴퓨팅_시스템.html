Ⅰ. 컴퓨팅 시스템 (디미고 소질·적성검사 핵심 요약)

디미고 실전 출제 유형 3가지:
① 기억장치·SW 선지 정오 판별 (휘발성 유무, 속도 순서, 컴파일러 vs 인터프리터)
② 네트워크 장비 역할 매칭 (DNS, 라우터, 방화벽의 작동 순서와 역할)
③ 피지컬 컴퓨팅 센서 조건표 추론 (센서 측정값 표를 보고 액추에이터가 작동하는 횟수·시점 찾기)

1.2 기억장치 속도 계층 및 휘발성 비교 (★출제 1순위)

▲ 속도 빠름 / 용량 작음

▼ 속도 느림 / 용량 큼 		1위: 레지스터 (Register) — CPU 내부 연산용 임시 저장
2위: 캐시 메모리 (Cache) — CPU와 RAM 사이 속도 병목 해소
3위: 주기억장치 (RAM) — 현재 실행 중인 작업 공간 		휘발성 (Volatile)
전원이 꺼지면 데이터 소멸
예외 및 영구 저장 • 주기억장치 (ROM) — 부팅 정보(BIOS) 저장, 읽기 전용
• 보조기억장치 (SSD > HDD) — 대용량 파일 영구 보관 		비휘발성 (Non-Volatile)
전원이 꺼져도 데이터 유지
  • RAM vs ROM: RAM은 읽고 쓰기가 가능한 휘발성 작업 공간이고, ROM은 부팅 정보(BIOS)가 담긴 비휘발성 읽기 전용(Read-Only) 메모리입니다.
  • SSD vs HDD: SSD는 반도체(플래시 메모리)를 사용하여 회전 원판을 쓰는 HDD보다 속도가 훨씬 빠르고 소음·충격에 강합니다.
  • 시험 직결 오답 함정 3가지:
    1. "RAM 용량을 늘리면 영구 저장할 수 있는 파일 공간이 늘어난다." → ❌ 거짓 (영구 저장은 SSD/HDD 역할, RAM은 동시 실행 작업 공간)
    2. "캐시 메모리는 보조기억장치와 주기억장치 사이의 속도 차이를 줄여준다." → ❌ 거짓 (CPU와 주기억장치(RAM) 사이의 속도 차이를 줄여줌)
    3. "ROM은 전원이 꺼지면 저장된 BIOS 정보가 사라진다." → ❌ 거짓 (ROM은 비휘발성 읽기 전용 메모리)

2. 소프트웨어(SW)와 운영체제(OS)

응용 소프트웨어 (Application SW) 사용자가 특정 목적을 위해 쓰는 프로그램 (웹 브라우저, 문서 작성, 게임, 모바일 앱)
시스템 소프트웨어 (System SW) 하드웨어를 제어하고 응용 SW 실행 기반 제공 (운영체제 OS: Windows, macOS, Linux, Android, iOS / 언어 번역기: 컴파일러, 인터프리터)
하드웨어 (Hardware) CPU, 주기억장치(RAM), 보조기억장치(SSD), 입출력장치 등 물리적 기계 장치
  • 운영체제(OS)의 핵심 역할: 하드웨어 자원(CPU, RAM) 효율적 배분·관리, 멀티태스킹 프로세스 제어, 사용자 인터페이스(UI) 제공
  • 언어 번역기 1초 구분 (인간이 작성한 소스 코드 → 기계어 0, 1 번역):
    • 컴파일러 (Compiler): 코드 전체를 한 번에 번역하여 실행 파일 생성 (번역 후 실행 속도 빠름)
    • 인터프리터 (Interpreter): 코드를 한 줄씩(Line by Line) 읽으며 즉시 번역·실행 (별도 실행 파일 없음, 수정·오류 확인 용이)

4. 피지컬 컴퓨팅 시스템 (입출력 조건 추론)

1. 입력: 센서 (Sensor)
외부 환경 변화 감지
• 조도(밝기), 초음파(거리)
• 온도, 습도, 소리, 적외선
──▶
측정값
2. 처리: 제어장치 (보드)
조건문(IF-ELSE) 판단
센서값을 기준값과 비교해
작동 여부 결정
──▶
제어신호
3. 출력: 액추에이터
물리적 동작/신호 출력
• 모터(회전·개폐), LED(점등)
• 부저(경고음), 화면 표시

★ 실전 출제 유형: 센서 조건표 판독법

  • 출제 방식: "조도 센서 값 ≤ 30 이고(AND) 초음파 거리 ≤ 50cm 일 때만 LED를 켠다" 같은 제어 규칙과 시간대별 센서 측정표를 주고 LED가 켜지는 시각을 고르게 합니다.
  • 풀이 공식:
    1. 조건을 만드는 측정 부품(조도·초음파·온도)은 무조건 센서(입력), 결과로 움직이는 부품(LED·모터·부저)은 무조건 액추에이터(출력)로 분류합니다.
    2. 표 옆에 각 조건의 만족 여부(O, X)를 적은 뒤, AND(둘 다 O)인지 OR(하나라도 O)인지 확인하여 개수를 셉니다.
