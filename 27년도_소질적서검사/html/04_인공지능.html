Ⅳ. 인공지능 (디미고 소질·적성검사 핵심 요약)

디미고 실전 출제 유형 4가지:
① 전통적 프로그래밍(규칙 기반) vs 기계학습(데이터 기반) 입출력 빈칸 추론
② 기계학습 3대 유형(지도[분류/회귀] · 비지도[군집] · 강화학습) 사례 매칭
③ 의사결정나무(Decision Tree) 조건 분기 추적 및 훈련/테스트 데이터 분리 원칙
④ AI 윤리 쟁점(데이터 편향성, 생성형 AI 환각 현상) 판별

1. 인공지능(AI)의 개념과 학습 원리

1.1 인공지능 · 기계학습 · 딥러닝 포함 관계와 지능 에이전트

인공지능 (AI: 인간의 인식·학습·추론 능력을 컴퓨터로 구현한 기술)
기계학습 (Machine Learning): 컴퓨터가 데이터로부터 스스로 패턴과 규칙을 찾아 학습하는 기술
딥러닝 (Deep Learning): 인간 뇌 신경망을 모방한 '인공신경망'으로 대규모 데이터를 심층 학습하는 기술
  • 지능 에이전트 (Intelligent Agent): 목표 달성을 위해 주변 환경을 인식(센서) → 학습·추론(판단) → 자율적으로 행동(액추에이터)하는 시스템
  • 일반 자동화 SW vs 인공지능 SW 구별: 사람이 정해준 고정 조건(온도 ≥ 28도면 에어컨 켜기)만 그대로 수행하면 일반 프로그램이고, 축적된 데이터를 통해 스스로 규칙을 개선·학습하면 인공지능입니다.

1.2 전통적 프로그래밍 vs 기계학습 구조 비교 (★출제 1순위)

구분 컴퓨터에 넣어주는 입력 (Input) 컴퓨터가 만들어내는 출력 (Output)
① 전통적 프로그래밍
(규칙 기반)		 [ 데이터 ] + [ 사람이 직접 만든 규칙 ] [ 결과 (정답) ]
② 기계학습
(데이터 기반 학습)		 [ 대량의 데이터 (및 결과값) ] [ 학습된 규칙 (AI 모델) ]

2. 기계학습(Machine Learning) 3대 유형과 의사결정나무

2.1 기계학습 3대 유형 1초 판별표

학습 유형 핵심 구분 기준 (1초 키워드) 세부 방법 및 시험 빈출 사례
지도학습
(Supervised)		 문제(데이터) + 정답(Label)을 함께 주고 학습시킴 • 분류 (Classification): 딱 떨어지는 종류/집단 구분 (스팸 메일 판별, 개/고양이 사진 구분, 손글씨 숫자 인식)
• 회귀 (Regression): 연속적인 숫자/수치 예측 (내일 기온 예측, 집값·전력 소비량 예측)
비지도학습
(Unsupervised)		 정답(Label) 없이 데이터만 주고 비슷한 특징끼리 스스로 묶게 함 • 군집 (Clustering): 마트 고객을 구매 성향이 유사한 그룹으로 묶기, 비슷한 주제의 뉴스 기사끼리 자동 그룹화
강화학습
(Reinforcement)		 정답 없이 시행착오를 겪으며 보상(Reward)을 최대화하는 행동 학습 • 바둑 AI(알파고), 자율주행차 주행 제어, 이족보행 로봇 걸음마 학습, 게임 클리어 AI

2.2 ★ 실전 추론 유형: 의사결정나무 (Decision Tree) 분류 추적

[ 질문 1: 날개가 있는가? ]
├── 예(Yes) ──▶ [ 질문 2: 하늘을 나는가? ] ──▶ (예: 참새 / 아니오: 펭귄)
└── 아니오(No) ──▶ [ 결과: 포유류 (강아지) ]
※ 표로 주어진 대상의 속성값을 보고 위에서부터 예/아니오 화살표를 정확히 따라가며 분류 결과를 찾습니다.

    • "모델의 정확도를 평가할 때 학습에 사용했던 훈련 데이터를 그대로 사용한다." → ❌ 거짓! 반드시 학습에 사용하지 않은 새로운 데이터(테스트 데이터)로 분리하여 평가해야 합니다.

3.2 인공지능의 한계와 윤리적 쟁점

  1. 데이터 편향성 (Algorithmic Bias): 특정 성별·인종·연령에 치우친 데이터를 학습하면 AI도 차별적·불공정한 결과를 내놓습니다.
  2. 환각 현상 (Hallucination): 생성형 AI가 사실이 아닌 거짓 정보를 마치 사실인 것처럼 그럴듯하게 지어내어 답변하는 현상입니다.
  3. 개인정보·저작권 침해 및 책임 소재: 학습 데이터 무단 수집, 딥페이크(Deepfake) 악용, 자율주행 사고 시 책임 주체 문제가 발생합니다.
