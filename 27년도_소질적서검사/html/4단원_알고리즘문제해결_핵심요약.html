1. 순서도(Flowchart) 필수 공식 · 디버깅 함정 · 변수 추적표

1.1 순서도 빈칸 채우기 & 논리 오류(디버깅) 4대 공식

알고리즘 목적 핵심 순서도 식 / 조건식 작동 원리 및 ★오답 함정 주의점
두 변수 값 교환 (SWAP) TEMP ← A ➔ A ← B ➔ B ← TEMP 임시 상자(TEMP)를 이용해 대각선 꼬리물기 순서로 교환 (TEMP 없이 A ← B를 먼저 하면 기존 A 값이 증발함!)
조건 만족 개수 세기 조건이 참일 때 CNT ← CNT + 1 배수·약수·특정 조건을 통과할 때마다 카운트 변수를 1씩 증가
최댓값(MAX) /
최솟값(MIN)		 • 최댓값: < A[i] > MAX ? > ➔ MAX ← A[i]
• 최솟값: < A[i] < MIN ? > ➔ MIN ← A[i] 		⚠️ [초기값 오류 함정]: 양수 배열 [10, 30, 20]에서 최솟값을 찾을 때 MIN ← 0으로 초기화하면 영원히 0이 출력되는 논리 오류 발생! 반드시 첫 번째 원소(MIN ← A[0])로 초기화해야 함!
자릿수 분리 합산 • 일의 자리 추출: N을 10으로 나눈 나머지
• 일의 자리 제거: N을 10으로 나눈 몫 		예: N = 358 ➔ 나머지 8 추출 후 몫 35로 갱신하며 각 자릿수 합(3+5+8=16) 계산

1.2 다중 변수 WHILE 루프 & 2중 FOR 루프 변수 추적표 (Trace Table)

머리로 암산하지 말고 시험지 여백에 변수 이름을 가로줄로 적은 표(Trace Table)를 그려 한 줄씩 값을 갱신합니다.

[예제 1] 두 변수가 동시에 변하는 WHILE 루프
A = 1, B = 10, CNT = 0
WHILE (A < B) { A = A + 3; B = B - 1; CNT = CNT + 1 }
단계 A B CNT 조건 (A < B)
초기값 1 10 0 1 < 10 (참)
1회차 후 4 9 1 4 < 9 (참)
2회차 후 7 8 2 7 < 8 (참)
3회차 후 10 7 3 10 < 7 (거짓 ➔ 종료)
[예제 2] 2중 중첩 FOR 루프 (i=1~3, j=1~2)
SUM = 0
FOR i = 1 TO 3 {
  FOR j = 1 TO 2 { SUM = SUM + (i * j) }
}
• 시침(i)이 1번 돌 때 분침(j)은 끝까지 다 돕니다!
  - i = 1 일 때: (1×1) + (1×2) = 1 + 2 = 3
  - i = 2 일 때: (2×1) + (2×2) = 2 + 4 = 6
  - i = 3 일 때: (3×1) + (3×2) = 3 + 6 = 9
• 총 실행 횟수: 3 × 2 = 6회
• 최종 SUM 출력값: 3 + 6 + 9 = 18!

2. 핵심 자료구조 시뮬레이션: 스택 · 큐 · 재귀 함수

2.1 스택(Stack) vs 큐(Queue) 입출력 시뮬레이션

① 스택 (Stack): LIFO (후입선출)
• "마지막에 들어간 것이 가장 먼저 나온다!"
• 입력 1→2→3 ➔ 출력 3→2→1 (역순)
• 예시: 웹브라우저 뒤로가기, 실행 취소(Ctrl+Z), 프링글스 통
② 큐 (Queue): FIFO (선입선출)
• "먼저 줄 선 것이 가장 먼저 나간다!" (양쪽 뚫린 터널)
• 입력 1→2→3 ➔ 출력 1→2→3 (순서 그대로)
• 예시: 프린터 인쇄 대기열, 매표소 줄서기, 은행 번호표
  • ★ 스택(Stack) 불가능한 출력 순서 5초 판별 공식:
    • 1, 2, 3, 4를 순서대로 넣었다 뺄 때, 큰 수 K가 먼저 나왔다면 아직 안 나온 작은 수들은 이미 통 안에 순서대로 깔려 있으므로 반드시 큰 수부터 작은 수(내림차순) 순서로만 나와야 합니다!
    • ⭕ 2 → 1 → 4 → 3 (가능)  /  ❌ 4 → 2 → 3 → 1 (절대 불가능! 4가 나온 뒤에는 3이 무조건 2보다 먼저 나와야 함)

2.2 재귀 함수(Recursion, 자기 호출 함수) 손추적법

함수 안에서 자기 자신을 다시 부르는 코드는 가장 작은 종료 조건(바닥값, 예: f(1))부터 위로 거꾸로 대입하면 10초 만에 풀립니다.

  • 예: f(1) = 2이고, n > 1일 때 f(n) = 2 × f(n - 1) + 1이라면 f(4)의 값은?
    ➔ 바닥부터 역산: f(1) = 2 ──▶ f(2) = 2×2 + 1 = 5 ──▶ f(3) = 2×5 + 1 = 11 ──▶ f(4) = 2×11 + 1 = 23!

3. 정렬(Sorting) 전체 회전 손추적 & 이진 탐색

3.1 3대 정렬 알고리즘 회전(Pass)별 전체 상태 변화 (★빈출)

초기 배열 [ 5, 3, 4, 1, 2 ](원소 5개)를 오름차순(1, 2, 3, 4, 5)으로 정렬할 때, 1회전부터 최종 정렬 완료(4회전)까지 배열이 변하는 전 과정을 완벽히 구분해야 합니다.

정렬 방식 핵심 규칙 (손추적 방법) 회전(Pass) 종료 시 확정되는 위치
선택 정렬
(Selection Sort)		 남은 숫자 중 가장 작은 값(최솟값)을 찾아 앞자리와 단 1번 맞바꿈(Swap) 맨 앞자리부터 1개씩 작은 수가 차례로 확정됨

(Bubble Sort)		 이웃한 두 숫자를 처음부터 끝까지 차례로 비교해 앞이 더 크면 즉시 교환 맨 뒷자리부터 1개씩 큰 수가 차례로 확정됨
삽입 정렬

3.2 이진 탐색 (Binary Search, 업다운 탐색)

  • 전제 조건: 데이터가 반드시 오름차순 또는 내림차순으로 정렬되어 있어야만 사용할 수 있습니다!
  • 작동 원리: 탐색 범위의 정가운데 값(중간값)과 찾는 값을 비교하여, 한 번 비교할 때마다 탐색 범위를 절반(1/2)씩 버립니다.
    • 예: [ 10, 20, 30, 40, 50, 60, 70 ]에서 60을 찾을 때 비교 순서:
      1차 중간값 40 (60 > 40이므로 왼쪽 절반 버림, [50, 60, 70] 남음) ➔ 2차 중간값 60 일치! (총 2회 비교)
  • 최대 비교 횟수 공식: 데이터가 N개일 때 최악의 경우 비교 횟수는 2ᵏ ≥ N을 만족하는 최소 자연수 k번입니다 (N=64이면 2⁶=64이므로 최대 6~7회, N=100이면 2⁷=128이므로 최대 7회).

4. 논리 연산 상자 연결 & 비버챌린지형 4대 실전 퍼즐

4.1 논리 연산 상자(AND · OR · NOT · XOR) 연결 추적

• 4대 기본 논리 상자 규칙:
  - AND (논리곱): 두 입력이 둘 다 1일 때만 1 출력
  - OR (논리합): 두 입력 중 하나라도 1이면 1 출력
  - NOT (부정): 입력을 반대로 뒤집음 (1 ↔ 0)
  - XOR (배타적 논리합): 두 입력이 서로 다를 때만 1 출력
• 실전 요령: 상자를 통과한 직후 연결선 위에 0, 1을 직접 적으며 추적!
[실전 연결 추적: A=1, B=0, C=1 일 때 최종 출력 Y]

4.2 유한 상태 전이도 (화살표 길 찾기) & 가중치 그래프 최단 거리

① 유한 상태 전이도 ('A ➔ B ➔ A' 입력 추적)
• 출발 [S0] ──(A)──▶ [S1] ──(B)──▶ [S2] ──(A)──▶ 최종 [S1] 도착!
② 가중치 그래프 최단 거리 (A ➔ D 최소 시간)
• A→B→D (2+5=7분) vs A→C→D (6+2=8분) vs A→B→C→D (2+1+2=5분, 최단!)

4.3 2D 격자판 로봇 이동 시뮬레이션 (좌표 · 방향 추적)

  • ★ 실수 방지 핵심: 로봇의 좌회전(L, 왼쪽 90도) / 우회전(R, 오른쪽 90도) 명령은 칸을 이동하지 않고 제자리에서 바라보는 방향 화살표(▲ 북, ▶ 동, ▼ 남, ◀ 서)만 바꿉니다!
    • 예: (0, 0)에서 동쪽(▶)을 보고 시작해 F(전진) - L(좌회전) - F(전진)을 수행하면?
      (0,0) ▶ ──(F)──▶ (1,0) ▶ ──(L: 북쪽으로 회전!)──▶ (1,0) ▲ ──(F)──▶ (1,1) ▲ 도착!
