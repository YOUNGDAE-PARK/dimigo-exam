1. 조건 문장 추론과 꼬리물기 (삼단논법)

1.1 조건 문장 뒤집기 절대 법칙 ("P이면 Q이다" ➔ "Q가 아니면 P가 아니다")

조건 문장 "P이면 Q이다 (P → Q)"가 참일 때, 유일하게 100% 참이 보장되는 문장은 앞뒤를 바꾸면서 동시에 부정한 "Q가 아니면 P가 아니다 (~Q → ~P)"뿐입니다!

[원래 조건 (참)] : "코딩 동아리 부원(P)이면 노트북을 가지고 있다(Q)."  ( P ──▶ Q )
• ❌ 앞뒤만 바꿈 (Q → P) : "노트북이 있으면 코딩 동아리이다." (참인지 알 수 없음! 오답 함정 1순위)
• ❌ 단순 부정 (~P → ~Q) : "코딩 동아리가 아니면 노트북이 없다." (참인지 알 수 없음! 오답 함정 2순위)
• ⭕ 뒤집어 부정 (~Q → ~P, 대우 관계): "노트북이 없으면(~Q) 코딩 동아리 부원이 아니다(~P)." (무조건 100% 참!)

1.2 징검다리 꼬리물기 추론 (삼단논법 사슬 연결)

복잡한 조건 문장 3~4개가 주어지고 "다음 중 반드시 참인 것은?"을 물으면, 각 문장과 뒤집어 부정한 문장(~Q → ~P)을 화살표로 길게 연결합니다.

[주어진 조건]
• (가) A가 참석하면 B도 참석한다. ──▶ A ──▶ B  (뒤집기: ~B ──▶ ~A)
• (나) C가 참석하지 않으면 B도 안 한다. ──▶ ~C ──▶ ~B  (뒤집기: B ──▶ C)
• (다) C가 참석하면 D는 참석하지 않는다. ──▶ C ──▶ ~D  (뒤집기: D ──▶ ~C)
[화살표 사슬 하나로 잇기]
• 정방향 사슬 : A ──▶ B ──▶ C ──▶ ~D  ➔ 결론 1: "A가 참석하면 D는 참석하지 않는다."
• 역방향 사슬 : D ──▶ ~C ──▶ ~B ──▶ ~A  ➔ 결론 2: "D가 참석하면 A는 참석하지 않는다."

1.3 조건 부정 뒤집기(그리고 ↔ 또는, 모두 ↔ 적어도 한 명) & 카드 뒤집기

규칙 구분 핵심 변환 공식 (오답 함정 주의!) 실전 예시
그리고(AND) / 또는(OR)
조건을 어긴 경우		 • "A 그리고 B" 위반 = ~A 이거나(OR) ~B
• "A 또는 B" 위반 = ~A 이고(AND) ~B 		• "수학 또는 코딩 보충에 참여해라"를 어긴 경우:
  ➔ "수학도 안 가고(AND) 코딩도 안 갔다"
모두 / 어떤
문장의 반대(부정)		 • "모든 학생이 ~이다"가 거짓 = "적어도 1명은 ~이 아니다"
(주의: "모두 ~이 아니다"로 고르면 100% 오답!)		 • "모든 학생이 안경을 썼다"가 거짓이면?
  ➔ "안경을 쓰지 않은 학생이 적어도 1명 있다"
규칙 확인 카드 뒤집기
("P이면 Q이다" 검증)		 규칙 "앞면이 P이면 뒷면은 Q이다" 확인할 때:
➔ ① P 카드 와 ② Q가 아닌 카드(위반) 2장만 뒤집음		 • "모음(P) 뒷면엔 짝수(Q)" (바닥: [A] [B] [2] [7])
  ➔ 모음 [ A ] 와 홀수 [ 7 ] 딱 2장만 뒤집음!

2. 참말쟁이 · 거짓말쟁이 진위 판별 퍼즐

2.1 유형 ①: 참말/거짓말 인원수가 주어질 때 ➔ '모순 쌍(반대말)' 먼저 찾기!

[실전 예제] 유리창을 깬 범인은 1명이고, 네 사람 중 '오직 1명만 참말'을 하고 나머지 3명은 거짓말을 한다.
• A: "나는 안 깼어요."  |  • B: "C가 유리창을 깼어요."  |  • C: "B는 거짓말을 하고 있어요."  |  • D: "C가 깬 게 맞아요."
[풀이 과정]
1) [모순 쌍 발견] B와 C는 서로 정반대 주장을 하므로 둘 중 1명은 무조건 참말, 1명은 무조건 거짓말입니다.
2) 참말을 하는 단 1명은 반드시 {B, C} 안에 있으므로, 나머지 A와 D의 말은 무조건 거짓말(F)로 확정됩니다!
3) A의 말("나는 안 깼어요")이 거짓말이므로 ──▶ 실제 유리창을 깬 범인은 A! (10초 컷 해결)

2.2 유형 ②: 참말쟁이(기사)와 거짓말쟁이(건달) ➔ '가정 검증법(귀류법)'

참말 인원수가 안 주어지고 "우리 둘 중 적어도 한 명은 건달이다"처럼 스스로를 포함한 진술이 나오면, 발언자 A가 참말쟁이(T)인 경우와 거짓말쟁이(F)인 경우 2가지를 가정하여 모순이 없는 쪽을 고릅니다.

[실전 예제] A와 B를 만났는데, A가 "우리 둘 중 적어도 한 명은 건달(거짓말쟁이)입니다"라고 말했다.
• 가정 1 (만약 A가 건달[거짓말쟁이]이라면?): A 자신이 이미 건달이므로 "적어도 한 명은 건달이다"라는 말은 '참말'이 되어버림! (건달이 참말을 했으므로 모순 ❌)
• 가정 2 (만약 A가 기사[참말쟁이]라면?): A의 말이 참이 되려면 둘 중 적어도 한 명은 건달이어야 하므로, B가 건달이면 완벽히 성립!
  ──▶ 정답: A는 기사(참말쟁이), B는 건달(거짓말쟁이)! ⭕

3. O/X 그리드 매칭 & 일렬 · 원탁 자리 배치 퍼즐

3.1 O/X 매트릭스 십자(+) 소거법 (1:1 매칭 퍼즐)

1:1 매칭 퍼즐은 표를 그려 O가 하나 확정될 때마다 그 칸의 가로줄·세로줄 전체를 X로 지우면 빈칸이 연쇄적으로 풀립니다.

구분 웹툰 해킹 AI 단계별 십자(+) 소거 추론 과정
갑 X X O 3단계: 남은 빈칸에 갑 = AI(O) 자동 확정!
을 O X X 2단계: 단서 "AI 학생은 을보다 키가 크다(을 ≠ AI)" ➔ 을 = 웹툰(O) 확정!
병 X O X 1단계: 단서 "병은 해킹 동아리다" ➔ 병 = 해킹(O) 확정 즉시 가로·세로줄 모두 X 소거!

3.2 일렬 순서 배치 & 원탁(마주보기) 배치 도식화 요령

① 일렬 배치 / 달리기 등수 / 층별 배정
• 빈 슬롯 먼저 그리기: [ 1 ] [ 2 ] [ 3 ] [ 4 ]
• "D는 A 바로 다음이다" ──▶ [ A D ] 묶음 블록!
• "A와 C 사이에 1명" ──▶ [ A □ C ] 또는 [ C □ A ]
• "A는 1등도 꼴찌도 아님" ──▶ 2등 또는 3등으로 압축!
② 6인 원탁(정육각형) 마주보기 배치
• 마주보는 짝:
  1↔4, 2↔5, 3↔6
• 기준 인물을 1번 자리에 먼저 고정하고 시계 방향으로 채움!

4. 전략 게임 · 고전 퍼즐 · 국어 · 영어 교과융합 독해법

4.1 3대 고전 수리·논리 퍼즐 (필승 게임 · 하노이 탑 · 강 건너기)

퍼즐 유형 핵심 해결 원리 및 10초 공식
필승 숫자/바둑돌 게임
(베스킨라빈스 31형)		 • 한 번에 1개 ~ K개까지 가져갈 수 있을 때, 상대방이 몇 개를 부르든 내 턴과 합쳐 항상 (1 + K)개씩 맞추면 무조건 승리합니다!
• 예: 돌 20개 중 한 번에 1~3개 가져가고 마지막 돌을 가져가는 사람이 승리할 때 ➔ 묶음 단위는 1 + 3 = 4개. 상대가 1개 가져가면 나는 3개, 상대가 2개 가져가면 나는 2개를 가져가서 4의 배수를 유지!
하노이 탑 최소 이동
(Tower of Hanoi)		 • 크기순으로 쌓인 원반 n개를 규칙에 맞게 다른 기둥으로 모두 옮기는 최소 이동 횟수 = 2ⁿ - 1회
• 자주 나오는 암기값: 원반 3개 = 7회, 원반 4개 = 15회, 원반 5개 = 31회
강 건너기 / 손전등 퍼즐
(병목 조건 해결)		 • 먹이사슬 충돌형(늑대·양·양배추): 둘만 남겨두면 안 되는 핵심 매개체(양)를 먼저 건네고, 돌아올 때 다시 데려오는 왕복을 활용합니다.
• 다리 건너기 시간 단축형(1분, 2분, 5분, 10분): 가장 느린 두 사람(5분, 10분)이 반드시 함께 건너야 시간을 아낄 수 있으므로, 가장 빠른 두 사람(1분, 2분)을 먼저 보내 손전등 배달부로 활용합니다 (최소 17분).

융합 영역 시험장 10초 실전 공략법
국어 융합 독해
(요금 할인 · 포인트 · 비밀번호 · 부호화 규칙)		 1. 경계값 동그라미 표시: 이상 / 이하 / 부터 / 까지(포함 ●) vs 초과 / 미만(제외 ○)
2. 예외·단서 조항 밑줄: "단, ~인 경우는 제외한다", "중복 할인 불가", "최대 한도"
3. 질문 사례 먼저 확인: 지문을 다 외우지 말고 문제에서 묻는 사례(예: "14세 청소년, 주말 오전, 3매")를 먼저 본 뒤 해당 조건 줄만 찾아 대입!
영어 융합 독해
(IT 용어 · 보안 · 네트워크 · AI 영문 지문)		 • 영문 지문 전체를 완벽히 번역하려 하지 말고, 정답과 직결되는 핵심 동사·명사 키워드를 찾아 1:1 매칭합니다:
  - forwards data packets / optimal path ──▶ Router (라우터)
  - domain name to IP address ──▶ DNS
  - block unauthorized access / traffic ──▶ Firewall (방화벽)
  - encrypts files and demands ransom ──▶ Ransomware (랜섬웨어)
  - learns from data without being explicitly programmed ──▶ Machine Learning (기계학습)
