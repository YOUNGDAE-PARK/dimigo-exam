## Part 1. 데이터 표현 · 진법 · 압축 · 네트워크 계산 (1번 ~ 10번)

**1. [정답] ②**
* **핵심 개념**: 1의 보수와 2의 보수 변환
* **상세 해설**:
  * **1의 보수(`A`)**: 주어진 2진수의 모든 비트를 `0 → 1`, `1 → 0`으로 반전합니다. 따라서 `10110100₂`의 1의 보수는 `01001011₂`입니다.
  * **2의 보수(`B`)**: 1의 보수에 `1`을 더합니다. `01001011₂ + 1 = 01001100₂`입니다.
* **함정 주의**: 1의 보수만 구하고 멈추거나, 2의 보수를 구할 때 맨 뒤 비트에 `1`을 더한 자리올림(`1 + 1 = 10₂`)을 빼먹지 않도록 주의하세요.

---

**2. [정답] ③**
* **핵심 개념**: 2진수 ↔ 8진수(3자리 묶음) / 16진수(4자리 묶음) 변환
* **상세 해설**:
  * **8진수(`X`)**: 오른쪽부터 3자리씩 끊으면 `110 | 101 | 110 | 110`입니다. 각각 `6, 5, 6, 6`이므로 `X = 6566(8)`이며, 각 자리 숫자의 합은 `6 + 5 + 6 + 6 = 23`입니다.
  * **16진수(`Y`)**: 오른쪽부터 4자리씩 끊으면 `1101 | 0111 | 0110`입니다. `1101₂ = 13 = D`, `0111₂ = 7`, `0110₂ = 6`이므로 `Y = D76(16)`입니다.
* **함정 주의**: 16진수 변환 시 `10=A, 11=B, 12=C, 13=D, 14=E, 15=F` 대응을 정확히 확인하세요.

---

**3. [정답] ③**
* **핵심 개념**: 16진수 → 10진수 변환 및 시간 단위 환산
* **상세 해설**:
  * 16진수 `2B7`의 각 자리값은 `16² = 256`, `16¹ = 16`, `16⁰ = 1`입니다.
  * `B = 11`이므로 10진수 초로 바꾸면 `(2 × 256) + (11 × 16) + 7 = 512 + 176 + 7 = 695초`입니다.
  * `695 ÷ 60 = 몫 11, 나머지 35`이므로 남은 시간은 **11분 35초**입니다.

---

**4. [정답] ①**
* **핵심 개념**: 16진수 RGB 색상 코드 연산
* **상세 해설**:
  * 각 채널을 두 자리씩 분리하여 10진수로 바꾼 뒤 평균을 구하고 다시 16진수로 변환합니다.
  * **R**: `28(16) = 40`, `48(16) = 72` → 평균 `(40 + 72) ÷ 2 = 56 = 38(16)`
  * **G**: `64(16) = 100`, `A4(16) = 164` → 평균 `(100 + 164) ÷ 2 = 132 = 84(16)`
  * **B**: `C0(16) = 192`, `E0(16) = 224` → 평균 `(192 + 224) ÷ 2 = 208 = D0(16)`
  * 따라서 결과 색상 코드는 `#3884D0`입니다.

**5. [정답] ③**
* **핵심 개념**: 색 깊이(`n`비트 → `2ⁿ`색)와 비압축 이미지 용량
* **상세 해설**:
  * **ㄱ (O)**: `2⁴ = 16`가지 색을 표현할 수 있습니다.
  * **ㄴ (X)**: 색의 수가 `4배(= 2²)`가 되려면 비트 수는 4비트가 아니라 **2비트**만 늘리면 됩니다.
  * **ㄷ (O)**: 해상도가 같으면 이미지 용량은 화소당 비트 수에 비례하므로 `24 ÷ 8 = 3배`입니다.
  * **ㄹ (O)**: 전체 화소 수가 `2 × 2 = 4배`가 되고, 화소당 비트 수가 `16 ÷ 8 = 2배`가 되므로 전체 용량은 `4 × 2 = 8배`가 됩니다.

**6. [정답] ②**
* **핵심 개념**: 허프만 부호화(가변 길이 압축)와 고정 길이 비교
* **상세 해설**:
  * 문자열 `ABAACABADA`에서 각 글자의 개수는 `A: 6개`, `B: 2개`, `C: 1개`, `D: 1개`(총 10글자)입니다.
  * **(가) 가변 길이 전체 비트 수**: `(6 × 1) + (2 × 2) + (1 × 3) + (1 × 3) = 6 + 4 + 3 + 3 = 16비트`입니다.
  * **(나) 절약된 비트 수**: 2비트 고정 방식은 `10 × 2 = 20비트`가 필요하므로, `20 - 16 = 4비트`가 절약됩니다.

**7. [정답] ①**
* **핵심 개념**: 허프만 트리 인코딩 및 접두어 기반 복호화
* **상세 해설**:
  * 트리에서 각 문자의 부호는 `A = 1`, `B = 01`, `C = 001`, `D = 000`입니다.
  * **인코딩**: `BADCA` → `01(2) + 1(1) + 000(3) + 001(3) + 1(1) = 10비트`입니다.
  * **복호화**: `001101000`을 앞에서부터 일치하는 부호로 끊으면 `001(C) | 1(A) | 01(B) | 000(D)` → `CABD`가 됩니다.

**8. [정답] ③**
* **핵심 개념**: 런-길이 압축(RLE) 비트 계산
* **상세 해설**:
  * **원본 크기**: 14글자 × 8비트 = **112비트**입니다.
  * **압축 후 크기**: `AAAAA`(1묶음), `BBBB`(1묶음), `CCCCC`(1묶음) 총 **3개의 묶음**이 만들어지며, 한 묶음당 12비트이므로 `3 × 12 = 36비트`입니다.
  * **절약된 비트 수**: `112 - 36 = 76비트`입니다.

**9. [정답] ③**
* **핵심 개념**: 네트워크 전송 속도(`bps`)와 파일 용량(`Byte`) 단위 변환
* **상세 해설**:
  * 전송 속도는 **비트(`Mbps`)** 단위이고 파일 용량은 **바이트(`MB`)** 단위이므로 반드시 단위를 통일해야 합니다.
  * `300MB = 300 × 8 = 2,400Mb`입니다.
  * 걸리는 시간 = `2,400Mb ÷ 200Mbps = 12초`입니다.
* **함정 주의**: `300 ÷ 200 = 1.5초`로 계산하면 비트와 바이트 변환(`× 8`)을 빠뜨린 함정(①번)에 걸리게 됩니다.

**10. [정답] ④**
* **핵심 개념**: 전가산기(Full Adder) 논리 동작
* **상세 해설**:
  * 전가산기는 세 비트 `A, B, Cin`을 이진수로 더한 결과를 출력합니다.
  * `1 + 1 + 1 = 3`이며, 3을 2진수로 나타내면 `11₂`입니다.
  * 따라서 현재 자리의 합 `S = 1`, 다음 자리로 올라가는 자리올림수 `Cout = 1`입니다.

**20. [정답] ③**
* **핵심 개념**: AI 분류 모델 혼동행렬(정확도와 재현율)

* **상세 해설**:
  * 위쪽 가지 `A`와 아래쪽 가지(`B`와 `C`의 직렬 = `B AND C`)가 병렬로 연결되어 있으므로 `(A OR (B AND C))`가 됩니다.
  * 이 병렬 묶음 전체가 스위치 `D`와 직렬로 연결되므로 최종 논리식은 `(A OR (B AND C)) AND D`입니다.
  * **불이 켜지는 경우의 수**:
    * 반드시 `D = 1`이어야 합니다. (1가지)
    * `A = 1`이면 `B, C` 값에 관계없이 불이 켜집니다. → `(B, C)` 조합 `2 × 2 = 4가지`
    * `A = 0`이면 `B = 1`이고 `C = 1`이어야만 불이 켜집니다. → `1가지`
    * 따라서 총 경우의 수는 `4 + 1 = 5가지`입니다.
