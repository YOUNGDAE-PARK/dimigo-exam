# 제5단원(추가단원): 디미고 소질·적성검사 누락 핵심 완벽 보강 특강

> **[단원 개요 및 보강 목적]**  
> 이 단원은 기존의 1~4단원 요약본에서 **누락되었거나 축소되었던 실전 필수 개념 및 빈출 킬러 유형 6대 영역**을 전수 조사하여 빠짐없이 보강한 핵심 특강입니다.  
> **데이터 용량 단위(`KB·MB·GB·TB·PB`)와 전송 시간 계산**, **8진수·16진수 변환**, **그래프·트리 공식(`악수 정리`, `E=V-1`, `이진 탐색 트리`)**, **포함·배제(벤다이어그램)와 주기 추론**, **양팔 저울(`3ⁿ`) 및 숫자 야구 퍼즐**, **대각선 지름길 격자 경로·괄호 짝 검사·해시 충돌·e-비즈니스 상식**까지 시험에 나올 수 있는 모든 사각지대를 완벽하게 메웁니다.

## 1. 데이터 용량 단위 체계(`Byte ~ PB`)와 멀티미디어·전송 속도 계산

중학교 정보 교과의 '데이터' 영역과 '수리추론'이 결합되어 출제되는 단골 계산 유형입니다.

### 1.1 데이터 저장 용량 단위 계층 (`2¹⁰ = 1,024배` 법칙)

컴퓨터는 2진법 체계를 사용하므로, 바이트(`Byte`) 이상의 용량 단위는 한 단계 올라갈 때마다 정확히 **`2¹⁰배 (1,024배)`**씩 커집니다. *(단, 시험 문제에서 계산 편의를 위해 `"1 KB = 1,000 Byte로 계산한다"`는 단서가 주어지면 `1,000배`로 계산합니다.)*

| 단위 기호 | 정식 명칭 (영문 / 한글) | 이전 단위와의 관계 (`1,024배`) | `Byte` 기준 거듭제곱 표기 | 실생활 데이터 크기 비유 |
| :---: | :---: | :---: | :---: | :--- |
| **`Bit` (b)** | 비트 (Binary Digit) | 데이터의 **최소 단위** (`0` 또는 `1`) | `1/8 Byte` | 전구 스위치 1개 (켜짐/꺼짐) |
| **`Byte` (B)** | 바이트 (Byte) | **`1 Byte = 8 Bit`** (`2⁸ = 256가지` 표현) | **`1 Byte` (`2⁰ B`)** | 영문자·숫자 1글자 저장 (한글은 2~3 Byte) |
| **`KB`** | 킬로바이트 (Kilobyte) | `1 KB = 1,024 Byte` | **`2¹⁰ Byte`** (약 1천 B) | 짧은 텍스트 메모 문서 1개 |
| **`MB`** | 메가바이트 (Megabyte) | `1 MB = 1,024 KB` | **`2²⁰ Byte`** (약 100만 B) | 고화질 스마트폰 사진 1장, MP3 음악 1곡(3~5 MB) |
| **`GB`** | 기가바이트 (Gigabyte) | `1 GB = 1,024 MB` | **`2³⁰ Byte`** (약 10억 B) | 고화질 영화 1편(2~4 GB), USB 메모리 용량 |
| **`TB`** | 테라바이트 (Terabyte) | `1 TB = 1,024 GB` | **`2⁴⁰ Byte`** (약 1조 B) | 외장 하드디스크, 대용량 SSD (1~4 TB) |
| **`PB`** | 페타바이트 (Petabyte) | `1 PB = 1,024 TB` | **`2⁵⁰ Byte`** (약 1,000조 B) | 대형 포털·클라우드 데이터센터 전체 저장 용량 |

* **시험장 1초 암기 공식**:
  * **크기 서열**: **`Bit < Byte < KB(킬로) < MB(메가) < GB(기가) < TB(테라) < PB(페타)`**
  * **단위 환산 화살표**:
    * 큰 단위 ➔ 작은 단위로 바꿀 때 (예: `GB → MB`): **`× 1,024` (또는 `× 2¹⁰`)**
    * 작은 단위 ➔ 큰 단위로 바꿀 때 (예: `KB → MB`): **`÷ 1,024` (또는 `÷ 2¹⁰`)**
  * **오답 선지 1순위**: *"1 Byte는 10개의 Bit로 이루어진다"* (**❌ 거짓**, `8 Bit`), *"1 GB는 `2²⁰ Byte`이다"* (**❌ 거짓**, `KB=2¹⁰, MB=2²⁰, GB=2³⁰, TB=2⁴⁰`)

### 1.2 멀티미디어(이미지·소리) 용량 및 파일 저장 개수 계산

1. **무압축 비트맵 이미지 용량 공식**:
   > **이미지 용량 = `(가로 픽셀 수) × (세로 픽셀 수) × (픽셀 1개당 용량)`**
   * **색상 수와 비트(Bit) 관계**:
     * 흑백(2색) = `1 Bit` / 16색 = `4 Bit` / **256색 = `8 Bit = 1 Byte`**
     * **트루컬러(빛의 삼원색 R·G·B 각 8비트) = `24 Bit = 3 Byte`**
   * **[예제 1]**: *"가로 `1,024`픽셀, 세로 `1,024`픽셀 크기의 24비트 트루컬러 무압축 이미지 1장의 용량은 몇 `MB`인가?"*
     * **풀이**: 픽셀 1개당 `24 Bit = 3 Byte`이므로, 전체 용량은 `1,024 × 1,024 × 3 Byte`입니다. 이때 `1,024 × 1,024 Byte = 1 MB`이므로 정답은 **`3 MB`**입니다!

2. **저장 공간 내 최대 파일 개수 계산**:
   * **[예제 2]**: *"여유 공간이 `4 GB`인 USB 메모리에 `8 MB` 크기의 고화질 사진 파일을 최대 몇 장까지 저장할 수 있는가? (단, `1 GB = 1,024 MB`)"*
     * **풀이**: 단위를 `MB`로 통일하면 `4 GB = 4 × 1,024 MB = 4,096 MB`입니다. 따라서 `4,096 ÷ 8 = 512장`을 저장할 수 있습니다.

### 1.3 네트워크 전송 속도(`bps`)와 전송 시간 계산 (★단위 함정 주의!)

* **핵심 함정 (`Byte` vs `bit`)**:
  * 파일의 크기(용량)는 대문자 **`B`(`Byte`, 바이트)**를 사용합니다 (예: `100 MB`).
  * 반면 인터넷 통신 속도는 소문자 **`b`(`bps`, bit per second = 1초당 전송되는 비트 수)**를 사용합니다 (예: `100 Mbps`).
  * 따라서 전송 시간을 구할 때는 반드시 **파일 용량(`Byte`)에 `8`을 곱해 `bit`로 바꾸거나, 전송 속도(`bps`)를 `8`로 나누어 초당 전송 바이트(`Byte/s`)로 통일**해야 합니다!

> **전송 시간(초) = `파일 용량(Byte) × 8` ÷ `전송 속도(bps)`**

* **[예제 3]**: *"용량이 `50 MB`인 동영상 파일을 `100 Mbps` 속도의 네트워크로 다운로드할 때 걸리는 최소 시간은 몇 초인가? (단, `1 MB = 10⁶ Byte`, `1 Mbps = 10⁶ bps`로 계산한다.)"*
  * **풀이**:
    1. 파일 용량을 비트(`bit`)로 변환: `50 MB × 8 bit = 400 Mbit`
    2. 전송 시간 = `400 Mbit ÷ 100 Mbps` = **`4초`**! *(8을 곱하지 않고 50 ÷ 100 = 0.5초라고 쓰면 오답 함정에 걸립니다!)*

## 2. 8진수 · 16진수(`0~9, A~F`) 초고속 변환 및 색상 코드

긴 2진수 비트열을 한눈에 읽기 쉽게 줄여 표기하기 위해 컴퓨터에서는 **8진법**과 **16진법**을 함께 사용합니다.

### 2.1 16진수의 알파벳 표기(`A ~ F`)와 4자리 묶음 법칙

* **16진수 기호 (`0 ~ 15`)**: `0 ~ 9`까지는 숫자를 그대로 쓰고, 두 자리 수인 **`10 ~ 15`는 알파벳 `A ~ F`**로 표기합니다.
  > **`A = 10`, &nbsp; `B = 11`, &nbsp; `C = 12`, &nbsp; `D = 13`, &nbsp; `E = 14`, &nbsp; `F = 15`**
* **2진수 ↔ 8진수·16진수 3초 변환 공식**:
  * **2진수 ↔ 8진수 (`2³ = 8`)**: 2진수를 오른쪽 끝(일의 자리)부터 **3자리씩(`4-2-1`)** 끊어서 바꿉니다.
  * **2진수 ↔ 16진수 (`2⁴ = 16`)**: 2진수를 오른쪽 끝(일의 자리)부터 **4자리씩(`8-4-2-1`)** 끊어서 바꿉니다.

| 변환 유형 | 실전 예제 문제 | 초고속 풀이 과정 | 정답 |
| :---: | :--- | :--- | :---: |
| **2진수 ➔ 16진수** | 2진수 **`10100011₂`**을 16진수로 변환하시오. | 뒤에서부터 4자리씩 분할: `1010` / `0011`<br>• 앞 묶음 `1010₂` = `8 + 2 = 10` ➔ **`A`**<br>• 뒤 묶음 `0011₂` = `2 + 1 = 3` ➔ **`3`** | **`A3₁₆`** |
| **16진수 ➔ 10진수** | 16진수 **`2F₁₆`**를 10진수로 변환하시오. | 16진수의 앞자리는 **`× 16`**, 뒷자리는 **`× 1`**입니다.<br>• `2 × 16 + F(15) × 1 = 32 + 15 = 47` | **`47`** |
| **10진수 ➔ 16진수** | 10진수 **`200`**을 16진수로 변환하시오. | `200`을 `16`으로 나눕니다: `200 = 16 × 12 + 8`<br>• 몫 `12`는 알파벳 **`C`**, 나머지 `8`은 **`8`** | **`C8₁₆`** |
| **8진수 ➔ 10진수** | 8진수 **`37₈`**을 10진수로 변환하시오. | 8진수의 앞자리는 **`× 8`**, 뒷자리는 **`× 1`**입니다.<br>• `3 × 8 + 7 × 1 = 24 + 7 = 31` | **`31`** |

* **웹 색상 코드(`#RRGGBB`) 활용**: 웹 디자인에서 색상을 나타낼 때 빛의 삼원색(**빨강 `R`, 초록 `G`, 파랑 `B`**)의 밝기를 각각 `00₁₆(0)`부터 `FF₁₆(255)`까지의 2자리 16진수로 표기합니다 (예: `#FF0000` = 순수 빨간색, `#FFFFFF` = 흰색, `#000000` = 검은색).

### 2.2 아스키코드(`'A' = 65`, `'a' = 97`)와 2진수 · 16진수 문자 해독

영문 알파벳을 숫자로 매핑하는 **아스키코드(ASCII)** 기준점(**대문자 `'A' = 65`**, **소문자 `'a' = 97`**)을 이용해 2진수나 16진수 코드를 영단어로 해독하는 유형입니다.
* **초고속 해독 공식**:
  * 주어진 2진수 또는 16진수를 **10진수**로 바꾼 뒤, 대문자 영역(`65 ~ 90`)이면 **`(10진수 - 65 + 1)`번째 알파벳**을 찾고, 소문자 영역(`97 ~ 122`)이면 **`(10진수 - 97 + 1)`번째 알파벳**을 찾습니다 (`A=65, B=66, C=67, D=68, E=69 ... M=77, N=78, O=79 ... V=86`).
* **[예제 1: 2진수 아스키코드 해독]**: 십진법 `65`가 `'A'`, `97`이 `'a'`일 때 이진수 **`01000100, 01101001, 01101110, 01101001`**을 문자로 표현하면?
  * `01000100₂ = 64 + 4 = 68` (`'A'=65`에서 3칸 뒤 ➔ **`'D'`**)
  * `01101001₂ = 64 + 32 + 8 + 1 = 105` (`'a'=97`에서 8칸 뒤 ➔ **`'i'`**)
  * `01101110₂ = 64 + 32 + 8 + 4 + 2 = 110` (`'a'=97`에서 13칸 뒤 ➔ **`'n'`**)
  * `01101001₂ = 105` (➔ **`'i'`**) ──▶ 정답: **`Dini`**!
* **[예제 2: 16진수 아스키코드 해독]**: `'A'`가 십진수 아스키코드로 `65`일 때, 16진수 아스키코드 **`4D 4F 56 45`**가 나타내는 영단어는?
  * `4D₁₆ = 4×16 + 13(D) = 77` (13번째 알파벳 ➔ **`'M'`**)
  * `4F₁₆ = 4×16 + 15(F) = 79` (15번째 알파벳 ➔ **`'O'`**)
  * `56₁₆ = 5×16 + 6 = 86` (22번째 알파벳 ➔ **`'V'`**)
  * `45₁₆ = 4×16 + 5 = 69` (5번째 알파벳 ➔ **`'E'`**) ──▶ 정답: **`MOVE`**!

## 3. 그래프 · 트리 수리 공식 심화 (악수 정리, `E = V - 1`, 이진 탐색 트리, 색칠하기)

2단원(한붓그리기)과 4단원(최단 거리)에 더해, 시험에서 **그림 없이 숫자만 주고 10초 만에 풀게 하는 그래프·트리 절대 공식 4가지**입니다.

### 3.1 그래프의 차수(Degree)와 악수 정리
* **차수(Degree)**: 한 꼭짓점(정점)에 연결된 선(간선)의 개수입니다.
* **악수 정리 공식**: 선분 1개는 양 끝의 점 2개를 동시에 연결하므로, **모든 꼭짓점의 차수를 다 더한 값은 항상 전체 간선(선) 개수의 2배**입니다.
  > **전체 간선(선)의 개수 = `(모든 꼭짓점의 차수 총합) ÷ 2`**
* **[예제 1]**: *"꼭짓점이 6개인 그래프에서 각 꼭짓점에 연결된 선의 개수(차수)가 각각 `3, 3, 2, 2, 2, 2`일 때, 이 그래프의 전체 선분(간선) 개수는?"*
  * **풀이**: 차수의 총합 = `3 + 3 + 2 + 2 + 2 + 2 = 14`. 따라서 전체 선분 개수 = `14 ÷ 2` = **`7개`**!

### 3.2 트리(Tree)의 간선 개수와 포화 이진 트리 공식
* **트리(Tree)의 정의**: 순환하는 고리(사이클)가 전혀 없이 모든 점이 하나로 연결된 그래프입니다.
* **트리 간선 절대 공식**: 점 1개에서 시작해 점이 1개 늘어날 때마다 선분도 정확히 1개씩만 늘어나므로, 정점(점)이 `V`개인 트리의 간선(선) 개수 `E`는 언제나 정점 수보다 `1` 작습니다.
  > **트리의 간선 개수 (`E`) = `정점 개수 (V) - 1`**
  * *예*: 정점이 `10개`인 트리의 간선 수는 무조건 **`9개`**, 정점이 `50개`인 트리의 간선 수는 무조건 **`49개`**입니다.
* **포화 이진 트리(Full Binary Tree) 노드 개수 공식**:
  * 부모 노드가 모두 자식 노드를 2개씩 꽉 채워 가진 이진 트리에서, 루트(꼭대기)를 1층이라 할 때 **`k`층(높이 `k`)까지 꽉 찬 전체 노드의 총개수**는 다음과 같습니다.
    > **높이 `k`인 포화 이진 트리의 총 노드 수 = `2ᵏ - 1`개**
  * *예*: 1층(`1개`) + 2층(`2개`) + 3층(`4개`) + 4층(`8개`) ➔ 높이 4인 포화 이진 트리의 총 노드 수 = `2⁴ - 1` = **`15개`**!

### 3.3 크기 비교 갈림길 트리 탐색 규칙 (이진 탐색 트리 원리)
> *(※ 디미고 시험에서는 '이진 탐색 트리'라는 전공 용어를 외우게 하지 않고, 아래와 같이 왼쪽·오른쪽 이동 규칙을 한글 지문으로 제시한 뒤 특정 숫자를 찾는 경로를 묻습니다.)*
데이터를 빠르게 찾기 위해 다음 규칙에 따라 숫자를 배치한 트리입니다.
> * 현재 부모 노드보다 **작은 숫자는 무조건 왼쪽(`↙`) 자식**으로 이동!
> * 현재 부모 노드보다 **큰 숫자는 무조건 오른쪽(`↘`) 자식**으로 이동!

| 단계 | 이진 탐색 트리 구조 예시 | 숫자 `28`을 찾는 방문 순서 추적 |
| :---: | :--- | :--- |
| **트리 구조** | • 1층(루트): **`[35]`**<br>• 2층: `[35]`의 왼쪽 **`[20]`**, 오른쪽 **`[45]`**<br>• 3층: `[20]`의 왼쪽 **`[10]`**, 오른쪽 **`[30]`**<br>• 4층: `[30]`의 왼쪽 **`[28]`** | 1. 루트 **`35`**에서 시작: `28 < 35`이므로 **왼쪽(`20`)**으로 이동<br>2. 노드 **`20`**과 비교: `28 > 20`이므로 **오른쪽(`30`)**으로 이동<br>3. 노드 **`30`**과 비교: `28 < 30`이므로 **왼쪽(`28`)**으로 이동하여 발견!<br>➔ **방문 경로: `35 → 20 → 30 → 28`** |

### 3.4 인접 영역 지도 색칠하기 (Graph Coloring)
이웃한(맞닿은) 구역끼리는 서로 다른 색을 칠하는 경우의 수 문제입니다.
* **해법**: **가장 많은 영역과 맞닿아 있는 중심 구역**부터 순서대로 칠하며 곱의 법칙을 적용합니다.
* **★ 대각선 배치(2×2 격자) 주의점**:
  * `A(좌상), B(우상), C(좌하), D(우하)` 4칸으로 나뉜 2×2 표를 **3가지 색**으로 칠할 때, 마주 보는 **`B`와 `C`가 같은 색인 경우**와 **`B`와 `C`가 다른 색인 경우**로 나누어 구해야 실수하지 않습니다!
  * **1) `B`와 `C`가 같은 색일 때**: `A(3가지) × B(2가지) × C(B와 같은 색 1가지) × D(B·C와만 다르면 되므로 2가지) = 12가지`
  * **2) `B`와 `C`가 다른 색일 때**: `A(3가지) × B(2가지) × C(A·B와 다른 1가지) × D(B·C 두 색과 모두 달라야 하므로 1가지) = 6가지`
  * **합계**: `12 + 6 = 18가지`! *(무작정 3 × 2 × 2 × 2 = 24가지라고 풀면 오답입니다!)*

## 4. 집합 포함·배제 원리(벤다이어그램)와 주기·최대공약수 추론

고등 집합 기호를 몰라도 중학생 수준에서 벤다이어그램과 겹침 원리로 30초 만에 풀 수 있는 필수 수리 유형입니다.

### 4.1 두 그룹 겹침(교집합) 인원수 공식
> **`(A 또는 B에 속하는 전체 인원) = (A 인원) + (B 인원) - (A와 B 둘 다 속하는 겹침 인원)`**

* **[예제 1: 설문조사 인원 추론]**: *"학생 30명을 대상으로 조사한 결과, 파이썬을 다뤄본 학생이 18명, C언어를 다뤄본 학생이 15명, 두 언어 모두 다뤄본 적이 없는 학생이 4명이었다. 두 언어를 모두 다뤄본 학생은 몇 명인가?"*
  * **1단계**: 전체 30명 중 둘 다 안 해본 4명을 빼면, **적어도 하나라도 다뤄본 학생은 `30 - 4 = 26명`**입니다.
  * **2단계**: `파이썬(18) + C언어(15) = 33명`인데 실제 인원은 `26명`이므로, 두 번 중복해서 세어진 **둘 다 다뤄본 학생 수**는 `33 - 26` = **`7명`**입니다!

* **[예제 2: 배수의 개수 (또는 조건)]**: *"1부터 20까지의 자연수 중 **2의 배수이거나(또는) 3의 배수**인 수의 개수는?"*
  * **풀이**: 2의 배수(`20 ÷ 2 = 10개`) + 3의 배수(`20 ÷ 3 = 6개`)에서 두 번 겹쳐 세어진 **6의 배수(공배수: `6, 12, 18` 총 `3개`)**를 빼줍니다 ➔ `10 + 6 - 3` = **`13개`**!

### 4.2 요일·달력 주기(나머지 연산)와 최대공약수(`GCD`)·최소공배수(`LCM`)
1. **요일·시계 주기 추론 (`MOD` 나머지)**:
   * 요일은 **7일**마다 똑같이 반복되므로, `N`일 뒤의 요일은 **`N ÷ 7`의 나머지**만큼만 현재 요일에서 앞으로 가면 됩니다.
   * *예*: "오늘이 **화요일**일 때 **100일 뒤**는 무슨 요일인가?" ➔ `100 = 7 × 14 + 2` (나머지 `2`) ➔ 화요일에서 이틀 뒤인 **목요일**!
2. **최대공약수(`GCD`) vs 최소공배수(`LCM`) 실전 구분**:
   * **최대공약수(`GCD`)**: 큰 직사각형 바닥을 남는 부분 없이 **가장 큰 정사각형 타일로 빈틈없이 나누어 채우기**, 물건을 똑같이 **가장 많은 학생에게 나누어 주기** (`84`와 `60`의 최대공약수 = `12`)
   * **최소공배수(`LCM`)**: 서로 다른 주기로 출발하는 **버스·기차가 다시 동시에 출발하는 시각**, 톱니바퀴가 다시 처음 맞물리는 회전수 찾기 (`12분` 간격과 `18분` 간격 버스가 오전 8시 동시 출발 ➔ 최소공배수 `36분` 뒤인 `08:36`에 다시 동시 출발!)
   * **[심화 예제: 근무 주기와 요일 주기 결합]**: *"갑은 3일 일하고 하루를 쉬고(4일 주기), 을은 토요일과 일요일만 쉰다(7일 주기). 두 사람 모두 어느 월요일에 처음 출근했을 때, 480일 동안 두 명 모두 쉬는 날은 며칠인가?"*
     * **풀이**: 갑의 휴무일(`4, 8, 12, 16, 20, 24, 28...`일째)과 을의 휴무일(월요일이 1일째이므로 토·일요일은 `6, 7, 13, 14, 20, 21, 27, 28...`일째)은 최소공배수인 **28일 주기**마다 반복됩니다. 1~28일 중 두 숫자가 겹치는 날은 **`20일째(토)`와 `28일째(일)` 총 2일**입니다. `480 ÷ 28 = 몫 17묶음 + 나머지 4일`이고 나머지 1~4일째에는 동시 휴무가 없으므로, 정답은 `17 × 2` = **`34일`**입니다!

## 5. 고전 추리 & 계측 퍼즐 (양팔 저울 `3ⁿ`, 숫자 야구, 스위치 회로)

### 5.1 양팔 저울로 가짜 동전 찾기 (`3ⁿ` 3등분 법칙)
겉모양은 같지만 **무게가 살짝 가벼운(또는 무거운) 가짜 동전 1개**를 양팔 저울을 최소한으로 사용하여 찾아내는 퍼즐입니다.
* **핵심 원리 (`2ⁿ`이 아니라 `3ⁿ`!)**:
  * 양팔 저울에는 왼쪽 접시, 오른쪽 접시, 그리고 **저울에 올리지 않고 바닥에 남겨둔 그룹**까지 총 **3개의 그룹**으로 동전을 나누어 한 번에 판별할 수 있습니다!
  * 만약 왼쪽과 오른쪽 접시가 수평을 이루면 바닥에 남겨둔 그룹에 가짜가 있고, 한쪽으로 기울면 가벼운 쪽 접시에 가짜가 있습니다.
  > **양팔 저울을 `k`번 사용하여 가짜 1개를 반드시 찾을 수 있는 최대 동전 수 = `3ᵏ`개**
  * **1번** 측정: 최대 **`3개`** (`1개 vs 1개`, 밖 `1개`)
  * **2번** 측정: 최대 **`9개`** (`3개 vs 3개`, 밖 `3개` ➔ 가짜가 있는 3개 중 다시 `1 vs 1`)
  * **3번** 측정: 최대 **`27개`** (`9개 vs 9개`, 밖 `9개`)
  * **4번** 측정: 최대 **`81개`** (`27개 vs 27개`, 밖 `27개`)

### 5.2 숫자 야구(스트라이크·볼) 비밀번호 추리
세 자리 또는 네 자리 비밀번호에 대한 힌트를 보고 정답을 찾는 퍼즐입니다.
* **3단계 10초 공략법**:
  1. **`"맞는 숫자가 하나도 없다 (0 스트라이크 0 볼)"` 조건부터 최우선 확인**: 거기에 적힌 숫자들을 다른 모든 힌트와 보기에서 즉시 지웁니다(`X`).
  2. **`"숫자는 맞지만 위치가 틀리다 (볼)"`**: 해당 숫자가 그 자리에 들어간 보기를 모두 소거합니다.
  3. **`"숫자와 위치가 모두 맞다 (스트라이크)"`**: 남은 후보 중 자리까지 일치하는 보기를 확정합니다.
* **[예제]**:
  * `1 4 7`: 1개의 숫자가 맞고 위치도 맞다.
  * `1 8 9`: 맞는 숫자가 하나도 없다. ➔ **`1, 8, 9` 완전 삭제!** (`1 4 7`에서도 `1`이 지워지므로 `4` 또는 `7`이 자기 자리!)
  * `4 5 6`: 2개의 숫자가 맞지만 위치는 둘 다 틀리다. ➔ 만약 `4`가 맞는 숫자라면 첫째 자리가 아니어야 하므로 첫 번째 단서(`1 4 7`에서 4가 둘째 자리로 위치가 맞음)와 양립 가능합니다. 이때 `4 5 6`에서 `4`와 `6`이 맞고 위치가 틀리다면, 셋째 자리는 `7`(`1 4 7`에서 위치 맞음)이 되어 `4`가 갈 자리가 없어지므로 모순! 따라서 `1 4 7`에서 맞은 숫자는 셋째 자리 **`7`**이고, `4 5 6`에서 맞은 2개는 **`5`와 `6`**입니다. 위치가 둘 다 틀리므로 첫째 자리에 `6`, 둘째 자리에 `5`가 들어가 정답은 **`6 5 7`** (또는 보기에 따라 위치 대조)!

### 5.3 직렬(`AND`) · 병렬(`OR`) 스위치 전구 회로 판독
전선과 스위치(`S1, S2, ...`)로 연결된 전구 회로 문제는 논리 게이트와 100% 동일합니다.
* **직렬 연결 (한 줄로 이어진 스위치)**: 두 스위치가 **모두 닫혀야(`ON`)** 전기가 흐릅니다 ➔ **`AND` 연산**
* **병렬 연결 (위아래 두 갈래로 나뉜 스위치)**: 위쪽이나 아래쪽 중 **하나라도 닫히면(`ON`)** 전기가 흐릅니다 ➔ **`OR` 연산**

## 6. 알고리즘·IT 융합 심화 (블랙박스 함수, 괄호 검사, 해시 충돌, 대각선 경로, e-비즈니스)

### 6.1 블랙박스 변환 상자(`입력 → 출력`) 규칙 추론
변환 상자에 넣은 입력값(`x`)과 출력값(`y`)의 짝을 보고 숨겨진 연산식을 찾는 문제입니다.
1. **일차함수형 (`y = ax + b`)**: 입력 `x`가 일정하게 커질 때 출력 `y`가 얼마씩 커지는지(배율 `a`)를 먼저 찾고, 상수 `b`를 보정합니다.
   * *예*: `2 → 5`, `4 → 9`, `6 → 13` ➔ 입력의 **2배에 1을 더한 값(`2x + 1`)**이므로, 입력이 `9`일 때는 `2 × 9 + 1` = **`19`**!
2. **문자열 번호 변환형**: 알파벳을 순서 번호(`A=1, B=2, C=3, ...`)로 바꾼 뒤 더하거나 곱하는 규칙입니다.
   * *예*: `"AB" → 3 (1+2)`, `"CD" → 7 (3+4)`, `"EF" → 11 (5+6)` ➔ `"GH"`는 `G(7) + H(8)` = **`15`**!

### 6.2 올바른 괄호 짝 맞추기 `(()())` 판별 규칙
여는 괄호 `(`와 닫는 괄호 `)`의 짝이 올바르게 맞는지 판별하는 규칙 추론 문제입니다.
* **실전 `+1 / -1` 카운팅 공식**:
  * 왼쪽 첫 글자부터 차례로 읽으면서 여는 괄호 **`(`가 나오면 `+1`**, 닫는 괄호 **`)`가 나오면 `-1`**을 계산합니다.
  * **규칙 1**: 계산 도중 **단 한 번이라도 음수(`-1`)가 나오면** 여는 괄호 없이 닫는 괄호가 먼저 나온 것이므로 **즉시 탈락!** (예: `())(()` ➔ 3번째에서 `-1`이 되어 탈락!)
  * **규칙 2**: 끝까지 다 계산했을 때 **최종 합계가 정확히 `0`**이어야만 올바른 괄호입니다! (예: `(()())` ➔ `1 → 2 → 1 → 2 → 1 → 0` 통과!)

### 6.3 나머지 연산(`MOD`)을 이용한 사물함/방 배정 규칙과 중복(충돌) 찾기
* **나머지 방 배정 규칙**: 지문에서 `"학생 번호 X를 7로 나눈 나머지를 사물함 번호로 배정한다. 만약 이미 다른 학생이 배정되어 있다면 바로 다음 빈 번호에 배정한다"`와 같은 규칙이 주어지는 유형입니다.
  * *예*: 번호를 `7`로 나눈 나머지로 배정할 때, **`15번`(`15 ÷ 7` 나머지 `1`)**과 **`22번`(`22 ÷ 7` 나머지 `1`)**은 둘 다 나머지가 `1`이어서 `1번` 사물함에서 겹치게 됩니다(충돌 발생). 규칙에 따라 먼저 온 `15번`이 `1번` 칸에 들어가고, 나중에 온 `22번`은 다음 빈칸인 `2번` 칸에 배정됩니다!

### 6.4 대각선 지름길(`↗`)이 있는 격자 도로망 최단 경로
일반적인 바둑판 도로망(`왼쪽 + 아래쪽`)에 특정 칸을 가로지르는 **대각선 지름길(`↗`)**이 추가된 심화 문제입니다.
* **해법 (`3방향 합산 공식`)**:
  * 대각선 지름길이 도착하는 교차점에서는 **`(왼쪽에서 오는 경우) + (아래쪽에서 오는 경우) + (대각선 아래 출발점에서 지름길로 바로 올라오는 경우)` 3가지를 모두 더합니다!**

| 구분 | 0열 | 1열 | 2열 | 3열 | 4열 (`3방향 합산` 풀이 설명) |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **3행** | `1` | `4` | `11` | `23` | **`G = 42가지`** (`23 + 19 = 42`) |
| **2행** | `1` | `3` | `7` | `12` | `19` (`12 + 7 = 19`) |
| **1행** | `1` | `2` | `3` | **`5 [↗도착]`** | `7` • `(2,0)→(3,1)` 대각선 지름길이 있을 때:<br>&nbsp;&nbsp;`3열 1행 = 왼쪽(3) + 아래(1) + 대각선(1) = 5`! |
| **0행** | **`S(1)`** | `1` | **`1 [↗출발]`** | `1` | `1` |

### 6.5 단계별 규칙과 원통 `(가)·(나)·(다)` 공 옮기기 시뮬레이션
위쪽만 열려 있는 원통(스택 구조) `(가), (나), (다)`와 단계별 규칙(`단계1 ~ 단계7`)이 주어질 때 공의 이동 결과를 추적하는 유형입니다.
* **핵심 주의점 (반복 구간 vs 단발 실행 구간 구분)**:
  * **`"단계 1로 간다"`**처럼 되돌아가는 화살표/지시가 있는 단계는 통이 빌 때까지 **끝까지 반복**합니다.
  * 반면 되돌아가는 지시 없이 곧바로 **`"종료한다"`**가 이어지는 단계는 **맨 위의 공 딱 1개만 꺼내어 처리하고 즉시 멈춰야** 합니다!
* **[예제]**: 원통 `(가)`에 위에서부터 `[8, 5, 6, 7, 2]` 순서로 공이 들어 있고 `(나), (다)`는 비어 있을 때:
  1. `단계1~4 반복`: `(가)`에서 맨 위 공을 하나씩 꺼내어 `6 이하`이면 `(나)`에 넣고, 아니면 `(다)`에 넣는 과정을 `(가)`가 빌 때까지 반복 ➔ `(나)`에는 위에서부터 **`[2, 6, 5]`**, `(다)`에는 위에서부터 **`[7, 8]`**이 쌓임
  2. `단계5~7 단발 실행`: `(나)`의 맨 위 공 **`2`**를 꺼내어 2의 배수이면 `(다)`에 넣고 **즉시 종료** ➔ `(다)`의 맨 위에 `2`가 올라가므로 위에서부터 나열한 최종 순서는 **`2 7 8`**! *(주의: `(나)`에 남은 `6`까지 계속 꺼내면 오답이 됩니다!)*

### 6.6 컴퓨팅 시스템 · 네트워크 · e-비즈니스 필수 혼동 개념 정리

| 분류 | 핵심 용어 | 1초 구분 핵심 키워드 및 오답 함정 포인트 |
| :---: | :---: | :--- |
| **하드웨어 vs<br>소프트웨어** | **`펌웨어 (Firmware)`** | • ROM 등 하드웨어에 저장되어 있지만 본질은 하드웨어를 제어하는 **시스템 소프트웨어**!<br>• *"하드웨어를 모두 고르시오"* 문제에서 `RAM, 하드디스크, CPU`만 고르고 **`펌웨어`는 반드시 제외**해야 함! |
| **컴퓨터 분류와<br>인터페이스** | **`웨어러블 컴퓨터` /<br>`키넥트 · 립모션`** | • **웨어러블 컴퓨터**: 옷, 시계, 안경처럼 몸에 착용 가능한 소형·경량 컴퓨터<br>• **키넥트 / 립모션**: 신체나 손가락의 3차원 동작(모션)을 인식하는 입력 인터페이스 |
| **네트워크 장비<br>(영문 키워드)** | **`Router` (라우터) vs<br>`Hub / Switch / Proxy`** | • **Router**: 동시 인터넷 연결(`connect simultaneously`), 사설 IP 할당(`assigns local IP`), 주소 변환(**`NAT: network address translation`**), 패킷 경로 전달(**`forwarding data packets`**)<br>• **Hub**: 모든 포트로 신호 단순 분배 / **Proxy Server**: 클라이언트-서버 간 중계·보안·캐시 대리 서버 |
| **전자상거래<br>4대 주체** | **`B2B` / `B2C` /<br>`C2C` / `D2C`** | • **`B2B`**(기업↔기업 솔루션·원자재) / **`B2C`**(기업↔소비자 쇼핑몰)<br>• **`C2C`**(소비자↔소비자 중고거래) / **`D2C`**(제조사가 유통망 없이 자사몰에서 소비자에게 **직접 판매**) |
| **서비스·웹 설계** | **`UI / UX` &<br>`HTML / CSS / JS`** | • **`UI`**(시각적 화면·버튼 조작 체계) vs **`UX`**(사용자가 느끼는 총체적 편리함·만족감 경험)<br>• **`HTML`**(웹페이지 구조·뼈대) / **`CSS`**(색상·레이아웃 디자인) / **`JavaScript`**(클릭 반응 등 동적 동작) |
