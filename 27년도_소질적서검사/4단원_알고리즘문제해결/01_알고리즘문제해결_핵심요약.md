# 제4단원: 알고리즘적 문제해결력 (순서도 추적 · 규칙 시뮬레이션 · 비버챌린지형)

> **디미고 일반전형 출제 기준 점검**:
> * **출제 범위**: 특정 프로그래밍 언어(C, 파이썬 등)의 문법이나 대학 수준의 컴퓨터공학 전공 지식(`반가산기 회로`, `NAND/NOR`, `정렬 알고리즘 학술 명칭 암기`)을 묻지 않습니다.
> * **핵심 평가 내용**: 문제 지문에 주어진 **한글 절차서나 순서도(Flowchart)의 규칙을 읽고 손으로 정확히 따라가며 결과를 도출**하는 능력을 평가합니다. **① 순서도 반복 루프 변수 추적표와 오류 찾기**, **② 막힌 통로(스택 원리) vs 뚫린 통로(큐 원리) 입출력 순서**, **③ 숫자 카드 정렬 규칙 단계별 추적 및 업다운(이진) 탐색**, **④ 비버챌린지형 시뮬레이션(논리 연산 상자·상태 화살표·격자 로봇·최단 거리·시간표 배정)**으로 출제됩니다.

## 1. 순서도(Flowchart) 빈칸 공식 · 오류 찾기 · 변수 추적표

### 1.1 순서도 빈칸 채우기 & 논리 오류 찾기 4대 단골 패턴

| 알고리즘 목적 | 핵심 순서도 식 / 조건식 | 작동 원리 및 ★오답 함정 주의점 |
| :---: | :--- | :--- |
| **두 변수 값 교환 (SWAP)** | `TEMP ← A` ➔ **`A ← B`** ➔ **`B ← TEMP`** | 임시 상자(`TEMP`)를 이용해 대각선 꼬리물기 순서로 교환 (`TEMP` 없이 `A ← B`를 먼저 하면 기존 `A` 값이 지워짐!) |
| **조건 만족 개수 세기** | 조건이 참(예)일 때 **`CNT ← CNT + 1`** | 배수·약수·특정 조건을 통과할 때마다 카운트 변수를 `1`씩 증가 |
| **최댓값(`MAX`) / 최솟값(`MIN`)** | • 최댓값: `< A[i] > MAX ? >` ➔ **`MAX ← A[i]`**<br>• 최솟값: `< A[i] < MIN ? >` ➔ **`MIN ← A[i]`** | **⚠️ [초기값 오류 함정]**: 양수 목록 `[10, 30, 20]`에서 최솟값을 찾을 때 **`MIN ← 0`으로 시작하면 영원히 `0`이 출력되는 논리 오류 발생!** 반드시 **첫 번째 값(`MIN ← A[0]`)**으로 시작해야 함! |
| **자릿수 분리 합산** | • 일의 자리 추출: **`N을 10으로 나눈 나머지`**<br>• 일의 자리 제거: **`N을 10으로 나눈 몫`** | 예: `N = 358` ➔ 나머지 `8` 추출 후 몫 `35`로 바꾸며 각 자릿수 합(`3+5+8=16`) 계산 |

### 1.2 두 변수가 동시에 변하는 반복문 & 2중 반복문 변수 추적표 (Trace Table)

머리로 암산하지 말고 **시험지 여백에 변수 이름을 가로줄로 적은 표(Trace Table)**를 그려 한 단계씩 값을 고쳐 적습니다.

#### ① [예제 1] 두 변수가 동시에 변하는 반복 구조 (`A < B`일 동안 반복)
* **절차 규칙**: 처음에 `A = 1, B = 10, CNT = 0`으로 시작하여, **`A < B`인 동안 `A`는 `3`씩 늘리고(`A ← A + 3`), `B`는 `1`씩 줄이며(`B ← B - 1`), `CNT`를 `1`씩 늘린다.** 반복이 끝난 후 `CNT`, `A`, `B`의 값은?

| 실행 단계 | 변수 `A` (`+3`씩 증가) | 변수 `B` (`-1`씩 감소) | 횟수 `CNT` (`+1`씩 증가) | 반복 조건 검사 (`A < B` 인가?) |
| :---: | :---: | :---: | :---: | :--- |
| **초기 상태** | `1` | `10` | `0` | `1 < 10` (참 ➔ 1회차 실행) |
| **1회차 실행 후** | `4` | `9` | `1` | `4 < 9` (참 ➔ 2회차 실행) |
| **2회차 실행 후** | `7` | `8` | `2` | `7 < 8` (참 ➔ 3회차 실행) |
| **3회차 실행 후** | **`10`** | **`7`** | **`3`** | `10 < 7` (**거짓 ➔ 반복 종료!** 최종 `CNT = 3`) |

#### ② [예제 2] 2중 중첩 반복 구조 (바깥 반복 `i = 1~3`, 안쪽 반복 `j = 1~2`)
* **핵심 원리**: 시계의 **시침(바깥 변수 `i`)이 1번 바뀔 때마다, 분침(안쪽 변수 `j`)은 처음부터 끝까지 한 바퀴를 전부** 돕니다!
  * `i = 1`일 때 (`j = 1, 2` 실행): `(1 × 1) + (1 × 2) = 1 + 2 = 3`
  * `i = 2`일 때 (`j = 1, 2` 실행): `(2 × 1) + (2 × 2) = 2 + 4 = 6`
  * `i = 3`일 때 (`j = 1, 2` 실행): `(3 × 1) + (3 × 2) = 3 + 6 = 9`
  * **총 실행 횟수**: `3 × 2 = 6번` / **`i × j`를 모두 누적한 총합(`SUM`)**: `3 + 6 + 9` = **`18`**!

## 2. 통로 입출력 순서 퍼즐 & 자기 호출 규칙 추적

시험에서는 전문 용어 대신 **"입구와 출구가 하나뿐인 막힌 통로(주차장/상자)"** 또는 **"양쪽이 뚫린 한 방향 터널(대기줄)"**이라는 비버챌린지형 지문으로 출제됩니다.

### 2.1 막힌 통로(스택 원리) vs 뚫린 통로(큐 원리) 비교

| 통로 유형 | 작동 규칙 (지문 표현) | `1 → 2 → 3` 순서로 넣었을 때 나오는 순서 |
| :---: | :--- | :--- |
| **① 막힌 통로**<br>(스택 / 후입선출 `LIFO`) | • 입구와 출구가 하나뿐인 통, 막다른 골목 주차장<br>• **"가장 마지막에 들어간 것이 가장 먼저 나온다!"** (뒤로가기, 실행 취소) | • 다 넣은 뒤 빼면 **`3 → 2 → 1` (역순)**<br>• 중간에 넣다 빼기를 섞으면 다양한 순서 가능 |
| **② 양쪽 뚫린 통로**<br>(큐 / 선입선출 `FIFO`) | • 한쪽으로 들어가 반대쪽으로 나오는 터널, 매표소 줄서기, 프린터 대기열<br>• **"먼저 들어간 것이 무조건 먼저 나온다!"** | • 무조건 **`1 → 2 → 3` (들어간 순서 그대로)** |

* **★ 막힌 통로(스택)에서 절대 나올 수 없는 출력 순서 5초 판별 공식**:
  * `1, 2, 3, 4`를 순서대로 넣었다 뺄 때(중간에 언제든 뺄 수 있음), **큰 숫자 `K`가 먼저 밖으로 나왔다면 아직 안 나온 작은 숫자들은 이미 통 안에 순서대로 깔려 있으므로 반드시 큰 수부터 작은 수(내림차순) 순서로만** 나와야 합니다!
  * ⭕ `2 → 1 → 4 → 3` (가능: 1, 2 넣고 2, 1 뺀 뒤, 3, 4 넣고 4, 3 빼기)
  * ❌ **`4 → 2 → 3 → 1` (절대 불가능!)**: `4`가 맨 처음 나오려면 `1, 2, 3, 4`가 모두 들어간 상태여야 하므로, 남은 숫자는 무조건 `3 → 2 → 1` 순서로만 나와야 합니다 (`2`가 `3`보다 먼저 나올 수 없음!).

### 2.2 이전 단계 값을 이용해 다음 값을 구하는 규칙 (재귀적 규칙 역산)
* **출제 형태**: `"규칙 상자 f(n)은 n=1일 때 2이고, n이 2 이상일 때는 f(n) = 2 × f(n-1) + 1로 계산한다. f(4)의 값은?"`
* **10초 해법 (바닥부터 역산)**: `f(4)`부터 거꾸로 생각하지 말고, **가장 작은 값 `f(1)`부터 차례대로 대입해 올라갑니다!**
  * `f(1) = 2` ──▶ `f(2) = 2×2 + 1 = 5` ──▶ `f(3) = 2×5 + 1 = 11` ──▶ **`f(4) = 2×11 + 1 = 23`**!

## 3. 숫자 카드 정렬 시뮬레이션(전체 단계) & 업다운(이진) 탐색

시험에서는 정렬의 이름을 묻는 대신 **정렬 규칙을 한글 지문으로 제시**하고, **`[ 5, 3, 4, 1, 2 ]`를 해당 규칙으로 정렬할 때 1단계~4단계(완료) 상태**나 **자리 교환 횟수**를 묻습니다.

### 3.1 3대 정렬 규칙의 1단계 ~ 4단계(최종 완료) 전체 변화 과정

| 단계 구분 | ① 최솟값을 찾아 앞자리와 맞바꾸기<br>*(선택 정렬 규칙: **맨 앞부터 1개씩 확정**)* | ② 이웃한 두 수를 비교해 큰 수를 뒤로 밀기<br>*(버블 정렬 규칙: **맨 뒤부터 1개씩 확정**)* | ③ 2번째부터 뽑아 앞쪽 정렬된 줄에 끼워 넣기<br>*(삽입 정렬 규칙: **앞쪽 묶음이 1칸씩 정렬 확장**)* |
| :---: | :--- | :--- | :--- |
| **초기 상태** | `[ 5, 3, 4, 1, 2 ]` | `[ 5, 3, 4, 1, 2 ]` | `[ 5 | 3, 4, 1, 2 ]` *(맨 앞 5를 기준으로 시작)* |
| **1회전(1단계) 후** | **`[ 1 | 3, 4, 5, 2 ]`**<br>• 전체 최솟값 `1`을 찾아 맨 앞 `5`와 교환 (`1` 확정) | **`[ 3, 4, 1, 2 | 5 ]`**<br>• `(5,3)→(5,4)→(5,1)→(5,2)` 연속 교환 (`5` 확정) | **`[ 3, 5 | 4, 1, 2 ]`**<br>• 2번째 `3`을 뽑아 앞쪽 `[5]`의 앞으로 끼워 넣음 |
| **2회전(2단계) 후** | **`[ 1, 2 | 4, 5, 3 ]`**<br>• 남은 구간 최솟값 `2`를 찾아 2번 자리 `3`과 교환 | **`[ 3, 1, 2 | 4, 5 ]`**<br>• `(3,4)유지→(4,1)교환→(4,2)교환` (`4, 5` 확정) | **`[ 3, 4, 5 | 1, 2 ]`**<br>• 3번째 `4`를 뽑아 앞쪽 `[3, 5]` 사이에 끼워 넣음 |
| **3회전(3단계) 후** | **`[ 1, 2, 3 | 5, 4 ]`**<br>• 남은 구간 최솟값 `3`을 찾아 3번 자리 `4`와 교환 | **`[ 1, 2 | 3, 4, 5 ]`**<br>• `(3,1)교환→(3,2)교환` (`3, 4, 5` 확정) | **`[ 1, 3, 4, 5 | 2 ]`**<br>• 4번째 `1`을 뽑아 앞쪽 `[3, 4, 5]` 맨 앞으로 삽입 |
| **4회전(완료) 후** | **`[ 1, 2, 3, 4 | 5 ]`**<br>• 남은 `[5, 4]` 중 `4`와 `5`를 교환 ➔ **정렬 완료!** | **`[ 1 | 2, 3, 4, 5 ]`**<br>• `(1,2)유지` (교환 없음) ➔ **정렬 완료!** | **`[ 1, 2, 3, 4, 5 ]`**<br>• 5번째 `2`를 뽑아 `1`과 `3` 사이에 삽입 ➔ **완료!** |

### 3.2 업다운 숫자 찾기 (이진 탐색 원리)
* **전제 조건**: 숫자 카드들이 반드시 **크기순(오름차순 또는 내림차순)으로 정렬되어 있어야만** 사용할 수 있습니다!
* **작동 원리**: 남은 범위의 **정가운데 숫자(중간값)**를 확인하여, 찾는 숫자보다 작거나 큰 **절반(`1/2`)의 카드를 한 번에 버립니다.**
  * *예*: `[ 10, 20, 30, 40, 50, 60, 70 ]`에서 **`60`**을 찾을 때 비교 순서:
    `1차 정가운데 40 확인` (`60 > 40`이므로 `10~40` 버림, `[50, 60, 70]` 남음) ➔ `2차 정가운데 60 확인` (일치! **총 2회 비교**)
* **최대 질문(비교) 횟수 공식**: 카드가 `N`장일 때 최악의 경우 질문 횟수는 **`2ᵏ ≥ N`을 만족하는 가장 작은 자연수 `k`회**입니다 (`64장`이면 `2⁶=64`이므로 최대 `6~7회`, `100장`이면 `2⁷=128`이므로 최대 `7회`).

## 4. 비버챌린지형 4대 실전 시뮬레이션 해법

### 4.1 논리 연산 상자(`AND` · `OR` · `NOT` · `XOR`) 연결 추적
* **4대 기본 논리 규칙**:
  * **`AND` (논리곱)**: 두 입력이 **모두 `1`일 때만 `1`** 출력 (하나라도 `0`이면 `0`)
  * **`OR` (논리합)**: 두 입력 중 **하나라도 `1`이면 `1`** 출력 (둘 다 `0`일 때만 `0`)
  * **`NOT` (부정)**: 입력을 반대로 뒤집음 (`1 → 0`, `0 → 1`)
  * **`XOR` (배타적 논리합)**: 두 입력이 **서로 다를 때만 `1`** 출력 (같으면 `0`)
* **실전 추적 요령**: 눈으로 보지 말고 **각 상자를 통과한 직후의 연결선 위에 중간 결과(`0` 또는 `1`)를 연필로 직접 적어 넣으며** 최종 출력까지 따라갑니다.
  * *예*: 입력 `A = 1, B = 0, C = 1`일 때, `A`를 `NOT` 상자에 넣은 값(`0`)과 `B`(`0`)를 `OR` 상자에 넣으면 중간 결과는 **`0`**이 되고, 이 값(`0`)과 `C`(`1`)를 `AND` 상자에 넣으면 최종 출력은 **`0`**이 됩니다!

### 4.2 화살표 상태 이동 퍼즐 · 가중치 도로망 최단 거리 · 로봇 · 시간표

| 퍼즐 유형 | 시험장 10초 손풀이 요령 및 실전 예시 |
| :---: | :--- |
| **① 화살표 상태 이동**<br>(자판기 / 개찰구 규칙) | • 현재 상태 동그라미 위에 연필 끝을 올려놓고, **입력 기호(`A → B → A`)가 들어올 때마다 해당 화살표를 따라 한 칸씩 이동**하며 도착 상태를 적습니다.<br>• *예*: `[S0] ──(A)──▶ [S1] ──(B)──▶ [S2] ──(A)──▶ [S1]` 규칙에서 `S0` 출발 후 `A → B → A` 입력 시 최종 **`S1`** 도착! |
| **② 연결 그래프 최단 거리**<br>(최소 시간 / 최소 비용) | • 두 지점을 잇는 선 위에 적힌 숫자(시간/비용)를 더할 때, **선 개수가 많아도 숫자의 합이 더 작은 우회 경로가 없는지** 반드시 확인합니다.<br>• *예*: `A→B(2분)`, `B→D(5분)`, `B→C(1분)`, `C→D(2분)`이면 `A→B→D(7분)`보다 **`A→B→C→D(2+1+2 = 5분)`**가 최단 경로! |
| **③ 격자판 로봇 이동**<br>(전진 `F` · 회전 `L`/`R`) | • **★ 실수 방지 핵심**: **`좌회전(L, 왼쪽 90도)` / `우회전(R, 오른쪽 90도)` 명령은 칸을 이동하지 않고 제자리에서 바라보는 방향(`▲ 북, ▶ 동, ▼ 남, ◀ 서`)만 바꿉니다!**<br>• *예*: `(0,0)` 동쪽(`▶`) 시작 후 `F - L - F` 실행 ➔ `(1,0) ▶` ➔ `(1,0) ▲(북쪽 회전)` ➔ **`(1,1) ▲`** 도착! |
