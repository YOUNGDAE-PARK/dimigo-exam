## 2. 문항별 상세 해설

### [Part 1. 제2단원: 수리추론 영역 해설]

**1. [정답] ③ (8비트)**
* **[해설]**: `n`비트로 표현할 수 있는 최대 가짓수는 **`2ⁿ`개**입니다. `2⁷ = 128`이고 `2⁸ = 256`이므로, 150개의 사물함을 구별하려면 `2ⁿ ≥ 150`을 만족하는 최소 자연수인 **`8비트`**가 필요합니다.

**2. [정답] ② (13)**
* **[해설]**: `11010₂`와 `10111₂`를 각 자리별로 비교하여 서로 다를 때만 `1`을 적으면(`XOR` 연산):
  * 첫째 자리(`1, 1` 같음=`0`), 둘째 자리(`1, 0` 다름=`1`), 셋째 자리(`0, 1` 다름=`1`), 넷째 자리(`1, 1` 같음=`0`), 다섯째 자리(`0, 1` 다름=`1`) ──▶ 결과: **`01101₂`**
  * 이를 10진수로 변환하면 자리값(`16, 8, 4, 2, 1`)에 따라 `0 + 8 + 4 + 0 + 1 = 13`입니다.

**3. [정답] ③ (`DATA`, `25`)**
* **[해설]**:
  1. **시저 암호 해독**: 암호화할 때 알파벳을 오른쪽(뒤)으로 4칸(`+4`) 이동했으므로, 암호문 **`HEXE`**를 원래 단어로 복호화할 때는 반대로 **왼쪽(앞)으로 4칸(`-4`)** 되돌립니다. `H(8번째)-4 = D(4번째)`, `E(5번째)-4 = A(1번째)`, `X(24번째)-4 = T(20번째)`, `E(5번째)-4 = A(1번째)` ──▶ **`DATA`**
  2. **규칙 연산 `★`**: 괄호 안의 `3 ★ 4 = (3 × 4) - (3 + 4) + 2 = 12 - 7 + 2 = 7`을 먼저 구한 뒤, `7 ★ 5 = (7 × 5) - (7 + 5) + 2 = 35 - 12 + 2 = 25`입니다.

**4. [정답] ③ (5시간)**
* **[해설]**: 전체 인쇄 작업량을 **`1`**로 놓으면, 1시간당 작업량(일률)은 **`A = 1/10`**, **`B = 1/15`**입니다.
  * 두 프린터가 4시간 동안 함께 한 작업량: `4 × (1/10 + 1/15) = 4 × (5/30) = 4 × (1/6) = 2/3`
  * 남은 작업량은 `1 - 2/3 = 1/3`이며, 이를 `B` 혼자(`1/15`) 인쇄하는 데 걸리는 시간 `t`는 `(1/15) × t = 1/3`이므로 **`t = 5시간`**입니다.

**5. [정답] ③ (35)**
* **[해설]**: 숫자가 커졌다 작아졌다 출렁이는 징검다리 수열이므로 **홀수 번째와 짝수 번째를 분리**합니다.
  * 홀수 번째 항: `3 → 6 → 12 → (가) → 48` (`×2`씩 커지는 규칙이므로 **`(가) = 24`**)
  * 짝수 번째 항: `20 → 17 → 14 → (나) → 8` (`-3`씩 작아지는 규칙이므로 **`(나) = 11`**)
  * 따라서 `(가) + (나) = 24 + 11 = 35`입니다.

**6. [정답] ② (76개)**
* **[해설]**: 1단계는 `6개`이고, 단계가 1씩 커질 때마다 성냥개비가 `5개`씩 늘어납니다 (`6 → 11 → 16 ...`).
  * 따라서 `N단계 성냥개비 개수 = 5N + 1`이며, 15단계(`N = 15`)에서는 `5 × 15 + 1 = 76개`가 필요합니다.

**7. [정답] ③ (방 13개, 학생 62명)**
* **[해설]**: 방의 총개수를 `x`개라고 놓습니다.
  * 4명씩 배정할 때의 학생 수: **`4x + 10`**
  * 6명씩 배정할 때: 빈방 2개와 2명만 들어간 방 1개를 제외한 `(x - 3)`개의 방에는 6명씩 모두 들어가 있으므로 학생 수는 **`6(x - 3) + 2`**입니다.
  * `4x + 10 = 6(x - 3) + 2` ──▶ `4x + 10 = 6x - 16` ──▶ `2x = 26` ──▶ **방 `x = 13개`**
  * 전체 학생 수 = `4 × 13 + 10 = 62명`입니다.

**8. [정답] ② (52가지)**
* **[해설]**: `0`이 포함된 짝수 만들기 문제는 **일의 자리가 `0`인 경우**와 **`2, 4`인 경우**로 나누어 풀어야 합니다.
  1. **일의 자리가 `0`인 경우**: 백의 자리에는 `1~5` 중 `5가지`, 십의 자리에는 남은 `4가지` ──▶ `5 × 4 = 20가지`
  2. **일의 자리가 `2` 또는 `4`인 경우(2가지)**: 백의 자리에는 `0`과 일의 자리 숫자를 제외한 `4가지`, 십의 자리에는 `0`을 포함해 남은 4장 중 `4가지` ──▶ `2 × (4 × 4) = 32가지`
  * 합산하면 `20 + 32 = 52가지`입니다.

**9. [정답] ③ (12개)**
* **[해설]**: 비둘기집 원리에 따라 운이 가장 나쁜 **최악의 상황(4개가 되기 직전인 3개씩만 나오는 경우)**을 먼저 계산합니다. 단, **초록 구슬은 총 2개뿐**이므로 최악의 경우에도 최대 `2개`까지만 나옵니다.
  * 최악의 경우 개수 = `빨강 3개 + 파랑 3개 + 노랑 3개 + 초록 2개 = 11개`
  * 여기서 구슬을 **딱 1개만 더** 꺼내면 반드시 한 색깔이 4개가 완성되므로 `11 + 1 = 12개`입니다.

**10. [정답] ① (8가지)**
* **[해설]**: 출발점 `A(0,0)`의 맨 아랫줄(0행)과 맨 왼쪽 줄(0열) 테두리에 모두 `1`을 적고, 공사 구간 `(1,1)`은 **`0`**으로 취급하여 `왼쪽 숫자 + 아래쪽 숫자`를 차례로 더합니다.
  * **1행**: `(1,0)=1`, `(1,1)=0[✕]`, `(1,2) = 0+1 = 1`, `(1,3) = 1+1 = 2`
  * **2행**: `(2,0)=1`, `(2,1) = 1+0 = 1`, `(2,2) = 1+1 = 2`, `(2,3) = 2+2 = 4`
  * **3행**: `(3,0)=1`, `(3,1) = 1+1 = 2`, `(3,2) = 2+2 = 4`, **`B(3,3) = 4+4 = 8가지`**!

**14. [정답] ② (`B`)**

  * **B**의 말(`"나는 충전기를 빌려 가지 않았어"`)이 거짓말이므로, 실제로 충전기를 빌려 간 범인은 **`B`**입니다.

**15. [정답] ③ (`P: 건달, Q: 기사, R: 건달`)**

  3. 따라서 **`Q`는 기사(참말쟁이)**이고, 기사가 정확히 1명뿐이라는 `Q`의 말이 참이므로 **`R`은 건달**입니다.

### [Part 3. 제4단원: 알고리즘적 문제해결력 영역 해설]

**21. [정답] ② (6)**
* **[해설]**: `N`이 `1`부터 `6`까지 변할 때 홀수이면 `N`을 더하고, 짝수이면 `1`을 뺍니다.
  * `N=1(홀)`: `S = 0 + 1 = 1` ➔ `N=2(짝)`: `S = 1 - 1 = 0` ➔ `N=3(홀)`: `S = 0 + 3 = 3` ➔ `N=4(짝)`: `S = 3 - 1 = 2` ➔ `N=5(홀)`: `S = 2 + 5 = 7` ➔ `N=6(짝)`: **`S = 7 - 1 = 6`** (이후 `N=7`에서 종료)

**22. [정답] ③ (`CNT = 4, A = 18`)**
* **[해설]**: 매 단계마다 `A`는 `+4`, `B`는 `-2`씩 변하므로 두 수의 차이는 한 번에 `6`씩 줄어듭니다.
  * 초기: `A = 2, B = 26, CNT = 0` (`2 < 26` 참)
  * 1회 후: `A = 6, B = 24, CNT = 1` (`6 < 24` 참)
  * 2회 후: `A = 10, B = 22, CNT = 2` (`10 < 22` 참)
  * 3회 후: `A = 14, B = 20, CNT = 3` (`14 < 20` 참)
  * 4회 후: **`A = 18, B = 18, CNT = 4`** (`18 < 18`이 **거짓**이 되어 즉시 반복 종료!)

**23. [정답] ④ (24)**
* **[해설]**: 안쪽 변수 `j`가 `1`부터 현재의 `i`까지 반복됩니다.
  * `i = 1`일 때 (`j = 1`): `(1 + 1) = 2`
  * `i = 2`일 때 (`j = 1, 2`): `(2 + 1) + (2 + 2) = 3 + 4 = 7`
  * `i = 3`일 때 (`j = 1, 2, 3`): `(3 + 1) + (3 + 2) + (3 + 3) = 4 + 5 + 6 = 15`
  * 누적 총합 `TOTAL = 2 + 7 + 15 = 24`입니다.

**24. [정답] ① (15)**
* **[해설]**: `f(12)`부터 바닥 조건인 `f(1)`까지 전개한 뒤, 아래에서 위로 거꾸로 값을 대입하여 계산합니다.
  * `f(12)` [짝수] = `f(6) + 3`
  * `f(6)` [짝수] = `f(3) + 3`
  * `f(3)` [홀수] = `f(2) × 2 - 1`
  * `f(2)` [짝수] = `f(1) + 3`
  * 바닥 조건 **`f(1) = 2`**부터 차례로 올라가면: `f(2) = 2 + 3 = 5` ──▶ `f(3) = 5 × 2 - 1 = 9` ──▶ `f(6) = 9 + 3 = 12` ──▶ **`f(12) = 12 + 3 = 15`**입니다.

**25. [정답] ④ (`4 → 1 → 3 → 2`)**
* **[해설]**: 막힌 골목 주차장(스택, 후입선출)에서 가장 큰 번호인 **`4번`이 맨 처음 나왔다는 것은 `1, 2, 3, 4`번이 모두 순서대로 들어간 상태**임을 뜻합니다. 따라서 남은 차량들은 입구 쪽에 있는 큰 번호부터 **`3 → 2 → 1` 순서로만** 나올 수 있으며, `1`이 `3`이나 `2`보다 먼저 나올 수는 없습니다.

**26. [정답] ② (`[ 4, 2, 3, 5, 6 ]`)**
* **[해설]**: 이웃한 두 수를 비교해 큰 수를 오른쪽으로 밀어내는 정렬(버블 정렬 규칙)입니다.
  * **초기 상태**: `[ 6, 4, 5, 2, 3 ]`
  * **1단계(1회전) 완료**: 가장 큰 수 `6`이 연속으로 자리를 바꾸며 맨 오른쪽 끝에 확정됨 ──▶ **`[ 4, 5, 2, 3 | 6 ]`**
  * **2단계(2회전) 진행**: `(4, 5)` 유지 ➔ `(5, 2)` 교환 ➔ `(5, 3)` 교환으로 두 번째 큰 수 `5`가 뒤에서 두 번째 자리에 확정됨 ──▶ **`[ 4, 2, 3 | 5, 6 ]`**

**27. [정답] ③ (`40 → 53 → 47`)**
* **[해설]**:
  1. **1차 비교**: 전체 9장 `[12, 18, 25, 31, 40, 47, 53, 62, 75]`의 정가운데(5번째) 카드인 **`40`**을 확인합니다 (`47 > 40`이므로 `12~40` 버림).
  2. **2차 비교**: 남은 4장 `[47, 53, 62, 75]` 중 가운데 왼쪽(2번째) 카드인 **`53`**을 확인합니다 (`47 < 53`이므로 `53~75` 버림).
  3. **3차 비교**: 마지막 남은 1장인 **`47`**을 확인하여 탐색을 완료합니다 (`40 → 53 → 47`).

**28. [정답] ④ (`X = 1, Y = 1, OUT = 1`)**
* **[해설]**: 입력이 `A = 1, B = 0, C = 0`일 때 각 상자의 출력을 차례대로 추적합니다.
  * **[1단계] `X`**: `A(1)`와 `B(0)`는 서로 다르므로 `XOR` 상자 출력 **`X = 1`**
  * **[2단계] `Y`**: `B(0)`와 `C(0)`를 `OR` 상자에 넣으면 `0`이고, 이를 `NOT` 상자로 뒤집으면 **`Y = 1`**
  * **[3단계] `OUT`**: `X(1)`와 `Y(1)`가 모두 `1`이므로 `AND` 상자 최종 출력 **`OUT = 1`**

**29. [정답] ① (`(2, 1)`, 동쪽 `▶`)**
* **[해설]**: 회전 명령(`R`, `L`)은 좌표를 바꾸지 않고 바라보는 방향만 바꾼다는 점에 주의하여 추적합니다.
  * 시작: `(0, 0)` 북(`▲`) ──(`F → F`)──▶ `(0, 2)` 북(`▲`) ──(`R`)──▶ `(0, 2)` 동(`▶`) ──(`F`)──▶ `(1, 2)` 동(`▶`) ──(`R`)──▶ `(1, 2)` 남(`▼`) ──(`F`)──▶ `(1, 1)` 남(`▼`) ──(`L`: 남쪽에서 반시계 90도 회전은 동쪽!)──▶ `(1, 1)` 동(`▶`) ──(`F`)──▶ **`(2, 1)` 동쪽(`▶`)**

**30. [정답] ④ (최대 4개: `B → C → E → F`)**
* **[해설]**: 가장 많은 활동에 참여하려면 무조건 **[ 종료 시각이 가장 빠른 특강 ]**부터 차례대로 선택해야 합니다.
  1. 가장 일찍 끝나는 **`B (09:30 ~ 10:30)`** 선택 (`A`는 겹치므로 제외)
  2. `10:30` 이후 시작하면서 가장 일찍 끝나는 **`C (10:30 ~ 11:30)`** 선택 (`D`는 겹치므로 제외)
  3. `11:30` 이후 시작하면서 가장 일찍 끝나는 **`E (11:30 ~ 12:30)`** 선택
  4. `12:30`에 시작하는 **`F (12:30 ~ 14:00)`** 선택 ──▶ **총 4개 (`B → C → E → F`)**
