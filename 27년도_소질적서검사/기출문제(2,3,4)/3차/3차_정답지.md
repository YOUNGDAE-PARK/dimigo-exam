## 2. 문항별 상세 해설 및 스캔 키워드 공략법

### [Part 1. 컴퓨팅 시스템 & 네트워크 필수 정의 해설]

**1. [정답] ⑤ (CPU)**
* **스캔 키워드**: `brain`, `arithmetic operations`, `logical comparisons`, `control functions`, `executing instructions`
* **해설**: 컴퓨터의 '두뇌' 역할을 수행하며 산술·논리 연산과 제어 기능을 실행하는 핵심 부품은 **중앙처리장치(CPU)**입니다. SSD는 보조기억장치, RAM은 주기억장치, GPU는 그래픽 연산 장치, ROM은 부팅 펌웨어 저장 장치입니다.

**2. [정답] ③ ((A) RAM - (B) ROM)**
* **스캔 키워드**:
  * (A): `volatile memory`(휘발성 메모리), `temporarily stores`, `lost when electrical power is turned off`(전원 차단 시 소멸) ➔ **RAM (주기억장치)**
  * (B): `non-volatile memory`(비휘발성 메모리), `BIOS`, `remain permanently even without power`(전원 없어도 영구 유지) ➔ **ROM (읽기 전용 메모리)**
* **해설**: 전원이 꺼졌을 때 내용이 사라지는 휘발성 메모리는 RAM이고, 부팅 프로그램(BIOS)을 담고 있어 전원이 꺼져도 유지되는 비휘발성 읽기 전용 메모리는 ROM입니다.

**3. [정답] ④ (Cache Memory)**
* **스캔 키워드**: `between fast CPU and slower main memory (RAM)`, `frequently accessed data`, `speed gap (bottleneck)`
* **해설**: 초고속 CPU와 상대적으로 느린 주기억장치(RAM) 사이에서 속도 차이(병목 현상)를 완화하기 위해 자주 사용하는 데이터와 명령어를 임시 저장하는 초고속 소용량 메모리는 **캐시 메모리(Cache Memory)**입니다.

**4. [정답] ① ((A) Compiler - (B) Interpreter)**
* **스캔 키워드**:
  * (A): `entire source code into machine code all at once`(전체 코드를 한꺼번에 번역) ➔ **Compiler (컴파일러)**
  * (B): `line by line immediately`(한 줄씩 즉시 번역 및 실행) ➔ **Interpreter (인터프리터)**
* **해설**: C, Java 등 소스 코드 전체를 한 번에 기계어로 번역하여 실행 파일을 만드는 도구는 컴파일러이고, Python, JavaScript처럼 소스 코드를 한 줄씩 읽어가며 즉시 실행하는 도구는 인터프리터입니다.

**5. [정답] ③ (Switch)**
* **스캔 키워드**: `inspects hardware MAC addresses`, `only to the specific intended recipient device`, `within the same local area network (LAN)`
* **해설**: 허브(Hub)는 들어온 데이터를 모든 포트에 무조건 뿌리지만, **스위치(Switch)**는 하드웨어 **MAC 주소**를 확인하여 같은 LAN 내의 **해당 목적지 기기에만** 선별적으로 전달하는 지능형 장비입니다.

**6. [정답] ② (MAC Address)**
* **스캔 키워드**: `permanent, unique physical address`, `network interface card (NIC)`, `manufacturer at the factory`, `hexadecimal digits (00:1A:2B:3C:4D:5E)`
* **해설**: 네트워크 카드(NIC) 제조 시 물리적으로 부여되는 고유 식별 번호로 16진수 6쌍 형태로 표기되는 것은 **MAC 주소(물리적 주소)**입니다. 네트워크 접속 위치에 따라 변경 가능한 것은 논리적 주소인 IP 주소입니다.

**7. [정답] ④ ((A) Router - (B) Access Point (AP))**
* **스캔 키워드**:
  * (A): `forwards data packets between different networks`(서로 다른 네트워크 간 패킷 전달), `optimal path`(최적 경로), `IP addresses` ➔ **Router (라우터)**
  * (B): `wireless devices connect to a wired network`(무선 기기를 유선 네트워크에 연결), `Wi-Fi radio waves` ➔ **Access Point (무선 AP)**
* **해설**: IP 주소를 기반으로 최적 경로를 찾아 서로 다른 네트워크(LAN-WAN)를 연결하는 장비는 라우터이고, 스마트폰이나 노트북 같은 무선 기기가 Wi-Fi 전파를 통해 유선 네트워크에 접속할 수 있도록 해주는 장치는 무선 접속 장치(AP)입니다.

**8. [정답] ① ((A) Firewall - (B) Proxy Server)**
* **스캔 키워드**:
  * (A): `monitors and filters incoming and outgoing network traffic`, `blocking unauthorized external connections` ➔ **Firewall (방화벽)**
  * (B): `acts as a gateway / intermediary between client and wider Internet`, `cache web content`, `filter traffic` ➔ **Proxy Server (프록시 서버)**
* **해설**: 정해진 보안 규칙에 따라 허용되지 않은 트래픽을 차단하는 보안 시스템은 방화벽이고, 클라이언트와 인터넷 사이에서 대리인(중간 다리) 역할을 하며 캐싱과 보안 필터링을 수행하는 서버는 프록시 서버입니다.

**9. [정답] ⑤ ((A) Bandwidth - (B) Latency)**
* **스캔 키워드**:
  * (A): `maximum volume of digital data transmitted within fixed time`(단위 시간당 최대 전송량), `width of highway`(도로 폭) ➔ **Bandwidth (대역폭)**
  * (B): `time delay for data packet to travel`(데이터가 전달되는 지연 시간) ➔ **Latency (지연 시간)**
* **해설**: 고속도로의 차선 폭에 비유되며 한 번에 보낼 수 있는 데이터 전송 용량은 대역폭(Bandwidth)이고, 데이터가 출발지에서 목적지까지 이동하는 데 걸리는 시간 지연은 지연 시간(Latency)입니다.

**10. [정답] ① ((A) Sensor - (B) Actuator)**
* **스캔 키워드**:
  * (A): `input device`, `detects physical changes in environment`(물리적 변화 감지), `converts into electronic signals` ➔ **Sensor (센서)**
  * (B): `output component`, `converts electronic control signals into physical motion or action`(물리적 동작/운동으로 변환) ➔ **Actuator (액추에이터)**
* **해설**: 주변 환경(빛, 온도, 소리 등)의 물리적 변화를 감지하여 전기 신호로 입력하는 장치는 센서이고, 제어 신호를 받아 모터 회전이나 불빛 점등 같은 물리적 동작으로 출력하는 부품은 액추에이터입니다.

### [Part 2. 데이터 & 진법 & 멀티미디어 필수 정의 해설]

**11. [정답] ① ((A) Bit - (B) Byte)**
* **스캔 키워드**:
  * (A): `smallest unit of storage`, `binary value of either 0 or 1` ➔ **Bit (비트)**
  * (B): `collection of 8 basic units`, `256 possible combinations (2⁸)`, `single alphanumeric character` ➔ **Byte (바이트)**
* **해설**: 0 또는 1을 나타내는 컴퓨터 데이터의 최소 기본 단위는 비트(Bit)이며, 비트 8개가 모여 1글자를 표현하는 단위는 바이트(Byte)입니다.

**12. [정답] ④ (Unicode)**
* **스캔 키워드**: `international character encoding standard`, `all written human languages across the globe`, `Korean, Chinese, Arabic, and modern emojis`
* **해설**: 영문 중심의 7비트 아스키코드(ASCII)의 한계를 극복하고, 전 세계의 모든 언어(한글, 한자, 아랍어 등)와 이모티콘에 고유한 코드 값을 부여한 국제 표준 문자 인코딩 규격은 **유니코드(Unicode)**입니다.

**13. [정답] ③ (Vector Graphics)**
* **스캔 키워드**: `mathematical formulas, geometric points, lines, curves`, `scaled infinitely without pixelation or loss of clarity`
* **해설**: 픽셀 격자망으로 이미지를 구성하는 비트맵(래스터)과 달리, 수학적 공식(점, 선, 곡선, 좌표)으로 이미지를 표현하여 아무리 확대해도 계단 현상(깨짐 현상)이 발생하지 않는 방식은 **벡터 그래픽(Vector Graphics)**입니다.

**14. [정답] ⑤ (Data Compression)**
* **스캔 키워드**: `fewer bits than original representation`, `reducing total file size`, `stored efficiently`, `transmitted significantly faster`
* **해설**: 원래의 데이터를 표현하는 데 필요한 비트 수를 줄여 파일 크기를 축소함으로써 저장 공간을 절약하고 전송 속도를 높이는 기술은 **데이터 압축(Data Compression)**입니다.

**15. [정답] ② ((A) Structured Data - (B) Unstructured Data)**
* **스캔 키워드**:
  * (A): `predefined rows and columns within tabular formats`, `relational database tables, spreadsheets` ➔ **Structured Data (정형 데이터)**
  * (B): `does not follow a predefined conceptual structure or schema`, `video streaming, audio, text, social media` ➔ **Unstructured Data (비정형 데이터)**
* **해설**: 행과 열이라는 고정된 표 형태로 규격화된 데이터는 정형 데이터이고, 동영상, 음성, 자유 텍스트처럼 고정된 틀이 없는 데이터는 비정형 데이터입니다.

**16. [정답] ⑤ ((A) Database (DB) - (B) Big Data)**
* **스캔 키워드**:
  * (A): `organized collection of related data`, `search, retrieve, update, and manage` ➔ **Database (데이터베이스)**
  * (B): `vast, complex, rapidly multiplying datasets`, `'3V' attributes (Volume, Velocity, Variety)` ➔ **Big Data (빅데이터)**
* **해설**: 여러 사람이나 응용 프로그램이 공유하여 검색, 갱신, 관리할 수 있도록 정리된 데이터의 집합은 데이터베이스(DB)이며, 규모(Volume), 생성 속도(Velocity), 다양성(Variety)이라는 3V 특성을 가지는 대규모 데이터 집합은 빅데이터(Big Data)입니다.

### [Part 3. 알고리즘 & 프로그래밍 필수 정의 해설]

**17. [정답] ③ (Abstraction)**
* **스캔 키워드**: `removing unnecessary, trivial details`(불필요한 세부사항 제거), `essential and core characteristics`(핵심 요소에 집중), `simplify complex realities`
* **해설**: 복잡한 문제에서 불필요하거나 지엽적인 요소를 제거하고 문제 해결에 꼭 필요한 핵심 특징만을 뽑아내어 단순화하는 컴퓨팅 사고력의 핵심 요소는 **추상화(Abstraction)**입니다.

**18. [정답] ② ((A) Pseudocode - (B) Flowchart)**
* **스캔 키워드**:
  * (A): `informal, human-readable method`, `conversational human language with structural logic` ➔ **Pseudocode (의사코드)**
  * (B): `visual diagram`, `geometric shapes (rectangles, diamonds) interconnected by directional arrows` ➔ **Flowchart (순서도)**
* **해설**: 엄격한 프로그래밍 언어의 문법을 따르지 않고 일상 언어와 프로그래밍 구조를 섞어 사람이 이해하기 쉽게 표현한 글 형태의 알고리즘은 의사코드이고, 기하학적 도형과 화살표를 이용해 알고리즘의 흐름을 시각적으로 나타낸 도표는 순서도입니다.

**19. [정답] ④ ((A) Variable - (B) Array (List))**
* **스캔 키워드**:
  * (A): `named storage container in memory`, `value can change dynamically` ➔ **Variable (변수)**
  * (B): `linear data structure`, `contiguous memory slots`, `referenced by numerical position called an index` ➔ **Array / List (배열/리스트)**
* **해설**: 프로그램 실행 도중 값이 변할 수 있는 메모리 내의 이름 붙은 저장 공간은 변수(Variable)이며, 연속된 공간에 데이터를 순서대로 모아 두고 인덱스(번호)로 접근하는 자료구조는 배열 또는 리스트(Array/List)입니다.

**20. [정답] ① ((A) Conditional - (B) Loop (Iteration))**
* **스캔 키워드**:
  * (A): `diverge into different branching paths`, `logical condition evaluates to true or false` ➔ **Conditional (조건문 / 선택 구조)**
  * (B): `repeatedly executes a designated block of code`, `boolean condition remains satisfied or predetermined number of iterations` ➔ **Loop / Iteration (반복문 / 반복 구조)**
* **해설**: 조건의 참/거짓 여부에 따라 실행 흐름을 여러 갈래로 분기시키는 문장은 조건문(`if-else`)이고, 정해진 횟수나 조건이 만족되는 동안 동일한 코드 블록을 되풀이 실행하는 구조는 반복문(`for`/`while`)입니다.

**21. [정답] ⑤ ((A) Syntax Error - (B) Logical Error)**
* **스캔 키워드**:
  * (A): `breaking grammatical or structural rules`, `prevents code from compiling or executing at all` ➔ **Syntax Error (문법 오류)**
  * (B): `runs successfully without crashing`, `consistently produces incorrect or unintended results` ➔ **Logical Error (논리 오류)**
* **해설**: 언어의 문법 규칙을 위반하여 컴파일이나 실행 자체가 불가능한 에러는 문법 오류(Syntax Error)이고, 프로그램은 정상적으로 실행되어 종료되지만 설계상의 잘못으로 원치 않는 엉뚱한 결괏값이 도출되는 에러는 논리 오류(Logical Error)입니다.

### [Part 4. 인공지능 필수 정의 해설]

**22. [정답] ④ ((A) Machine Learning - (B) Deep Learning)**
* **스캔 키워드**:
  * (A): `learn patterns automatically from data`, `without being explicitly hardcoded` ➔ **Machine Learning (기계학습)**
  * (B): `multi-layered artificial neural networks`, `human brain`, `image and speech recognition` ➔ **Deep Learning (딥러닝)**
* **해설**: 규칙을 직접 프로그래밍하지 않고 데이터로부터 컴퓨터가 스스로 패턴을 학습하는 분야는 기계학습(머신러닝)이고, 인간 뇌의 신경망 구조를 모방한 다층 인공신경망 기반의 심층 기계학습 기법은 딥러닝입니다.

**23. [정답] ① ((가) 지도학습 - (나) 비지도학습 - (다) 강화학습)**
* **스캔 키워드**:
  * (가): `labeled inputs paired with known ground-truth correct answers` ➔ **Supervised Learning (지도학습)**
  * (나): `unlabeled data without any predefined answers`, `inherent structures / natural groupings (clusters)` ➔ **Unsupervised Learning (비지도학습)**
  * (다): `autonomous agent interacts with environment`, `trial and error`, `maximize cumulative rewards` ➔ **Reinforcement Learning (강화학습)**
* **해설**: 문제와 정답이 함께 있는 레이블 데이터를 학습하는 것은 지도학습, 정답이 없는 데이터에서 군집이나 패턴을 스스로 찾는 것은 비지도학습, 환경과의 상호작용 속에서 보상을 최대화하도록 시행착오를 거쳐 학습하는 것은 강화학습입니다.

**24. [정답] ② ((A) Test Data - (B) Hallucination)**
* **스캔 키워드**:
  * (A): `never shown during training phase`, `evaluate model's predictive accuracy and generalization` ➔ **Test Data (테스트 데이터)**
  * (B): `generative AI fabricates confident responses`, `factually incorrect, ungrounded in real data` ➔ **Hallucination (환각 현상)**
* **해설**: AI 모델의 학습에 쓰이지 않고 학습 완료 후 모델의 성능을 공정하게 평가하기 위해 따로 떼어 둔 데이터는 테스트 데이터입니다. 대형 언어 모델(LLM)이 거짓 정보를 마치 사실인 것처럼 그럴듯하게 지어내는 현상은 환각(Hallucination)이라고 부릅니다.

**25. [정답] ⑤ (Algorithmic Bias)**
* **스캔 키워드**: `unfair, prejudiced, or discriminatory outcomes against specific demographic groups`, `unrepresentative, historically skewed training data`
* **해설**: 훈련 데이터 자체에 내포된 사회적 편견이나 불균형으로 인해 인공지능 모델이 특정 인종, 성별, 집단에 대해 차별적이거나 불공정한 판단을 내리는 문제는 **알고리즘/데이터 편향(Algorithmic Bias)**입니다.

**26. [정답] ③ (Generative AI)**
* **스캔 키워드**: `create novel and original digital content`, `essays, computer code, artwork, music`, `learning statistical structures of massive datasets`
* **해설**: 기존 데이터를 단순히 분류하거나 예측하는 데 그치지 않고, 텍스트, 이미지, 오디오, 소스 코드 등의 새로운 창작물을 직접 생성해 내는 최신 AI 기술은 **생성형 인공지능(Generative AI)**입니다.

### [Part 5. 디지털 문화 & 정보 보안 필수 정의 해설]

**27. [정답] ② ((A) Internet of Things (IoT) - (B) Cloud Computing)**
* **스캔 키워드**:
  * (A): `physical objects ('things') embedded with sensors`, `collect and exchange telemetry data over Internet` ➔ **Internet of Things (IoT, 사물인터넷)**
  * (B): `on-demand delivery of diverse computing services over Internet`, `eliminating requirement to buy local physical data centers` ➔ **Cloud Computing (클라우드 컴퓨팅)**
* **해설**: 가전제품이나 자동차 같은 사물에 센서와 통신 기능을 탑재하여 인터넷으로 데이터를 주고받는 기술은 사물인터넷(IoT)이고, 인터넷망을 통해 저장 공간, 서버, 소프트웨어 등의 컴퓨팅 자원을 필요할 때마다 원격으로 빌려 쓰는 서비스는 클라우드 컴퓨팅입니다.

**28. [정답] ④ ((A) Ransomware - (B) Phishing)**
* **스캔 키워드**:
  * (A): `encrypts victim's critical files or locks OS`, `demanding a ransom payment` ➔ **Ransomware (랜섬웨어)**
  * (B): `forged emails / SMS / fake websites`, `trick users into disclosing sensitive personal credentials` ➔ **Phishing (피싱)**
* **해설**: 시스템이나 파일을 인질로 삼아 암호화한 뒤 이를 풀어주는 대가로 금전(몸값)을 요구하는 악성코드는 랜섬웨어(Ransomware)이고, 금융기관이나 공공기관을 사칭해 비밀번호나 금융 정보를 빼돌리는 사회공학적 공격 기법은 피싱(Phishing)입니다.

**29. [정답] ③ ((가) 기밀성 - (나) 무결성 - (다) 가용성)**
* **스캔 키워드**:
  * (가): `strictly to authorized individuals`, `preventing unauthorized viewing or leaks` ➔ **Confidentiality (기밀성)**
  * (나): `accurate, authentic`, `protected against improper, unauthorized modifications` ➔ **Integrity (무결성)**
  * (다): `promptly accessible whenever needed`, `resisting denial-of-service attacks` ➔ **Availability (가용성)**
* **해설**: 오직 인가된 사람만 열람할 수 있도록 비밀을 보장하는 것은 기밀성(Confidentiality), 데이터가 부당하게 위조·변조되지 않고 완전무결함을 보장하는 것은 무결성(Integrity), 인가된 사용자가 원하는 시점에 언제든 시스템을 정상 이용할 수 있음을 보장하는 것은 가용성(Availability)입니다.

**30. [정답] ② ((A) Public-Key (Asymmetric) Encryption - (B) Open Source Software)**
* **스캔 키워드**:
  * (A): `pair of two different keys`, `public key distributed freely to encrypt`, `private key kept secret to decrypt` ➔ **Public-Key (Asymmetric) Encryption (공개키/비대칭키 암호화)**
  * (B): `source code is made publicly available for everyone`, `inspect, modify, improve, and freely redistribute` ➔ **Open Source Software (오픈소스 소프트웨어)**
* **해설**: 암호화할 때 쓰는 공개키와 복호화할 때 쓰는 개인키라는 서로 다른 키 한 쌍을 사용하여 안전하게 암호 통신을 구현하는 기술은 공개키(비대칭키) 암호화이며, 원본 소스 코드를 대중에게 투명하게 공개하여 누구나 검토, 수정, 재배포할 수 있도록 허용한 소프트웨어는 오픈소스 소프트웨어(OSS)입니다.
