# 제3단원: 논리·추리 퍼즐 및 교과융합 조건 독해 (디미고 소질·적성검사 실전 해법)

> **디미고 일반전형 출제 기준 점검**:
> * **출제 범위**: 고등학교 수학의 집합·명제 용어(`역·이·대우`, `드모르간 법칙`, `필요충분조건`)를 암기해서 답하는 시험이 아닙니다.
> * **핵심 평가 내용**: 중학교 수준의 국어·영어 독해력과 논리적 사고력을 결합하여 **① 조건 문장 뒤집기(`P → Q`이면 `~Q → ~P`)와 꼬리물기 추론**, **② 참말·거짓말쟁이 모순 추리**, **③ `O`/`X` 표 소거법과 순서·자리 배치 퍼즐**, **④ 국어 조건·규칙 독해 및 영어 IT 핵심 키워드 스캔 독해**를 평가합니다.

## 1. 조건 문장 추론과 꼬리물기 (삼단논법)

### 1.1 조건 문장 뒤집기 절대 법칙 (`"P이면 Q이다"` ➔ `"Q가 아니면 P가 아니다"`)

문제에서 **`"A이면 B이다 (A → B)"`라는 조건이 참일 때, 유일하게 100% 참이 보장되는 문장은 앞뒤를 바꾸면서 동시에 부정한 `"B가 아니면 A가 아니다 (~B → ~A)"`뿐**입니다!

| 조건 문장 변형 | 예시 문장 (원래 조건: **"코딩 동아리 부원이면 노트북을 가지고 있다"**) | 반드시 참인가? |
| :---: | :--- | :---: |
| **원래 조건 (`A → B`)** | "코딩 동아리 부원(`A`)이면 노트북을 가지고 있다(`B`)." | **⭕ 참 (기준)** |
| **앞뒤만 바꿈 (`B → A`)** | "노트북이 있으면 코딩 동아리 부원이다." *(일반 학생도 노트북이 있을 수 있음)* | **❌ 알 수 없음 (함정 1순위)** |
| **단순 부정 (`~A → ~B`)** | "코딩 동아리 부원이 아니면 노트북이 없다." | **❌ 알 수 없음 (함정 2순위)** |
| **★ 뒤집어 부정 (`~B → ~A`)**<br>*(대우 관계)* | **"노트북이 없으면(`~B`), 코딩 동아리 부원이 아니다(`~A`)."** | **⭕ 무조건 100% 참!** |

### 1.2 징검다리 꼬리물기 추론 (삼단논법 사슬 연결)

복잡한 조건 문장 3~4개가 주어지고 `"다음 중 반드시 참인 것은?"`을 물으면, 각 문장과 **뒤집어 부정한 문장(`~B → ~A`)**을 화살표로 길게 연결합니다.

```
[주어진 조건]
  (가) A가 참석하면 B도 참석한다.        ──▶  A ──▶ B   (뒤집기: ~B ──▶ ~A)
  (나) C가 참석하지 않으면 B도 안 한다.  ──▶ ~C ──▶ ~B  (뒤집기:  B ──▶ C)
  (다) C가 참석하면 D는 참석하지 않는다. ──▶  C ──▶ ~D  (뒤집기:  D ──▶ ~C)

[화살표 사슬 하나로 잇기]
  • 정방향 연결 :  A ──▶ B ──▶ C ──▶ ~D   (결론 1: "A가 참석하면 D는 참석하지 않는다.")
  • 역방향 연결 :  D ──▶ ~C ──▶ ~B ──▶ ~A  (결론 2: "D가 참석하면 A는 참석하지 않는다.")
```

### 1.3 조건 부정 뒤집기(`그리고 ↔ 또는`, `모두 ↔ 적어도 한 명`) & 카드 뒤집기

| 규칙 구분 | 핵심 변환 공식 (오답 함정 주의!) | 실전 예시 |
| :---: | :--- | :--- |
| **`그리고(AND)` / `또는(OR)`<br>조건을 어긴 경우** | • **`"A 그리고 B"`를 어긴 경우 = `A가 아니거나(OR) B가 아님`**<br>• **`"A 또는 B"`를 어긴 경우 = `A도 아니고(AND) B도 아님`** | • 선생님 지시: `"수학 또는 코딩 보충에 참여해라"`<br>  ➔ 지시를 어긴 경우: **`"수학도 안 가고 코딩도 안 갔다"`** |
| **`모두` / `어떤`<br>문장의 반대(부정)** | • **`"모든 학생이 ~이다"`가 거짓 = `"적어도 1명은 ~이 아니다"`**<br>*(주의: "모든 학생이 ~이 아니다"로 고르면 100% 오답!)* | • `"모든 학생이 안경을 썼다"`가 거짓이면?<br>  ➔ **`"안경을 쓰지 않은 학생이 적어도 1명 있다"`** |
| **규칙 확인 카드 뒤집기**<br>(`"P이면 Q이다"` 검증) | 규칙 **`"앞면이 P이면 뒷면은 Q이다"`**가 맞는지 확인할 때:<br>➔ **`① P 카드(앞면 조건)`**와 **`② Q가 아닌 카드(뒷면 위반)`** 딱 2장만 뒤집음! | • 규칙: `"모음 카드 뒷면엔 짝수가 적혀 있다"` (`[A] [B] [2] [7]`)<br>  ➔ 모음 **`[ A ]`**와 짝수가 아닌 홀수 **`[ 7 ]`** 2장만 뒤집음! |

## 2. 참말쟁이 · 거짓말쟁이 진위 판별 퍼즐

### 2.1 유형 ①: 참말/거짓말 인원수가 주어질 때 ➔ '모순 쌍(반대말)' 먼저 찾기!

* **[실전 예제]**: 유리창을 깬 범인은 1명이고, 네 사람 중 **'오직 1명만 참말'**을 하고 나머지 3명은 거짓말을 한다.
  * **A**: `"나는 안 깼어요."`
  * **B**: `"C가 유리창을 깼어요."`
  * **C**: `"B는 거짓말을 하고 있어요."`
  * **D**: `"C가 깬 게 맞아요."`
* **[10초 해결 과정]**:
  1. **[모순 쌍 포착]**: **B와 C는 서로 정반대 주장**을 하므로, 둘 중 1명은 무조건 참말이고 1명은 무조건 거짓말입니다!
  2. **[나머지 인원 확정]**: 참말을 하는 단 1명은 반드시 `{B, C}` 안에 있으므로, 나머지 **A와 D의 말은 볼 것도 없이 무조건 거짓말(F)**입니다.
  3. **[결론 도출]**: A의 말(`"나는 안 깼어요"`)이 거짓말이므로 ──▶ **실제 유리창을 깬 범인은 `A`!**

### 2.2 유형 ②: 스스로를 포함한 진술 ➔ '만약 ~라면(가정법)'으로 모순 찾기

참말 인원수가 안 주어지고 `"우리 둘 중 적어도 한 명은 거짓말쟁이이다"`처럼 말할 때는 **발언자 `A`가 참말쟁이인 경우와 거짓말쟁이인 경우 2가지를 가정하여 모순이 없는 쪽**을 고릅니다.
* **[실전 예제]**: 항상 참말만 하는 '기사'와 거짓말만 하는 '건달'이 사는 섬에서 **A가 `"우리 둘 중 적어도 한 명은 건달입니다"`**라고 말했다.
  * **가정 1 (만약 A가 건달[거짓말쟁이]이라면?)**: A 자신이 이미 건달이므로 `"적어도 한 명은 건달이다"`라는 말은 **참말**이 되어버립니다! (건달이 참말을 했으므로 **모순 ❌**)
  * **가정 2 (만약 A가 기사[참말쟁이]라면?)**: A의 말이 참이 되려면 둘 중 적어도 한 명은 건달이어야 하므로, **B가 건달**이면 모순 없이 완벽히 성립합니다! (──▶ **정답: `A = 기사, B = 건달` ⭕**)

## 3. `O`/`X` 그리드 매칭 & 일렬 · 원탁 자리 배치 퍼즐

### 3.1 `O`/`X` 매트릭스 십자(`+`) 소거법 (1:1 매칭 퍼즐)

1:1 매칭 퍼즐은 **표를 그려 `O`가 하나 확정될 때마다 그 칸의 가로줄·세로줄 전체를 `X`로 지우면** 빈칸이 연쇄적으로 풀립니다.

| 구분 | 웹툰 | 해킹 | AI | 단계별 십자(`+`) 소거 추론 과정 |
| :---: | :---: | :---: | :---: | :--- |
| **갑** | `X` | `X` | **`O`** | **3단계**: 남은 빈칸에 **`갑 = AI (O)`** 자동 확정! |
| **을** | **`O`** | `X` | `X` | **2단계**: 단서 `"AI 동아리 학생은 을보다 키가 크다(을 ≠ AI)"` ➔ **`을 = 웹툰 (O)`** 확정! |
| **병** | `X` | **`O`** | `X` | **1단계**: 단서 `"병은 해킹 동아리다"` ➔ **`병 = 해킹 (O)`** 확정 즉시 가로·세로줄 모두 `X` 소거! |

### 3.2 일렬 순서 배치 & 원탁(마주보기) 배치 요령

| 배치 유형 | 핵심 도식화 및 해결 요령 |
| :---: | :--- |
| **① 일렬 배치 / 달리기 등수 /<br>아파트 층별 배정** | • **빈칸 슬롯 먼저 그리기**: `[ 1 ] [ 2 ] [ 3 ] [ 4 ]`<br>• `"D는 A 바로 다음에 들어왔다"` ──▶ **`[ A D ]` 한 묶음 블록**으로 묶어서 이동!<br>• `"A와 C 사이에 1명이 있다"` ──▶ **`[ A □ C ]` 또는 `[ C □ A ]`**<br>• `"A는 1등도 꼴찌도 아니다"` ──▶ 양끝을 제외하고 **가운데(2등 또는 3등)**로 후보 압축! |
| **② 원탁(정육각형) 마주보기 배치** | • 6명이 둥근 탁자에 같은 간격으로 앉을 때 시계 방향으로 `1, 2, 3, 4, 5, 6`번 자리를 매기면 **마주보는 짝은 `1↔4`, `2↔5`, `3↔6`**(번호 차이 `+3`)입니다.<br>• 가장 단서가 많은 **기준 인물 1명을 `1번` 자리에 먼저 고정**한 뒤 왼쪽·오른쪽·마주보는 자리를 채웁니다. |

## 4. 고전 전략 퍼즐 & 국어 · 영어 교과융합 독해법

### 4.1 3대 고전 논리·전략 퍼즐 (필승 게임 · 하노이 탑 · 강 건너기)

| 퍼즐 유형 | 핵심 해결 원리 및 10초 공식 |
| :---: | :--- |
| **필승 숫자/바둑돌 게임**<br>(마지막 돌 가져가기) | • 한 번에 **`1개 ~ K개`**까지 가져갈 수 있을 때, **상대방이 몇 개를 가져가든 내 차례와 합쳐 항상 `(1 + K)개`씩 맞추면** 무조건 이깁니다!<br>• *예*: 돌 20개 중 한 번에 `1~3개` 가져갈 때 ➔ 묶음 단위는 **`1 + 3 = 4개`** (상대가 1개 가져가면 나는 3개, 상대가 2개면 나는 2개를 가져가서 4개씩 맞춤) |
| **하노이 탑 최소 이동**<br>(원반 옮기기 규칙) | • 작은 원반 위에 큰 원반을 올릴 수 없다는 규칙으로 원반 **`n`개**를 다른 기둥으로 모두 옮기는 **최소 이동 횟수 = `2ⁿ - 1`회**<br>• 자주 나오는 암기값: 원반 3개 = **`7회`**, 원반 4개 = **`15회`**, 원반 5개 = **`31회`** |
| **강 건너기 / 다리 건너기**<br>(병목 조건 해결) | • **먹이사슬 충돌형(늑대·양·양배추)**: 둘만 남겨두면 안 되는 핵심 대상(**양**)을 먼저 건네고, 돌아올 때 다시 데려오는 왕복을 활용합니다.<br>• **손전등 다리 건너기(1분, 2분, 5분, 10분)**: 가장 느린 두 사람(`5분, 10분`)이 **반드시 함께 건너야** 시간을 아끼므로, 가장 빠른 두 사람(`1분, 2분`)을 먼저 보내 손전등 배달부로 활용합니다 (`최소 17분`). |

### 4.2 국어 조건·규칙 지문 & 영어 IT 융합 지문 10초 독해 전략 (★입시요강 핵심)

| 융합 영역 | 시험장 10초 실전 공략법 |
| :---: | :--- |
| **국어 융합 독해**<br>(요금 할인 · 포인트 · 비밀번호 · 부호화 규칙) | 1. **경계값 동그라미 표시**: **`이상 / 이하 / 부터 / 까지`**(경계 숫자 포함 ●) vs **`초과 / 미만`**(경계 숫자 제외 ○)<br>2. **예외·단서 조항 밑줄**: `"단, ~인 경우는 제외한다"`, `"중복 할인 불가"`, `"최대 한도"`<br>3. **질문 사례 먼저 확인**: 지문을 다 외우지 말고 **문제에서 묻는 사례(예: `"14세 청소년, 주말 오전, 3매"`)를 먼저 본 뒤** 해당 조건 줄만 찾아 대입! |
| **영어 융합 독해**<br>(IT 용어 · 보안 · 네트워크 · AI 영문 지문) | • 영문 지문 전체를 처음부터 끝까지 완벽히 해석하려 하지 말고, **정답과 직결되는 핵심 동사·명사 키워드(Scan Keywords)를 찾아 1:1 매칭**합니다:<br>  - `forwards data packets / optimal path` ──▶ **`Router (라우터)`**<br>  - `domain name to IP address` ──▶ **`DNS`**<br>  - `block unauthorized access / traffic` ──▶ **`Firewall (방화벽)`**<br>  - `encrypts files and demands ransom` ──▶ **`Ransomware (랜섬웨어)`**<br>  - `learns from data without being explicitly programmed` ──▶ **`Machine Learning (기계학습)`** |
